# 2025 question JSON preview

Tiny desktop-only renderer for the four corrected Summer 2025 Physics 9702 question JSON files.
Double-click `index.html`; no server is required.

```bash
node prototypes/2025-question-json/server.js
```

Alternatively, open <http://127.0.0.1:4177>. The bundled preview data is a snapshot and does not modify the source JSON files.
