Repeated-object arrangements

Count what really changes.

Identical objects can swap places without producing a new visible arrangement. Divide out that overcount, then handle restrictions with fixed positions, separate cases or gaps.

Start the lesson · Key ideas

First separate distinct from identical

  • Distinct objects can be told apart.
  • Identical objects cannot be told apart.
  • An arrangement records the order in which objects appear.
  • The symbol ! is read “factorial”.
  • For a positive whole number n, n! means n × (n − 1) × … × 2 × 1.
  • For example, 5! = 5 × 4 × 3 × 2 × 1 = 120.
  • If all n objects are distinct, they can be arranged in n! orders.
  • Swapping identical copies does not create a new arrangement.

Count the total objects and every repeated group before calculating.

Why repeated groups make us divide

  • Suppose n objects include r identical copies.
  • If you temporarily label those copies, each visible arrangement is counted r! times.
  • Divide by r! to remove that overcount.
  • If several object types repeat, divide once for every repeated group.
  • The numerator is above a fraction bar. The denominator is below it.

One repeated group

arrangements = n!r!

Several repeated groups

arrangements = n!r! s! …

  • The repeat sizes, plus every single object, must total n.
  • LEVEL has 5 letters, with L twice and E twice.
  • 5!2! × 2! = 30.

Every denominator factor needs a counting reason.

Count each repeated letter type

Worked example: BALLOON

How many different arrangements can be made from all 7 letters?

  1. There are 7 letters.
  2. L appears twice and O appears twice.
  3. B, A and N appear once.
  4. Check the total: 2 + 2 + 1 + 1 + 1 = 7.
  5. arrangements = 7!2! × 2! = 50404 = 1260.

Keep identical objects apart with gaps

  • Adjacent objects are next to each other.
  • If identical objects must not be adjacent, temporarily remove them.
  • Arrange the remaining objects, allowing for any repeats among them.
  • A gap is a position before, between or after those arranged objects.
  • Three arranged objects A B C create four gaps: before A, between A and B, between B and C, and after C.
  • Choose different gaps for the identical objects. At most one goes in each chosen gap.

Arrange first, then choose gaps.

Key ideas

Unrestricted

Start with n!, then divide by the factorial of every repeat size.

Fixed positions

Place required end or block objects first, then arrange what remains.

Not adjacent

Arrange the other objects, identify gaps, then choose different gaps.

Several cases

Count each non-overlapping case correctly, then add.

  • Do repeat counts and single objects total n?
  • Are the repeated objects truly identical?
  • Can the cases overlap?

Every denominator or gap choice must have a counting reason.

More worked examples

Matching ends

Three identical A books, three identical B books and two identical C books are arranged on a shelf. Count arrangements with both end books A or both end books B.

  1. Case 1: AA ends. Fix an A at each end.
  2. The middle contains A, B, B, B, C, C.
  3. 6!3! × 2! = 60.
  4. Case 2: BB ends. Fix a B at each end.
  5. The middle contains A, A, A, B, C, C.
  6. 6!3! × 2! = 60.
  7. The cases cannot overlap: one arrangement cannot have both ends A and both ends B.
  8. Add the separate cases: 60 + 60 = 120.

Fix the ends, count the middle, then add non-overlapping cases.

No adjacent copies

How many arrangements of the 9 letters of TELEPHONE have no two Es adjacent?

  1. TELEPHONE has three identical Es.
  2. The other six letters T, L, P, H, O, N are distinct.
  3. Arrange those six letters: 6! = 720.
  4. They create 7 gaps.
  5. Choose 3 different gaps for the three identical Es.
  6. To count that choice, begin with 7 × 6 × 5 ordered selections.
  7. The same three gaps occur in 3! orders, so divide by 3!.
  8. This unordered choice is written C(7, 3): C(7, 3) = 7 × 6 × 53! = 35.
  9. Total = 720 × 35 = 25 200.

One E in each chosen gap guarantees separation.
