Counting numbers and codes

Which slot should you fill first?

A four-digit number has four positions, but those positions may not have the same choices. Count each legal choice in order, then multiply.

Start the lesson · See the key ideas

One choice follows another

  • A slot is one position in a number or code.
  • An ordered outcome changes when its positions change. For example, AB and BA are different codes.
  • If the first slot has a choices and the next has b choices, each first choice can be paired with every second choice.
  • There are therefore a × b ordered pairs. This is the product rule.
  • Without replacement means that an item cannot be used again. The number of available choices falls after each selection.

Product rule

total outcomes = choices for slot 1 × choices for slot 2 × …

For three ordered choices from five distinct items, with no repetition:

5 × 4 × 3 = 60

5first×4second×3third=60

Build the slots

  1. Write the positions in order.

    Ask what each position is allowed to contain.

  2. Fill a restricted position first.

    Place value is the value a digit receives from its position. In a 4-digit number, the first slot is the thousands digit. The final digit controls whether the number is odd or even.

  3. Update the later counts.

    If repetition is forbidden, remove a chosen item before counting the next slot.

  4. Multiply along one case.

    Add counts only for separate cases that cannot describe the same outcome. Such cases are called disjoint.

Zero needs care

A number cannot begin with 0, because 0 in the first position would make the number shorter. A code may begin with 0 unless the question says otherwise.

Worked example

Three distinct digits from five

From {0, 1, 2, 3, 4}, the first digit has 4 choices because it cannot be 0.

After that choice, 4 digits remain, then 3.

4 × 4 × 3 = 48

There are 48 distinct 3-digit numbers.

Worked example

Distinct three-digit numbers

How many 3-digit numbers can be formed from {0, 1, 2, 3, 4, 5} if no digit is repeated?

Solution

  1. The hundreds digit cannot be 0, so it has 5 choices.

  2. One digit has been used. Five digits remain for the tens digit, including 0 if it is unused.

  3. Four digits then remain for the units digit.

  4. 5 × 5 × 4 = 100

    There are 100 numbers.

Do not start with 6 × 5 × 4: that includes arrangements beginning with 0.

Several ordered stages still multiply

Worked example

A letter-digit code

A code has 2 different letters from {A, B, C, D}, followed by 3 different digits from {1, 2, 3, 4, 5, 6}. How many codes are possible?

Solution

  1. The letter slots have 4 × 3 = 12 arrangements.

  2. The digit slots have 6 × 5 × 4 = 120 arrangements.

  3. Any legal letter arrangement can be followed by any legal digit arrangement, so multiply the two stages.

    12 × 120 = 1440

    There are 1440 codes.

Permutation notation

An ordered selection without replacement is a permutation. Let n be the number available and r the number selected. The notation ⁿPᵣ counts those selections. Here ⁴P₂ × ⁶P₃ = 1440.

Choose the restricted slot first

  • For a number between 2000 and 5000, the thousands digit must be 2, 3 or 4.
  • Parity means whether an integer is odd or even.
  • An odd number ends in 1, 3, 5, 7 or 9. An even number ends in 0, 2, 4, 6 or 8.
  • When there is no repetition, fixing one digit may change the choices for another restricted slot.
  • If two restrictions draw from the same set, split into separate cases when their counts differ.

Worked example

A number range

How many numbers between 2000 and 5000 can be formed from {0, 1, 2, 3, 4, 5, 6} if no digit is repeated?

Solution

  1. The thousands digit must be 2, 3 or 4, so it has 3 choices.

  2. After it is chosen, the remaining slots have 6, then 5, then 4 choices. Zero is allowed after the first position.

  3. 3 × 6 × 5 × 4 = 360

    There are 360 numbers.

Worked example

Repetition allowed

How many even 4-digit numbers can be formed from {0, 1, 2, 3, 4, 5} if digits may be repeated?

Solution

  1. The first digit has 5 choices because it cannot be 0.

  2. Each middle digit has all 6 choices. Repetition means an earlier choice does not reduce these counts.

  3. The final digit must be 0, 2 or 4, so it has 3 choices.

  4. 5 × 6 × 6 × 3 = 540

    There are 540 numbers.

Check-in 2

Using {0, 2, 4, 5, 7} without repetition, how many even 3-digit numbers are possible?

Count “at least one” by removing neither

  • An inclusive or allows the first feature, the second feature, or both.
  • The complement contains every outcome outside the group we want.
  • For “A or B or both”, the complement contains outcomes with neither A nor B.
  • Count all outcomes, count the complement, then subtract.

At least one

at least one = total − neither

Key ideas

  • Ordered slotsDraw the positions. Count legal choices for each, then multiply.
  • No repetitionRemove each selected item before counting later slots.
  • Range or parityRestrict the first or final slot before filling the others.
  • Several casesAdd cases that cannot overlap. For an inclusive “or”, consider total minus neither.

Worked example

Several lengths

Using some or all of {0, 2, 3, 5, 7}, with no repetition, how many odd numbers with at most 4 digits can be formed?

Solution

  1. “At most 4 digits” means the number may have 1, 2, 3 or 4 digits.

  2. Different lengths cannot describe the same number, so count each length separately and add.

  3. The units digit has 3 odd choices. For lengths above 1, the first digit then has 3 non-zero choices.

LengthCount
1 digit3
2 digits3 × 3 = 9
3 digits3 × 3 × 3 = 27
4 digits3 × 3 × 3 × 2 = 54

Total: 3 + 9 + 27 + 54 = 93 odd numbers.

Worked example

At least one named feature

A code has 2 different letters from {A, B, C, D, E, F}, followed by 3 different digits from {1, 2, 3, 4, 5, 6, 7, 8}. How many codes contain A or 5 or both?

  • A code qualifies if it contains A.
  • It also qualifies if it contains 5.
  • A code containing both still counts once.
  • The complement contains codes with neither A nor 5.
  • Subtracting that complement leaves exactly the required codes.

Solution

  1. Count all codes.

    ⁶P₂ × ⁸P₃ = (6 × 5)(8 × 7 × 6) = 10080

  2. For neither A nor 5, only 5 letters and 7 digits remain available.

    ⁵P₂ × ⁷P₃ = (5 × 4)(7 × 6 × 5) = 4200

  3. 10080 − 4200 = 5880

    There are 5880 codes.
