Building probability equations

Translate routes
into one equation.

A complete first-stage split has probabilities that add to 1. Multiply along a route, add separate routes to the same final event, then solve for the unknown.

Start with a complete split

Notation before the equation

  • A probability is a number from 0 to 1.
  • A branch describes one possible next result; a complete route joins branches through all stages.
  • If an event has probability x, its complement has probability 1 − x, because x + (1 − x) = 1.
  • On one route, multiply branch probabilities. For separate routes ending in the same event, add their products.
  • Let A and B be the two first-stage alternatives and E the final event wanted. P(E) means its probability; E′ means it does not happen.
  • Write a = P(A), x = P(E given A), and b = P(E given B). Each letter represents a number. Beside one another, letters mean multiplication: ax means a × x.
  • An equation says two quantities are equal. Keep it true by doing the same operation to both sides.

Total probability

ax + (1 − a)b = P(E)
  • Route through A has probability ax.
  • Route through B has probability (1 − a)b.
  • The routes are separate, so add them.

Find an unknown branch

Worked example

Good connection

Maya uses network A with probability 0.7 and network B with probability 0.3. A good connection has probability x on A and 0.8 on B. Overall, P(good connection) = 0.38. Find x.

Solution
  1. Multiply each source probability by its conditional good-connection probability.
  2. 0.7x + 0.3 × 0.8 = 0.38
  3. 0.7x + 0.24 = 0.38
  4. Subtract 0.24 from both sides: 0.7x = 0.38 − 0.24 = 0.14.
  5. Divide both sides by 0.7 to isolate x: x = 0.14/0.7.
  6. x = 0.20
  7. Check: x is between 0 and 1, and 0.7 × 0.20 + 0.24 = 0.38 as required.

Use complements before adding

Worked example

Not late

Lina travels by bus with probability 0.75 and cycles with probability 0.25. She is late with probability 0.3 by bus and x by cycle. Overall P(not late) = 0.65. Find x.

Solution
  1. Complement both conditional late probabilities first.
  2. P(not late | bus) = 1 − 0.3 = 0.7
  3. P(not late | cycle) = 1 − x
  4. 0.75 × 0.7 + 0.25(1 − x) = 0.65
  5. Expand the brackets by multiplying 0.25 by each term: 0.25(1 − x) = 0.25 − 0.25x.
  6. 0.525 + 0.25 − 0.25x = 0.65
  7. Add 0.25x to both sides and subtract 0.65: 0.775 − 0.65 = 0.25x.
  8. 0.25x = 0.125
  9. Divide by 0.25: x = 0.125/0.25 = 0.50. Check 0.75 × 0.7 + 0.25 × 0.5 = 0.65.

Three source routes

With three source routes, the source probabilities a, b and c must satisfy a + b + c = 1. If event E has conditional probabilities p, q and x on the three sources, the route products are ap, bq and cx.

Three-route equation

ap + bq + cx = P(E)

Do not average conditional probabilities without their source probabilities: a common route contributes more than a rare route.

Three ways to travel

The symbol ≈ means approximately equal. Three significant figures keeps three digits from the first nonzero digit, using the next digit to round.

Worked example

Find the car lateness probability

Noah travels by bus, train or car with probabilities 0.3, 0.4 and 0.3. The probabilities of being late are 0.5, 0.25 and x respectively. Overall P(not late) = 0.62. Find x.

Solution
  1. Complement the known late probabilities: not late by bus is 0.5 and by train is 0.75. Not late by car is 1 − x.
  2. 0.3 × 0.5 + 0.4 × 0.75 + 0.3(1 − x) = 0.62
  3. 0.15 + 0.30 + 0.30 − 0.30x = 0.62
  4. 0.75 − 0.30x = 0.62
  5. Add 0.30x and subtract 0.62 on both sides: 0.30x = 0.75 − 0.62 = 0.13.
  6. Divide by 0.30: x = 0.13/0.30 = 13/30.
  7. x = 13/30 ≈ 0.433 (three significant figures)

Use the simplest score event

Worked example

Biased spinners

Two identical biased triangular spinners are labelled 1, 2 and 3. They spin independently, so one result does not affect the other. Each has probabilities p, q and r for scores 1, 2 and 3 respectively. “Biased” means the outcomes need not be equally likely. Given P(total score 6) = 1/25 and P(total score 5) = 4/25, find p, q and r.

Solution
  1. For total 6, both scores must be 3. Thus r × r = r² = 1/25. The power 2 means multiply r by itself. Both 1/5 and −1/5 square to 1/25; reject −1/5 because a probability cannot be negative.
  2. For a total of 5, the routes are 2 then 3 and 3 then 2, so P(total 5) = qr + rq = 2qr.
  3. 2q × 1/5 = 4/25. Multiply both sides by 5/2 to get q = (4/25) × (5/2) = 2/5
  4. p = 1 − q − r = 1 − 2/5 − 1/5 = 2/5
  5. p = 2/5, q = 2/5, r = 1/5

Unknown counts can be probabilities

Worked example

Two boxes of fruit

Jamal’s box contains 4 plums and 6 apricots. Rosa’s box contains x plums and 5 apricots. One fruit is chosen at random from each box, independently. Rosa’s total is x + 5, because both the x plums and 5 apricots count. P(both plums) = 1/5. Find x.

Solution
  1. P(plum from Jamal) = 4/10 = 2/5
  2. P(plum from Rosa) = x/(x + 5)
  3. (2/5) × x/(x + 5) = 1/5
  4. Multiply both sides by 5 to remove the factor 1/5: 2x/(x + 5) = 1.
  5. Multiply both sides by x + 5, which is positive because x is a fruit count: 2x = x + 5.
  6. Subtract x from both sides.
  7. x = 5

Specified path products

Worked example

Rain, hat and scarf

The probability of rain is x. If it is not raining, Alex wears a hat with probability 0.2. If Alex is not wearing a hat, the probability of a scarf is 0.15. P(no rain, no hat and no scarf) = 0.544. Find x.

Solution
  1. P(no rain) = 1 − x
  2. P(no hat | no rain) = 1 − 0.2 = 0.8
  3. P(no scarf | no hat) = 1 − 0.15 = 0.85
  4. (1 − x) × 0.8 × 0.85 = 0.544
  5. 0.68(1 − x) = 0.544. Divide both sides by 0.68: 1 − x = 0.8
  6. Subtract 0.8 and add x to both sides: x = 1 − 0.8 = 0.20. Check 0.8 × 0.8 × 0.85 = 0.544.
