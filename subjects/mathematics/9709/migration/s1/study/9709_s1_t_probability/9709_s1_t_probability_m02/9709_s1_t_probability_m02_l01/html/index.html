Probability trees and branch probabilities

Build the tree before you calculate.

Label every branch, check each node, multiply along a path, and add separate paths only when they describe the requested event.

Start the lesson · Return to key ideas

Node totals, complements and paths

  • An event describes a result or collection of results. P(A) means the probability of event A.
  • A node is a point where the tree splits. A branch is a line for one possible next result. A path follows branches through successive stages.
  • The branches leaving one node cover all possible next results without overlap. Their probabilities therefore add to 1.
  • Mutually exclusive means the alternatives cannot both occur in the same trial.
  • A conditional probability describes the chance after specified information is known. A later branch uses the result already reached.
  • At one split, probabilities leaving the same node add to 1.
  • Along one complete path, multiply the branch probabilities.
  • Across mutually exclusive paths, add the path probabilities.
Complement

If event A has probability P(A), its complement is the event “A does not happen”.

P(not A) = 1 - P(A) = 1 - 0.72 = 0.28

Build a probability tree

A node is a joining point where one stage ends and the next starts. A branch is one outcome leaving it.

Worked example · bus and coffee

Bus on time: 0.6; late: 0.4. After on time, coffee: 0.9. After late, coffee: 0.2.

  • Draw one branch for each outcome.
  • Read each second-stage value after its first-stage condition.
  • Check 0.6 + 0.4 = 1, 0.9 + 0.1 = 1 and 0.2 + 0.8 = 1.
Conditional probability is read after a stated earlier result.

Complete every branch

Worked example · matches

First win: 0.6. First loss and draw are equally likely. After a win, win: 0.7 and loss: 0.1.

  1. Remaining first probability: 1 - 0.6 = 0.4.
  2. Equal split: 0.4 ÷ 2 = 0.2 each.
  3. Missing draw after win: 1 - 0.7 - 0.1 = 0.2.
0.6 + 0.2 + 0.2 = 1
0.7 + 0.2 + 0.1 = 1

Impossible branches

Worked example · meal and bread

Soup, pasta and curry: 0.25, 0.50, 0.25. Bread after them: 0.8, 0.3, 0.

After curry, bread is impossible, so its branch is 0 and no bread is 1. Every outgoing group still totals 1.

Update counts without replacement

  • Without replacement means the chosen counter is kept out. With replacement means it is put back before the next draw.
  • The fraction’s top number, its numerator, counts the colour wanted. Its bottom number, the denominator, counts all counters available.
  • Choose each counter at random, so every remaining counter has the same chance.
Worked example · 3 red, 2 blue

After a red from a bag of 3 red and 2 blue, the total changes from 5 to 4. The next branches are 2/4 and 2/4. After a blue, they are 3/4 and 1/4. Only the colour removed loses one from its numerator.

With replacement, second-stage fractions would stay 3/5 and 2/5.

Worked example · 4 green, 3 yellow

First green: 4/7, then 3/6 green and 3/6 yellow. First yellow: 3/7, then 4/6 green and 2/6 yellow.

After green: 3/6 + 3/6 = 1
After yellow: 4/6 + 2/6 = 1

State-dependent weather and transfer

Worked example · weather

Monday sunny: 0.7. After sunny, Tuesday sunny: 0.8. After rainy, Tuesday sunny: 0.3.

Complements: 1 - 0.7 = 0.3, 1 - 0.8 = 0.2, 1 - 0.3 = 0.7. Read the second-stage branch after the correct first-stage state.

Worked example · transfer

Bag A has 2 red and 1 blue; Bag B has 3 red and 2 blue. Red transferred gives B 4 red and 2 blue; blue transferred gives B 3 red and 3 blue. Each receiving total is 6.

  1. Choose one counter at random from A and move it to B.
  2. Choose one counter at random from the updated B.
  3. The complete path probabilities are (2/3) × (4/6), (2/3) × (2/6), (1/3) × (3/6) and (1/3) × (3/6), in the same top-to-bottom order as the tree.

Key ideas

  • Draw stages left to right and one branch for each possible outcome.
  • Name every outcome and write its probability on the correct branch.
  • For no replacement or transfer, update contents before the next split.
  • Use conditional probability after the earlier result.
  • Check node totals. Multiply along paths; add mutually exclusive paths.

Quick checks

Check A. A first branch is 0.65. There are exactly two other possible outcomes, equally likely.

Check B. A bag has 4 red and 2 blue counters. One red is removed.
