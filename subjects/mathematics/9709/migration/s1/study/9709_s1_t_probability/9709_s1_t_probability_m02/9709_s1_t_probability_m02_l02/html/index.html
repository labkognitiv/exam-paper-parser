Probability trees

Follow every path,
then add the valid ones.

A tree diagram keeps multi-stage probability organised. Multiply along one complete path. Add separate paths that reach the event.

Start the lesson

Two rules for a probability tree

  • P(A) means the chance that event A happens. A′ means A does not happen.
  • A branch is one possible next result; a node is the point it starts from. A later branch gives the chance after the earlier results on that route.
  • Mutually exclusive paths cannot both describe the same trial. Adding them counts each result once.
  • A path is one complete route from the start to an end point.
  • Multiply along a path: “and then” means multiply.
  • Add across paths: separate valid routes are mutually exclusive.
  • Without replacement means an item is removed, so the next total falls by one. Only the count of the colour actually removed falls by one.
Example: P(A and B) = 0.6 × 0.4 = 0.24. If two valid paths have probabilities 0.24 and 0.15, total = 0.39.

Worked example: win on a later turn

A bag contains 3 red and 5 white discs. Sam and Tom alternately remove one disc without replacement. Sam starts. A player wins when that player has removed their second red disc. Write R for red and W for white. Find the probability Tom wins on his second turn.

  1. Tom wins on his second turn on draw 4. Tom needs red on draws 2 and 4. Sam must not have two reds on draws 1 and 3, or the game ends earlier. These conditions give exactly three sequences: RRWR, WRRR and WRWR.
  2. For RRWR: (3/8)(2/7)(5/6)(1/5) = 1/56.
  3. For WRRR: (5/8)(3/7)(2/6)(1/5) = 1/56.
  4. For WRWR: (5/8)(3/7)(4/6)(2/5) = 1/14.
  5. Add mutually exclusive paths: 1/56 + 1/56 + 1/14 = 3/28.

List only sequences where the game has not ended earlier.

The method map

Describe

Translate the requested event into complete, mutually exclusive paths.

Update

After removal or transfer, write the new contents before the next probability.

Calculate

Multiply every factor along each path, then add valid path probabilities.

Check

Probabilities lie between 0 and 1. Branches at one node add to 1.

From branches to paths

  • A terminal outcome, at the end of the tree, belongs to exactly one complete route.
  • Do not add branch probabilities along one route. The word and means multiply.
  • Write the event beside the product before calculating.
  1. If P(A) = 0.7 and P(B after A) = 0.4, then P(A and then B) = 0.7 × 0.4.
  2. P(A and then B) = 0.28.

Worked example: either order

A bag has 3 red and 5 white balls. Two are chosen without replacement. Find the probability that the balls have different colours.

  1. Different colours means either RW or WR.
  2. P(RW) = (3/8)(5/7) = 15/56.
  3. P(WR) = (5/8)(3/7) = 15/56.
  4. Add the two paths: P(different) = 30/56 = 15/28.

Total probability

Nadia travels by bus with probability 0.65 and by train with probability 0.35. She arrives early with probability 0.4 by bus and 0.7 by train.

  1. Early occurs on two mutually exclusive paths. “By bus” and “by train” specify the condition for the next probability.
  2. P(bus and early) = 0.65 × 0.4 = 0.26.
  3. P(train and early) = 0.35 × 0.7 = 0.245.
  4. Add them: P(early) = 0.26 + 0.245 = 0.505.

Without replacement

A bag contains 4 green and 2 yellow counters. Two are drawn at random without replacement. G means green and Y means yellow.

  • The path product must use the contents remaining at each stage.
  • After a green item is removed from 4 green and 2 yellow, the next green probability is 3/5.
  • After a yellow item is removed, the next yellow probability is 1/5.
  1. P(GG) = (4/6)(3/5) = 2/5.
  2. P(YY) = (2/6)(1/5) = 1/15.
  3. Update first, then multiply.

Same or different

A box contains 5 blue and 3 orange counters. Two are chosen without replacement. Write B for blue and O for orange. “Same” means BB or OO.

  1. P(BB) = (5/8)(4/7) = 20/56.
  2. P(OO) = (3/8)(2/7) = 6/56.
  3. P(same) = 26/56 = 13/28.
  4. As a check, different means BO or OB: (5/8) × (3/7) + (3/8) × (5/7) = 30/56 = 15/28. Since same and different cover every result, P(same) = 1 − 15/28 = 13/28.

Longer paths

For three or more stages, describe the target event as a list of valid sequences before multiplying.

Example target: exactly two successes in three attempts

Write S for success and F for failure. Exactly two successes means SSF, SFS or FSS. Independence means a previous result does not change the next success probability. If each attempt is independent with P(S) = 0.6, each sequence has probability 0.6 × 0.6 × 0.4 = 0.144. Total: 3 × 0.144 = 0.432.

List first; calculate second; add once.

Worked example: two attempts

A student passes a written test on the first attempt with probability 0.75. After a first fail, the probability of passing the second attempt is 0.6. A student who passes the written test then passes a practical test with probability 0.4. Find the probability of passing both tests.

  1. Pass first, then practical: 0.75 × 0.4 = 0.30.
  2. Fail first, pass second, then practical: 0.25 × 0.6 × 0.4 = 0.06.
  3. Add the two success paths: 0.30 + 0.06 = 0.36.
  4. A student who fails both written attempts cannot reach the practical test.

Worked example: choose then sample

A fair coin chooses Bag A or Bag B. Bag A has 6 white and 4 black balls; Bag B has 3 white and 5 black balls. Two balls are drawn without replacement. Find the probability both are white.

  1. The bag choice is the first factor on every complete path.
  2. P(AWW) = 1/2 × 6/10 × 5/9 = 1/6.
  3. P(BWW) = 1/2 × 3/8 × 2/7 = 3/56.
  4. Use a common denominator to add fractions: 1/6 = 28/168 and 3/56 = 9/168. Add the numerators: 37/168.

Key ideas

  • Describe complete valid paths.
  • Multiply along each path.
  • Add mutually exclusive valid paths.
  • Update counts after every removal.
  • Check branch totals and the direct method where possible.
