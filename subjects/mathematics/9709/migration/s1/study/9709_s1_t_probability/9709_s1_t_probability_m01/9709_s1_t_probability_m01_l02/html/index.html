Combining events

Choose the right event to count.

Complements, nested intervals, exclusive alternatives and conditional paths all describe different ways events can fit together.

Start the lesson

Complementary events

  • An event is a stated outcome or collection of outcomes.
  • The complement of A, written A′, means A does not happen.
  • A and A′ cover every outcome exactly once, so their probabilities add to 1.

Reading the notation

  • P(A) means the probability that event A happens.
  • W records the waiting time in minutes; < means less than and ≤ means less than or equal to.
  • A′ means the complement, “A does not happen”.
  • Independent trials do not change one another’s probabilities, so repeated factors can be multiplied.

Complement rule

P(A′) = 1 − P(A)

Use it when the opposite event is easier to count.

Worked example

A bus is not late

The probability that a bus is late is 0.18. Find the probability that it is not late.

Solution
  1. Let L mean “the bus is late”. The event “not late” is L′.
  2. P(L′) = 1 − P(L) = 1 − 0.18
  3. P(L′) = 0.82
  4. Check: 0.18 + 0.82 = 1.
Check-in A

If P(A) = 0.37, which expression gives P(A′)?

Between two cut-offs

  • A cumulative probability such as P(W < 10) includes everything below 10.
  • To keep only the values from 5 up to 10, subtract the smaller nested event.
Worked example

Waiting time between 5 and 10 minutes

P(W < 5) = 0.16 and P(W < 10) = 0.88. Find P(5 ≤ W < 10).

Solution
  1. The event W < 5 sits inside W < 10.
  2. P(5 ≤ W < 10) = P(W < 10) − P(W < 5)
  3. = 0.88 − 0.16
  4. = 0.72

Mutually exclusive events

  • Events are mutually exclusive when they cannot happen together.
  • Then P(A and B) = 0.
  • For mutually exclusive events, P(A or B) = P(A) + P(B).
Worked example

Red or blue

A spinner lands on Red with probability 0.35 and Blue with probability 0.25. Exactly one colour occurs. Find P(Red or Blue).

Solution
  1. Red and Blue cannot occur together, so the events are mutually exclusive.
  2. P(Red or Blue) = P(Red) + P(Blue)
  3. = 0.35 + 0.25
  4. = 0.60

Several repeated trials

  • For a fair four-sided spinner, each number has probability 1/4.
  • The power 3 means the same no-4 factor is multiplied once for each of the three independent spins.
  • “No 4” is the complement of “4”, so its one-spin probability is 3/4.
  • For independent spins, multiply the same probability once for each spin.
Worked example

At least one 4

A fair four-sided spinner is spun three times. Find the probability of at least one 4.

Solution
  1. Use the complement: “at least one 4” is opposite to “no 4”.
  2. P(no 4 in three spins) = (3/4)^3 = 27/64
  3. P(at least one 4) = 1 − 27/64
  4. = 37/64

Enumerate ordered outcomes

  • When every ordered outcome has the same probability, count favourable outcomes and divide by the total.
  • Let S be the total score. Four spins of a 1, 2, 3 spinner give 3⁴ = 81 ordered outcomes.
Worked example

Total score 5

A fair spinner numbered 1, 2, 3 is spun four times. Find P(total score = 5).

Solution
  1. Since four minimum scores total 4, reaching 5 adds exactly one point. The only pattern is 2, 1, 1, 1 in some order.
  2. The 2 can occupy any of four positions: (2,1,1,1), (1,2,1,1), (1,1,2,1), (1,1,1,2).
  3. P(S = 5) = 4 × (1/3)^4 = 4/81
  4. P(S = 5) = 4/81
Check-in B

For four spins of a 1, 2, 3 spinner, which pattern can make a total of 6?

Conditional paths

  • A conditional probability gives a chance after specified information is known. The vertical bar | means “given that”. Here the next day depends on the previous day in the stated weather model.
  • In a run of dry days, the model gives P(dry next | dry previous) = 1 − 0.25 = 0.75.
  • Multiply along one valid path, once for the first day and once for each transition.
Worked example

Dry on all four days

An event lasts four days. P(rain on day 1) = 0.3. On a later day, P(rain) = 0.25 if the previous day was dry. Find P(dry on all four days).

Solution
  1. P(dry day 1) = 1 − 0.3 = 0.7
  2. P(dry next | dry previous) = 1 − 0.25 = 0.75
  3. There are three transitions after day 1.
  4. P(all dry) = 0.7 × (0.75)^3
  5. = 0.7 × 0.421875
  6. = 0.2953125
