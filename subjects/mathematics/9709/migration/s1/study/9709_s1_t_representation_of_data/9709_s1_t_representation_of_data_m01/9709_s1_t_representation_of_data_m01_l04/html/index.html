Cumulative frequency graphs

Add as you go.
Plot where each class ends.

A frequency tells you how many values lie in one class. A running total tells you how many lie up to that point. Plot those totals at the class boundaries and the growing pattern becomes a curve.

Start the lesson

A cumulative frequency is a running total

  • Frequency is the number of observations in one class.
  • Cumulative means built up step by step.
  • Cumulative frequency is the running total of frequencies so far.
  • Begin with the first frequency.
  • Add each new frequency to the previous running total.
  • The final cumulative frequency equals the total number of observations.

Coordinates

  • The second number locates it up the vertical axis.

Rounded classes need continuous boundaries

  • A value recorded to the nearest unit represents an interval extending half a unit on either side.
  • A recorded 5 can represent values from 4.5 up to, but not including, 5.5.
  • So recorded class 5–9 has true boundaries 4.5 and 9.5.
  • Use upper boundary 9.5, not midpoint 7.
  • Start the curve at the first true lower boundary with cumulative frequency zero.

Key ideas

  1. Add frequencies to make running totals.
  2. Match each total to its class’s upper boundary.
  3. Write (upper boundary, cumulative frequency).
  4. Start at the first lower boundary with cumulative frequency zero.
  5. Use linear labelled axes.
  6. Join points with a smooth increasing curve.
  7. For nearest-unit classes, move half a unit to find continuous boundaries.
