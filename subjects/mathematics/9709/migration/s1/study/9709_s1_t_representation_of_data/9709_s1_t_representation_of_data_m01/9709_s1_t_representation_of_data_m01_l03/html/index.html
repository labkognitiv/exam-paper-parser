Histogram bars can have different widths. Their areas, rather than their heights alone, show how many observations lie in each class.

Width comes from the class interval

  • A class interval is a range used to group values.
  • The letter x stands for the observed value being grouped.
  • The symbol ≤ means “less than or equal to”, so the endpoint is included.
  • The symbol < means “less than”, so the endpoint is excluded.
  • In , the value 0 is included and 8 is excluded.
  • The lower boundary is the left endpoint. The upper boundary is the right endpoint.
  • Subtract the lower boundary from the upper boundary.

Why histograms use area

  • Frequency is the number of observations in a class.
  • Frequency density is frequency divided by class width.
  • The horizontal axis runs left to right and carries observed values.
  • The vertical axis runs up the page and carries frequency density.
  • A linear scale uses equal distances for equal changes in value.
  • A bar's width shows its class width.
  • A bar's height shows its frequency density.
  • So width × height equals frequency.

Recorded values need continuous boundaries

  • A continuous variable can take any value in an interval.
  • If values are rounded to the nearest whole unit, each recorded integer represents values up to 0.5 below and 0.5 above it.
  • Therefore a recorded class 10–19 has exact boundaries 9.5 and 19.5.
  • Find boundaries before widths, then find densities.

Key ideas

  • Class width = upper boundary − lower boundary.
  • Frequency density = frequency ÷ class width.
  • Frequency = class width × frequency density.
  • Histogram bars touch because continuous classes meet at their boundaries.
  • With unequal class widths, compare areas. Height alone can mislead.
  • For data rounded to the nearest whole unit, move 0.5 outwards to find exact boundaries.
