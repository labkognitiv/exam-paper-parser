Choosing and interpreting data displays

What should the reader notice?

The same data can be shown in several ways. A useful choice makes the comparison clear and admits what the display hides.

Start the lesson

Begin with centre and spread

  • A dataset is the complete collection of values being studied.
  • Centre describes a typical value.
  • Spread describes how far the values vary.
  • The mean uses every value: add the values, then divide by how many there are.
  • The median is the middle value after the data are placed in order.
  • The range is the maximum value minus the minimum value.

Worked example

Books read: 4, 6, 6, 8, 11

Solution

  1. Add all five values: 4 + 6 + 6 + 8 + 11 = 35
  2. Divide by 5: mean = 35 ÷ 5 = 7
  3. The ordered list has five values. The third value is in the middle, so median = 6.
  4. range = 11 - 4 = 7

The mean 7 and median 6 describe centre. The range 7 describes spread.

A number is useful only when you say what it describes.

Check for an extreme value

  • An extreme value is much smaller or much larger than the other values.
  • The mean uses every value, so one extreme value can pull it strongly up or down.
  • The median depends on position, so it usually changes much less.

Look before you choose

For 21, 22, 24, 25, 73, the extreme value 73 pulls the mean up to 33. The median stays at 24, so it describes the cluster more faithfully.

Worked example

Which centre is useful?

Seven commute times, in minutes, are 12, 13, 14, 14, 15, 16, 52.

Solution

  1. The values are already ordered.
  2. 12 + 13 + 14 + 14 + 15 + 16 + 52 = 136
  3. mean = 136 ÷ 7 ≈ 19.4 minutes
  4. The fourth of seven values is the middle one, so median = 14 minutes.
  5. The value 52 is extreme. It pulls the mean upward.

The median, 14 minutes, is the more useful description of a typical commute.

Two measures of spread

  • A quartile divides ordered data into quarters.
  • Q₁, the lower quartile, marks the lower quarter.
  • Q₃, the upper quartile, marks the upper quarter.
  • The interquartile range, or IQR, is Q₃ - Q₁. It describes the spread of the middle 50%.
  • For these times, Q₁ = 13, Q₃ = 16, so IQR = 16 - 13 = 3 minutes.
  • The range is 52 - 12 = 40 minutes. It reacts strongly to 52.

Choose the display by purpose

Start with the comparison the question asks the reader to make.

  • A frequency is the number of values in a category or interval.
  • A percentile is a value below which a stated percentage of the data lies.

Stem-and-leaf diagram

  • A stem holds the leading digit or digits.
  • A leaf holds the final digit.
  • Every original value stays visible and ordered.
  • Include a key with units, such as 2 | 1 = 21 years.

Paired box plots

  • A five-number summary is minimum, Q₁, median, Q₃, maximum.
  • The box runs from Q₁ to Q₃; a line inside marks the median.
  • The whiskers extend from the box to the minimum and maximum used by the plot.
  • Two box plots on the same scale make centre and spread quick to compare.
  • They hide the individual values and their exact frequencies.

Cumulative frequency curve

  • Cumulative frequency is a running total.
  • The curve plots each running total against the corresponding value.
  • Use it to estimate percentiles or counts below a chosen value.
  • It can reveal more cumulative totals than a five-number summary.

Histogram

  • Use it for frequencies across continuous class intervals.
  • A continuous variable can take any value in an interval.
  • The area of each bar represents frequency.

Ask: What does this display reveal? What does it hide? Which comparison is needed?

Compare two groups with evidence

Paired box plots compress both groups into the same five-number language.

A4052586480
B4550607282
  1. Centre: Group B has the higher median, 60 compared with 58.
  2. Middle 50% spread: IQR(A) = 64 - 52 = 12; IQR(B) = 72 - 50 = 22. Group A is less variable in its middle 50%.
  3. Overall spread: range(A) = 40; range(B) = 37. Group B has the slightly smaller overall range.

State the group, name the statistic, and quote both values.

Key ideas

  • Use mean or median for centre; check whether extreme values make the mean unrepresentative.
  • Use range for overall spread and IQR for the middle 50%.
  • Use a stem-and-leaf diagram when every ordered value should remain visible.
  • Use paired box plots for a quick comparison of medians and spreads on one scale.
  • Use a cumulative frequency curve for percentiles or counts below a chosen value.
  • Use a histogram for continuous grouped data; its bar areas represent frequencies.
  • A strong comparison names the group, the statistic and the values.

Worked example

Compare journey times

School A: minimum 42, Q₁ = 48, median 55, Q₃ = 61, maximum 70. School B: minimum 38, Q₁ = 51, median 57, Q₃ = 66, maximum 75.

Solution

  1. School B has the higher typical time: medians 57 and 55 minutes.
  2. IQR(A) = 13; IQR(B) = 15.
  3. range(A) = 28; range(B) = 37.
  4. School A is less spread out by both IQR and range.
  5. Advantage: paired box plots make medians and spreads easy to compare on one scale.
  6. Limitation: they hide individual values and exact frequencies.

Worked example

When the mean misleads

Eight package masses, in grams, are 18, 20, 21, 21, 22, 23, 24, 61.

Solution

  1. mean = 210 ÷ 8 = 26.25 g
  2. Eight is even, so no single value occupies the middle. Positions 4 and 5 are equally central.
  3. Average those two values: median = (21 + 22) ÷ 2 = 21.5 g.
  4. The extreme value 61 g pulls the mean upward.

The mean 26.25 g is not representative of a typical package mass.

Worked example

Why paired box plots can be clearer

The same 80 race times for each of two groups are shown by cumulative frequency curves and paired box plots.

Solution

  • Each median is marked directly.
  • Each box runs from Q₁ to Q₃, so its width shows the IQR.
  • The whiskers show the overall spread used by the plot.
  • Therefore it is easier to compare which group has the higher typical time and which is more spread out.
