Means

Turn every value
into its contribution.

A mean shares a total equally. Find the total each value contributes, then divide once by the full number of observations.

Start the lesson

Before you start

  • The mean is the total of all values divided by the number of values.
  • The frequency of a value is the number of times it occurs.
  • If 7 has frequency 4, its contribution to the total is 7 × 4 = 28.
  • The capital Greek letter Σ means add all entries. Here f means frequency, and x means a value or a class midpoint.
  • Σf counts all observations. Σfx adds all weighted contributions.
  • Add every contribution, then divide once. Keep the unit: a mean of times is in minutes; a mean of lengths is in centimetres.

Mean

mean = total / number

Work backwards

total = mean × number

number = total / mean, if mean ≠ 0

Raw values and a missing value

Worked example

Seven plant heights

The heights, in centimetres, are 4.2, 5.1, 6.3, 4.8, 5.6, 6.0 and 4.9. Find their mean.

Solution

  1. There are 7 values.
  2. Add them: 4.2 + 5.1 + 6.3 + 4.8 + 5.6 + 6.0 + 4.9 = 36.9 cm.
  3. mean = 36.9 / 7 = 5.271428…
  4. Round to 3 significant figures.

The mean height is 5.27 cm.

The denominator counts the values, not the gaps between them.

Worked example

Recover one missing quiz score

Eight quiz scores have mean 14. Seven of the scores are 11, 13, 15, 12, 16, 14 and 16. Find the missing score.

Solution

  1. Turn the mean into the total: 14 × 8 = 112.
  2. Add the known scores: 11 + 13 + 15 + 12 + 16 + 14 + 16 = 97.
  3. Subtract: 112 - 97 = 15.
  4. Check: (97 + 15) / 8 = 14.

The missing score is 15.

Combine two totals

Worked example

Two groups with different sizes

Group A has 8 values with mean 14.5. Group B has 12 values with mean 17. Find the mean of all 20 values.

Solution

  1. Total for A: 8 × 14.5 = 116.
  2. Total for B: 12 × 17 = 204.
  3. Combined total: 116 + 204 = 320.
  4. Combined number: 8 + 12 = 20.
  5. combined mean = 320 / 20 = 16.

The combined mean is 16.

Do not calculate (14.5 + 17) / 2. The group sizes differ. Combine totals and numbers.

Estimate a mean from grouped data

  • A class is an interval containing a group of values.
  • The exact values inside a class are unknown, so use its midpoint as one representative value.
  • The midpoint is (lower boundary + upper boundary) / 2.
  • Multiply each midpoint x by its frequency f, then use estimated mean = Σfx / Σf.
  • This is an estimate because one midpoint represents every value in its class. Never replace the midpoint with an endpoint or class width.

Worked example

Grouped journey times

The times t minutes are grouped below. Estimate the mean time.

Class0 ≤ t < 1010 ≤ t < 2020 ≤ t < 3030 ≤ t < 50
Frequency4754

Solution

  1. Midpoints: 5, 15, 25, 40.
  2. Σf = 4 + 7 + 5 + 4 = 20.
  3. Σfx = 5(4) + 15(7) + 25(5) + 40(4).
  4. Σfx = 20 + 105 + 125 + 160 = 410.
  5. estimated mean = 410 / 20 = 20.5 minutes.

The estimated mean time is 20.5 minutes.

From cumulative frequency to frequency

  • A cumulative frequency is a running total that includes every earlier class.
  • Subtract consecutive cumulative totals to recover each class frequency.
  • Then find the class midpoints and calculate the weighted mean.

Worked example

Fifty journey times from cumulative totals

For 50 journeys, the first class is 0–20 minutes. The cumulative frequencies at 20, 30, 50 and 80 minutes are 8, 20, 44 and 50. Estimate the mean journey time.

Solution

  1. Class frequencies: 8, 20 − 8 = 12, 44 − 20 = 24, 50 − 44 = 6.
  2. Classes: 0–20, 20–30, 30–50, 50–80.
  3. Midpoints: 10, 25, 40, 65.
  4. Σfx = 10(8) + 25(12) + 40(24) + 65(6).
  5. Σfx = 80 + 300 + 960 + 390 = 1730.
  6. estimated mean = 1730 / 50 = 34.6 minutes.

The estimated mean journey time is 34.6 minutes.

The final cumulative frequency supplies Σf.

Key ideas

The letter n is the number of observations.

Raw values

Add every value, then divide by the number of values.

mean = Σx / n

Mean and number given

Turn the mean into a total.

total = mean × number

Grouped frequencies

Find each midpoint x, calculate fx, then divide.

estimated mean = Σfx / Σf

Cumulative frequencies

Subtract consecutive cumulative totals to recover class frequencies before using midpoints.

Final check

  1. Did every observation contribute once?
  2. Did you divide by the full number of observations?
  3. For grouped data, did you call the mean an estimate?
  4. For a contextual mean, did you include the unit?

Worked example

Grouped parcel masses

The masses x grams of 30 parcels are grouped below. Estimate the mean mass. [3]

Class20 ≤ x < 3030 ≤ x < 5050 ≤ x < 8080 ≤ x < 100
Frequency61275

Solution

  1. Midpoints: 25, 40, 65, 90.
  2. Σf = 30.
  3. Σfx = 25(6) + 40(12) + 65(7) + 90(5).
  4. Σfx = 150 + 480 + 455 + 450 = 1535.
  5. estimated mean = 1535 / 30 = 51.166….
  6. Round to 3 significant figures.

The estimated mean mass is 51.2 g.

Worked example

Recover the cost of one folder

A shopper buys 6 identical notebooks at $4.50 each, 3 identical folders and one bag costing $21. The mean cost of the 10 items is $7.20. Find the cost of one folder. [3]

Solution

  1. Total cost: 10 × $7.20 = $72.
  2. Cost of notebooks: 6 × $4.50 = $27.
  3. Let one folder cost $x.
  4. 27 + 3x + 21 = 72.
  5. Combine the known costs, then subtract 48 from both sides: 3x = 72 − 48 = 24.
  6. Divide both sides by 3: x = 24 / 3 = $8.

One folder costs $8.

Check: (27 + 24 + 21) / 10 = 72 / 10 = $7.20. Use one variable for the cost of one repeated item.

Worked example

A combined mean height

Nine players have mean height 168 cm. Eleven other players have mean height 174 cm. Find the mean height of all 20 players. [2]

Solution

  1. First total: 9 × 168 = 1512 cm.
  2. Second total: 11 × 174 = 1914 cm.
  3. Combined total: 1512 + 1914 = 3426 cm.
  4. combined mean = 3426 / 20 = 171.3 cm.

The mean height is 171.3 cm.

It lies between 168 and 174, and is closer to 174 because the second group is larger.
