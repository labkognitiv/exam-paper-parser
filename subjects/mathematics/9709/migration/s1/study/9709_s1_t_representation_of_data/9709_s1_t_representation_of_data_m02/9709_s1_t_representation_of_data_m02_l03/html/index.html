The 1.5 IQR outlier rule

  • An outlier is an unusually distant observed value.
  • A fence is a calculated boundary used to test for outliers.
  • A value is an outlier only when it is below the lower fence or above the upper fence.
  • A value exactly on a fence is not an outlier.

Key ideas

  • Check the five values are ordered before drawing.
  • Use one labelled linear scale.
  • The box shows the middle half; its width is the IQR.
  • The median line shows the centre. Whiskers show the spread beyond the box.
  • Comparative plots need the same scale.
  • Use both outlier fences and compare each endpoint with the correct boundary.
