Coding data

Shift to simplify.
Decode what changes.

Subtract the same constant from every value to make the arithmetic smaller. The mean shifts, while variance and standard deviation stay the same.

Start the lesson

One shift, two effects

  • Coding replaces each original value x with a simpler coded value y = x - a.
  • The constant a is subtracted from every value.
  • If 48, 51 and 56 are coded using y = x - 50, they become −2, 1 and 6.
  • x̄ is the original mean and ȳ is the coded mean.
  • The mean shifts by the same amount: ȳ = x̄ − a, so x̄ = ȳ + a.
  • Var means variance and sd means standard deviation.
  • Adding or subtracting the same constant does not change the gaps between values. Therefore variance and standard deviation stay the same.

Totals for n values

The capital Greek letter Σ means add all entries. The letter n is the number of values.

Σy = Σ(x − a) = Σx − na

Σx = Σy + na

Because the same constant appears n times, its total contribution is na.

Mean and spread

ȳ = Σy/n = x̄ − a

Var(y) = Var(x)

sd(y) = sd(x)

Worked example

Find the shift

For 24 values, x̄ = 52.5 and Σ(x − k) = 300. Find k.

Solution

  1. The coded mean is mean(x − k) = 300/24 = 12.5.
  2. Use coded mean = original mean − shift: x̄ − k = 12.5.
  3. Substitute the original mean: 52.5 − k = 12.5.
  4. Add k to both sides, then subtract 12.5: k = 52.5 − 12.5 = 40.

k = 40.

Check: Σx = 24(52.5) = 1260 and 1260 − 24(40) = 300.

Worked example

Find the number of values

For n values, Σ(x − 50) = 144 and Σx = 944. Find n.

Solution

  1. Expand the coded total: Σ(x − 50) = Σx − 50n.
  2. Substitute: 144 = 944 − 50n.
  3. Rearrange: 50n = 944 − 144 = 800.
  4. Divide both sides by 50: n = 16.

There are 16 values.

Check: the coded mean is 144/16 = 9, the original mean is 944/16 = 59, and 59 − 50 = 9.

Worked example

Variance from coded totals

For 25 values, let y = x − a. Given Σy = 150 and Σy² = 1900, find the variance and standard deviation of x.

The variance of values z is Var(z) = Σz²/n − (Σz/n)². The standard deviation is the non-negative square root of the variance.

Solution

  1. A shift does not change spread: Var(x) = Var(y).
  2. Var(y) = 1900/25 − (150/25)².
  3. Var(y) = 76 − 36 = 40.
  4. sd(x) = √40 ≈ 6.32 (3 s.f.).

The variance of x is 40 and its standard deviation is 6.32.

When both totals use the same code, the unknown a is not needed for spread.

Worked example

Recover an original squared total

For 16 values, x̄ = 28, Σ(x − 20) = 128 and Σ(x − 20)² = 1664. Find Σx². [4]

Solution

  1. Σx = 16(28) = 448. Let y = x − 20, so ȳ = 128/16 = 8.
  2. Var(y) = 1664/16 − 8² = 104 − 64 = 40.
  3. The variances are equal, so 40 = Σx²/16 − 28².
  4. Add 28² to both sides: Σx²/16 = 40 + 784 = 824.
  5. Multiply both sides by 16: Σx² = 824(16) = 13 184.

Σx² = 13 184.

Worked example

Code raw values near 1000

The values are 998.5, 1001.2, 1000.3, 999.8, 1002.2 and 999.0. Use y = x − 1000 to find the mean and standard deviation of x.

Solution

  1. Coded values: −1.5, 1.2, 0.3, −0.2, 2.2, −1.0.
  2. Σy = −1.5 + 1.2 + 0.3 − 0.2 + 2.2 − 1.0 = 1.0, so ȳ = 1/6 ≈ 0.1667.
  3. Σy² = (−1.5)² + (1.2)² + (0.3)² + (−0.2)² + (2.2)² + (−1.0)² = 9.66.
  4. Var(y) = 9.66/6 − (1/6)² ≈ 1.5822.
  5. Use the unrounded variance expression: sd(y) = √(9.66/6 − (1/6)²) ≈ 1.26.
  6. x̄ = 1000 + 1/6 ≈ 1000.17 to 2 decimal places.
  7. sd(x) = sd(y) ≈ 1.26 to 3 significant figures.

The mean is approximately 1000.17 and the standard deviation is approximately 1.26.

Adding 1000 restores the mean only.

Worked example

Recover a positive coded sum

For 30 values, y = x − 40, Σy² = 1350 and sd(x) = 3. Given Σy is positive, find Σy and x̄. [4]

Solution

  1. Var(y) = Var(x) = 3² = 9.
  2. 9 = 1350/30 − (Σy/30)².
  3. (Σy/30)² = 45 − 9 = 36.
  4. The stated positive sign gives Σy/30 = 6, so Σy = 180.
  5. x̄ = ȳ + 40 = 6 + 40 = 46.

Σy = 180 and x̄ = 46.

A squared equation has two roots. Use the stated sign.

Your turn · 2

Twenty new values are coded by y = x − 200. If Σy = 60 and Σy² = 500, what is the standard deviation of x?

Worked example

Add one new monthly price

Seven monthly prices have mean 250. One new price is added and the mean of all eight prices becomes 245. Find the new price. [2]

Solution

  1. Convert the old mean to a total: 7(250) = 1750.
  2. Convert the new mean to a total: 8(245) = 1960.
  3. Subtract: 1960 − 1750 = 210.

The new price is 210.

Check: (1750 + 210)/8 = 245. Convert each mean to its total before subtracting.
