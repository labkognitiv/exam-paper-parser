Mathematics 9709 · Mechanics 1

Connected motion to free flight

Split a journey at the event, then carry event speed and height into a new model.

Set upWorked examplesChecksRecap

Two particles can share a string for one stage, then one can continue alone after the string becomes slack or another particle reaches the floor.

Two stages, one event

  • A light inextensible string has negligible mass and fixed length. While it is taut, connected particles have equal speed magnitudes and equal acceleration magnitudes.
  • A smooth fixed pulley changes direction without friction, so the tension is the same through the string.
  • At the event, the floor is hit or the string becomes slack. Freeze speed, time and height there.
  • After the event, the free particle moves under gravity only. With upward positive and g=10, use a=−10 m s⁻².
  • Use a fresh Stage 2 clock if helpful: its initial velocity is the event velocity and its initial position is event height. Add stage times only at the end.

Event method

  1. Name the connected stage and set its initial values.
  2. Use SUVAT to find event speed, event time and event height.
  3. Start a new SUVAT line after the event.
  4. At the apex set v=0. Distinguish extra rise after the event from total height above the floor.

Worked examples

Worked example · event to apex

Two particles start from rest. Connected acceleration is 2 m s−2. After 1.5 s one hits the floor and the other rises freely.

  1. v=0+2(1.5)=3 m s−1.
  2. Stage 2: u=3, v=0, a=−10.
  3. 0=3²+2(−10)s=9−20s; 20s=9 ⇒ s=0.45 m extra rise.
  4. Stage 1 rise is ½(2)(1.5²)=2.25 m, so total above release point is 2.25+0.45=2.70 m.

Greatest height = 2.70 m.

Worked example · extra rise

At slack, upward speed is 4 m s−1. Find extra height. For 2.5 m s−1, repeat the same method.

  1. 0=4²−20s ⇒ 20s=16 ⇒ s=0.8 m.
  2. For 2.5: 0=2.5²−20s ⇒ s=6.25/20=0.3125≈0.313 m.

Extra rises: 0.8 m and 0.313 m.

Worked example · total time

Connected for 0.8 s, event speed 3.2 m s−1, then free flight to apex.

  1. 0=3.2−10t2 ⇒ 10t2=3.2 ⇒ t2=0.32 s.
  2. ttotal=0.8+0.32=1.12 s.

Total time = 1.12 s.

Worked example · height above floor

At the event, height is 1.6 m and upward speed is 3 m s−1.

  1. 0=3²−20s ⇒ s=0.45 m extra.
  2. H=1.6+0.45=2.05 m above floor.

Greatest height = 2.05 m.

Worked example · return to level

After slack, upward speed is 2.4 m s−1. Find return time and speed at the same level.

  1. 0=2.4t−5t²=t(2.4−5t), so t=0 or t=0.48 s. Reject the starting root.
  2. v=2.4−10(0.48)=−2.4; speed is 2.4 m s−1 downward.

Return time 0.48 s; speed 2.4 m s−1.

Worked example · velocity-time graph

Connected motion reaches speed 3 m s−1 at t=0.6 s, then free flight begins.

  • Gradient 0 to 0.6 is 5 m s−2; after the event it is −10 m s−2.
  • Apex at t=0.6+3/10=0.9 s.

Worked example · height above floor

At slack, height is 1.2 m and upward speed 2.8 m s−1.

  1. 0=2.8²−20s ⇒ 20s=7.84 ⇒ s=0.392 m.
  2. H=1.2+0.392=1.592 m.

Greatest height = 1.59 m to 3 s.f.

Worked example · connected then free

Connected stage: upward acceleration 4 m s−2 for 0.5 s, then slack.

  1. v=0+4(0.5)=2 m s−1.
  2. 0=2²−20s ⇒ s=0.2 m.

Event speed 2 m s−1; extra rise 0.2 m.

Key ideas

  1. Use shared magnitudes only while the light inextensible string is taut.
  2. Freeze event speed, time and height, then start a fresh free-flight model.
  3. For upward free flight, a=−g and apex v=0.
  4. Reject the t=0 root when finding a later return.
  5. Add extra rise to event height for total height; add stage times at the end.
