Return to O and total distance

Find when a particle returns to its start, then measure every part of its journey.

Start the lesson
SetupWorked examplesKey ideas

Before you calculate

  • Let s(t) be displacement from O at time t. Returning to O means s(t)=0.
  • The root t=0 is usually only the starting instant. Look for a later positive root in the stated domain.
  • Instantaneous rest means v(t)=0. A turning time is where velocity changes sign.
  • Total distance adds magnitudes of displacement changes on each interval: |Δs₁|+|Δs₂|+…. Displacement can cancel; distance cannot.
  • Integrate velocity to obtain position: s(t)=∫v(t)dt, including a constant chosen from the starting position.
  1. Build or integrate v(t) to get s(t).
  2. Solve v=0 for turns and s=0 for returns.
  3. Keep roots inside the time interval and split at turns.
  4. Evaluate position at each boundary and add absolute changes.

Worked examples

Worked example

Return to O

A particle starts from O with v=12t−3t². Find when it returns.

  1. s=∫(12t−3t²)dt=6t²−t³+C.
  2. At t=0, s=0, so C=0.
  3. Return means 0=6t²−t³=t²(6−t).
  4. Roots are t=0 and t=6. Ignore the starting root.

The particle returns to O at t = 6 s.

Worked example

Find the turn times

v=t²−6t+8=(t−2)(t−4).

  1. Set velocity to zero: (t−2)(t−4)=0.
  2. Turn times are t=2 and t=4. These split the motion into 0–2, 2–4 and 4 onward.

Worked example

Distance needs magnitudes

For v=t²−6t+8, find distance from t=1 to t=5.

  1. s=t³/3−3t²+8t.
  2. s(1)=16/3, s(2)=20/3, s(4)=16/3, s(5)=20/3.
  3. Distance is |20/3−16/3|+|16/3−20/3|+|20/3−16/3|=4m.

Total distance = 4 m.

Worked example

Unknown constant first

v=k(t²−4t+3). Displacement is 2 m at t=1 and 8 m at t=3.

  1. s=k(t³/3−2t²+3t)+C.
  2. At t=1,s=2: 2=(4/3)k+C. At t=3,s=8: 8=0k+C, so C=8.
  3. 2−8=(4/3)k, so k=−6(3/4)=−4.5.

k = −4.5.

Worked example

Build, then return

A particle starts from rest at O with acceleration a=6−2t. Find its return time.

  1. v=∫(6−2t)dt=6t−t²+C. Since it starts from rest, C=0.
  2. s=∫(6t−t²)dt=3t²−t³/3+D, and s(0)=0 gives D=0.
  3. 0=3t²−t³/3=t²(3−t/3), so later root t=9s.

Return time = 9 s.

Key ideas

  • A positive-to-negative change in velocity gives a local maximum of displacement. Compare that candidate with domain endpoints and any other turns before choosing the greatest displacement.
  • For piecewise velocity, integrate each phase with its own limits.
  • Use position differences and absolute values for distance.
  • Signed displacement may be zero when the particle returns, while total distance remains positive.

Worked example

Maximum displacement

For v=12t−3t², the first rest time solves 3t(4−t)=0, so t=4. Then s=6t²−t³ gives s(4)=96−64=32m.

Greatest displacement = 32 m.

Worked example

Piecewise distance

v=2t for 0≤t≤4, then v=24−4t for 4≤t≤8.

  1. Phase 1 distance: ∫₀⁴2t,dt=16m.
  2. Phase 2 crosses zero at t=6. Distance 4–6 is 8 m and 6–8 is 8 m.
  3. Total distance = 16+8+8=32 m.

Worked example

Try it yourself

v=10t−2t². Return means s=5t²−2t³/3=0, so t²(5−2t/3)=0.

  1. Roots are t=0 and t=7.5.
  2. Ignore the starting root. Return time = 7.5 s.

Worked example

Watch the signs

For v=t²−6t+8 from t=1 to 5, a single integral gives displacement 4/3m, not distance.

  1. Turning times are 2 and 4.
  2. Interval changes are each 4/3 m in magnitude.
  3. Total distance = 4 m.

Worked example

Exam-style return and maximum

v=15t−3t². Find return time and greatest displacement.

  1. s=15t²/2−t³. Set s=0: t²(7.5−t)=0, so return at t=7.5s.
  2. Set v=0: 3t(5−t)=0, so the turn is t=5.
  3. s(5)=7.5(25)−125=62.5m.

Return at 7.5 s; greatest displacement = 62.5 m.

Worked example

Exam-style total distance

v=t²−5t+4 from t=0 to 5. Rest times are 1 and 4.

  1. s=t³/3−2.5t²+4t.
  2. s(0)=0,s(1)=11/6,s(4)=−8/3,s(5)=−5/6.
  3. distance=11/6+9/2+11/6=49/6m.

Total distance = 49/6 m.
