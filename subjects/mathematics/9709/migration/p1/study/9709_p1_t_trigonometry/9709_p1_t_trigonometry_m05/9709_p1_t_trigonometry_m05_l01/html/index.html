When a trig equation has no solution

Use a range, a discriminant, or a special boundary value to decide how many angles can work.

1. Two tools before you start

  • In aX²+bX+c=0, the numbers a, b and c are coefficients; a must not be zero. X is the value we are finding. A root is a value of X that makes the equation true.
  • The quadratic formula is X = (−b ± √D)/(2a). The ± symbol asks for both signs. When D is positive there are two roots; when D is zero both signs give the same root. A negative number has no real square root.
  • A real number lies on the ordinary number line. A distinct solution is counted once, even if algebra produces it twice.

A discriminant is the expression D = b² − 4ac for a quadratic aX² + bX + c = 0. It counts real values of X:

  • D > 0: two distinct real X-values.
  • D = 0: one repeated real X-value.
  • D < 0: no real X-value.

In a trigonometric equation, X is often sin θ, cos θ, or tan θ. Always check which real X-values are allowed: −1 ≤ sin θ, cos θ ≤ 1; 0 ≤ sin² θ, cos² θ ≤ 1; tan θ may be any real number.

A range is every output a function can take. For example, if 3 ≤ f(x) ≤ 11, then f(x)=k has no solution when k<3 or k>11. For an unrestricted real angle, a real tangent value always corresponds to an angle. A restricted angle interval still needs checking, even when the quadratic has real roots. For X=cos² θ, a real root still has to lie in [0,1].

The reversed question is common: “For which k are there no solutions?” Find a range or force D<0, then state the strict inequality clearly.

2. Method 1: use the range

For a sine or cosine expression, find its smallest and largest values first.

  1. Use −1≤sin x,cos x≤1 to find the extrema.
  2. Write the full range m≤f(x)≤M.
  3. Values k<m or k>M cannot be reached.

Worked example 1

Question: For f(x)=7−4 cos x, 0°≤x≤360°, find k for which f(x)=k has no solution.

  1. Since −1≤cos x≤1, multiplying by −4 reverses the endpoints: −4≤−4cos x≤4.
  2. Add 7: 3≤f(x)≤11. The minimum is 3 when cos x=1; the maximum is 11 when cos x=−1.
  3. Therefore no angle gives f(x)=k when k<3 or k>11.
Answer: k<3 or k>11.

3. Method 2: make a quadratic and use D

Replace the trig expression by one letter, compare with aX²+bX+c=0, and require D<0.

Worked example 2

Question: Find k so that 3tan²x−5tan x+k=0 has no real solution.

  1. Let X=tan x. There is no restriction such as −1≤X≤1.
  2. The quadratic is 3X²−5X+k=0, so a=3, b=−5, c=k.
  3. D=(−5)²−4(3)(k)=25−12k.
  4. No real X means D<0: 25−12k<0. Thus k>25/12.
Answer: k>25/12.

4. Real roots can still be invalid trig values

When X=cos²x, the allowed interval is 0≤X≤1. Check it after using the quadratic formula.

Worked example 3

Question: Show that 4cos⁴x+cos²x−k=0 has no solution when k>5.

  1. Let c=cos²x. Then 0≤c≤1 and the equation becomes 4c²+c−k=0.
  2. The roots are c=(−1±√(1+16k))/8. The minus root is negative whenever the roots are real, so it cannot be cos²x.
  3. The plus root becomes larger than 1 when (−1+√(1+16k))/8>1.
  4. Multiply by 8: √(1+16k)>9. Square both positive sides: 1+16k>81, so k>5.
  5. For k>5, the only possible root is above 1; every real root fails 0≤c≤1.
Answer: k>5.

5. A boundary value can give exactly three solutions

On 0°≤x≤180°, tan x=0 at both endpoints 0° and 180°. A second tan value inside the interval can therefore make three angles.

Worked example 4

Question: Find k so that 3tan²x−5tan x+k=0 has exactly three solutions for 0°≤x≤180°.

  1. Each nonzero tangent value gives exactly one angle in this interval. The value zero gives two, at the endpoints. A quadratic has at most two distinct roots, so three angles require a zero root. Substituting tan x = 0 gives k = 0. The equation then factors: tan x(3tan x−5)=0.
  2. From tan x=0, x=0° and x=180°, giving two endpoint solutions.
  3. From 3tan x−5=0, tan x=5/3, giving x≈59.0°. The other tangent angle is outside 0°≤x≤180°.
  4. There are 2+1=3 solutions. Thus k=0.
Answer: k=0; x=0°, about 59.0°, and 180°.

6. Three slips to avoid

  • Forgetting the trig range: a real root c=2 is not possible when c=cos²x. Reject it.
  • Confusing X with θ: D<0 says no real X, hence no angle only after the substitution and its allowed range are understood.
  • Using the wrong sign: no real roots means D<0. D=0 is one repeated root, not no solution.

Key ideas

  • Use a range when the expression’s extreme values are easy to find.
  • Use D<0 for no real quadratic value.
  • After substitution, enforce the natural trig range, especially 0≤sin²θ,cos²θ≤1.
  • For tangent on a closed 0° to 180° interval, tan x=0 occurs at both endpoints.

More worked examples

Example A: range

Question: Find k for which 5+2sin x=k has no solution, 0°≤x≤360°.

  1. −1≤sin x≤1, so −2≤2sin x≤2.
  2. Add 5: 3≤5+2sin x≤7.
  3. No solution when k<3 or k>7.

Example B: discriminant

Question: Find k so that 2tan²θ−3tan θ+k=0 has no solution.

  1. Let X=tan θ, which can be any real number.
  2. D=(−3)²−8k=9−8k.
  3. Set D<0: 9−8k<0, so k>9/8.

Example C: three solutions

Question: Find k for exactly three solutions of 2tan²x−3tan x+k=0 on 0°≤x≤180°.

  1. Two nonzero tangent roots give at most two angles here. Three angles require the zero tangent root, so substituting it gives k=0. Then tan x(2tan x−3)=0.
  2. tan x=0 gives x=0°,180°.
  3. tan x=3/2 gives x≈56.3° only within the interval.
  4. Total: three solutions, so k=0.

8. Exam-style practice, fully worked

Question 1

For f(x)=6−3cos x, 0°≤x≤360°, find k for which f(x)=k has no solution.

  1. −1≤cos x≤1 gives −3≤−3cos x≤3.
  2. Add 6: 3≤f(x)≤9.
  3. Therefore k<3 or k>9.
Answer: k<3 or k>9.

Question 2

For 4cos⁴x+cos²x−k=0: (i) show there is no solution when k>5; (ii) find k for exactly three distinct solutions in 0°≤x≤360°.

  1. Put c=cos²x, so 0≤c≤1. Then 4c²+c−k=0.
  2. The roots are c=(−1±√(1+16k))/8. The minus root is below 0; the plus root is above 1 precisely when k>5. Hence (i) no valid c exists for k>5.
  3. An interior value 0<c<1 gives four angles; c=0 gives two; c=1 gives three. The other quadratic root is negative for any valid c. Therefore exactly three angles require c=1. Then cos²x=1, so x=0°,180°,360°: three distinct angles in the closed interval.
  4. Substitute c=1 into 4c²+c−k=0: 4+1−k=0, hence k=5. The other root is −5/4, invalid.
(i) k>5 gives no solution. (ii) k=5 gives exactly three.
