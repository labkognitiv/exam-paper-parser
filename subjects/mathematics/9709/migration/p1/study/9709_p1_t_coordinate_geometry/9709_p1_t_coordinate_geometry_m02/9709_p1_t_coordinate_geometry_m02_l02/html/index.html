Quadrilaterals

Turn each shape property
into an equation.

A shape name gives you facts about its sides, angles or diagonals. Translate only those facts into distance, gradient and midpoint equations.

Start the lesson · Go to examples

First read the shape

  • A quadrilateral is a closed shape with four straight sides.
  • A corner is a vertex; more than one are vertices.
  • Two sides sharing a vertex are adjacent. Sides across from each other are opposite.
  • A diagonal joins two opposite vertices.
  • Letters in cyclic order follow the boundary: A to B to C to D and back to A.
  • Parallel lines keep the same direction and never meet. Their gradients are equal when both gradients are defined.
  • Perpendicular lines meet at 90°. For two non-vertical lines, their gradients multiply to -1.
  • To bisect a segment means to cut it into two equal parts. The cutting point is its midpoint.

Coordinate tools to recall

  • For points (x₁, y₁) and (x₂, y₂), subscripts 1 and 2 keep each point’s coordinates together.
  • Distance squared: d² = (x₂ - x₁)² + (y₂ - y₁)².
  • Midpoint: M = ((x₁ + x₂)/2, (y₁ + y₂)/2).
  • Gradient: m = (y₂ - y₁)/(x₂ - x₁), provided x₂ ≠ x₁.
  • If x₂ = x₁, the line is vertical and its gradient is undefined.

  • A kite’s symmetry diagonal is the one lying on that line.

  • Read the named property, select its row, write the equations it guarantees, then solve.

Worked example

A kite: use symmetry and perpendicular diagonals

Kite OABC has O(0, 0), A(0, 4) and C(8, 0). AC is its line of symmetry. OB is perpendicular to AC and is bisected by AC. Find the equations of AC and OB, then find B.

Solution

  1. Gradient of AC: m_AC = (0 - 4)/(8 - 0) = -1/2.
  2. AC passes through A(0, 4): y - 4 = -1/2(x - 0), so AC: y = -x/2 + 4.
  3. OB is perpendicular to AC. Its gradient is the negative reciprocal: m_OB = -1/(-1/2) = 2.
  4. OB passes through O(0, 0), so OB: y = 2x.
  5. At M, both equations give the same y-value: 2x = -x/2 + 4.
  6. Multiply by 2: 4x = -x + 8, so 5x = 8 and x = 8/5 = 1.6.
  7. Then y = 2(1.6) = 3.2, so M = (1.6, 3.2).
  8. Because M is the midpoint of OB and O = (0, 0), B is twice M.
  9. B = (3.2, 6.4).

A trapezium: combine three conditions

A(4, 0), B(0, 2) and C(h, 3h) are vertices of trapezium ABCD. BC is parallel to AD, angle ABC is 90°, and CD is parallel to the x-axis. Find h and D.

Solution

  1. m_AB = (2 - 0)/(0 - 4) = -1/2.
  2. Angle ABC is 90°, so BC is perpendicular to AB. Therefore m_BC = 2.
  3. BC has the finite gradient 2, so its horizontal change h cannot be zero.
  4. Using B(0, 2) and C(h, 3h): m_BC = (3h - 2)/h.
  5. Set this equal to 2: 3h - 2 = 2h, so h = 2 and C = (2, 6).
  6. CD is horizontal, so D has the same y-coordinate as C: y_D = 6.
  7. AD is parallel to BC, so m_AD = 2.
  8. With A(4, 0) and D(x_D, 6): 6/(x_D - 4) = 2.
  9. 6 = 2(x_D - 4), so x_D = 7.
  10. D = (7, 6).

A parallelogram: use the shared diagonal midpoint

A(1, 2), B(5, 4) and C(7, 8) are consecutive vertices of parallelogram ABCD. Find D.

  • Consecutive means next to each other around the boundary.
  • In cyclic order ABCD, A and C are opposite, while B and D are opposite.
  • The diagonals are therefore AC and BD.

Solution

  1. Midpoint of AC: M_AC = ((1 + 7)/2, (2 + 8)/2) = (4, 5).
  2. Write D = (x_D, y_D). Then M_BD = ((5 + x_D)/2, (4 + y_D)/2).
  3. The diagonals bisect each other, so M_BD = M_AC.
  4. (5 + x_D)/2 = 4 gives 5 + x_D = 8, so x_D = 3.
  5. (4 + y_D)/2 = 5 gives 4 + y_D = 10, so y_D = 6.
  6. D = (3, 6).

Rectangle and square

  • A rectangle is a parallelogram with four right angles.
  • Proving one corner of a parallelogram is 90° is enough: its parallel sides force all four corners to be 90°.
  • A square is a rectangle whose four sides are equal.
  • So a square has every rectangle property, plus four equal sides.

Worked example

Find the fourth vertex, then classify

A(0, 0), B(4, 0) and C(4, 3) are consecutive vertices of rectangle ABCD. Find D and decide whether ABCD is a square.

Solution

  1. Midpoint of AC is ((0 + 4)/2, (0 + 3)/2) = (2, 1.5).
  2. Set the midpoint of BD equal to (2, 1.5): ((4 + x_D)/2, y_D/2) = (2, 1.5).
  3. This gives x_D = 0 and y_D = 3, so D = (0, 3).
  4. AB is horizontal and BC is vertical, so AB is perpendicular to BC.
  5. AB = 4 and BC = 3. Adjacent sides are unequal.
  6. ABCD is a rectangle, but it is not a square.

Worked example

  • A rhombus is a parallelogram with all four sides equal.
  • Its diagonals are perpendicular and bisect each other.
  • If its diagonal lengths are d₁ and d₂, its area is half their product.

Area of a rhombus

Area = 1/2 d₁d₂

The subscripts only distinguish the two diagonal lengths.

Worked example

Verify a rhombus and find its area

P(0, 0), Q(4, 3), R(7, 7) and S(3, 4) are in cyclic order.

Solution

  1. PQ² = (4 - 0)² + (3 - 0)² = 25.
  2. QR² = (7 - 4)² + (7 - 3)² = 25.
  3. RS² = (3 - 7)² + (4 - 7)² = 25.
  4. SP² = (0 - 3)² + (0 - 4)² = 25.
  5. All four sides have length 5.
  6. Diagonals are PR and QS. m_PR = (7 - 0)/(7 - 0) = 1.
  7. m_QS = (4 - 3)/(3 - 4) = -1.
  8. The product is -1, so the diagonals are perpendicular.
  9. M_PR = ((0 + 7)/2, (0 + 7)/2) = (3.5, 3.5).
  10. M_QS = ((4 + 3)/2, (3 + 4)/2) = (3.5, 3.5).
  11. The midpoints coincide, so the diagonals bisect each other.
  12. Therefore PQRS is a rhombus.
  13. PR² = (7 - 0)² + (7 - 0)² = 98, so PR = 7√2.
  14. QS² = (3 - 4)² + (4 - 3)² = 2, so QS = √2.
  15. The perpendicular, bisecting diagonals divide the rhombus into four right-angled triangles.
  16. Adding their areas gives half the product of the full diagonal lengths.
  17. Area = 1/2(7√2)(√2) = 7.
  18. PQRS is a rhombus and its area is 7.

Avoid three common slips

Kite sides

Incorrect: all four sides are equal.

Correct: two pairs of adjacent sides are equal. For kite ABCD, this might be AB = AD and CB = CD.

Kite diagonals

Incorrect: both diagonals bisect each other.

Correct: only the symmetry diagonal bisects the other diagonal.

Parallel to an axis

Incorrect: horizontal CD means x_C = x_D.

Correct: horizontal CD means y_C = y_D. A vertical segment would have equal x-coordinates.

Key ideas

  • Read vertices in cyclic order before choosing sides or diagonals.
  • Parallel sides give equal gradients; perpendicular sides give gradient product -1 when both gradients exist.
  • A parallelogram’s diagonals share a midpoint.
  • A rectangle adds right angles. A square also has four equal sides.
  • A rhombus has four equal sides and perpendicular diagonals.
  • A kite has two pairs of adjacent equal sides; only its symmetry diagonal bisects the other.
  • A trapezium guarantees one pair of opposite parallel sides.

Your turn · 1

Kite with a different symmetry diagonal

Kite OABC has O(0, 0), A(0, 6) and C(8, 0). AC is the symmetry diagonal and OB is perpendicular to AC. Find B.

Solution

  1. m_AC = (0 - 6)/(8 - 0) = -3/4.
  2. AC: y = -3x/4 + 6.
  3. The perpendicular gradient is 4/3, so OB: y = 4x/3.
  4. At M: 4x/3 = -3x/4 + 6.
  5. Multiply by 12: 16x = -9x + 72, so x = 72/25 = 2.88.
  6. Then y = 4(2.88)/3 = 3.84, so M = (2.88, 3.84).
  7. M is the midpoint of OB and O is the origin, so B = (5.76, 7.68).

Your turn · 2

A trapezium from height and direction

A(0, 0), B(6, 0). CD is parallel to AB and lies 3 units above it. D has x-coordinate 1, C is to the right of D, and CD = 4.

Solution

  1. AB lies on y = 0. The parallel segment CD is 3 units above it, so y_C = y_D = 3.
  2. D has x-coordinate 1, so D = (1, 3).
  3. CD has length 4 to the right, so x_C = 1 + 4 = 5.
  4. C = (5, 3) and D = (1, 3).

Your turn · 3

Missing parallelogram vertex

A(2, 1), B(7, 2), C(8, 6) are consecutive vertices of parallelogram ABCD. Find D.

Solution

  1. The diagonals are AC and BD.
  2. Midpoint of AC is ((2 + 8)/2, (1 + 6)/2) = (5, 3.5).
  3. Set midpoint of BD equal to this: ((7 + x_D)/2, (2 + y_D)/2) = (5, 3.5).
  4. 7 + x_D = 10 gives x_D = 3.
  5. 2 + y_D = 7 gives y_D = 5.
  6. D = (3, 5).

Exam-style · 1 · 7 marks

Kite equations and a missing vertex

Kite PQRS has symmetry diagonal QS. P is the origin, Q(0, 3), S(6, 0), and PR is perpendicular to QS. Find the equations of QS and PR, then find R.

Solution

  1. m_QS = (0 - 3)/(6 - 0) = -1/2.
  2. Through Q(0, 3): QS: y = -x/2 + 3.
  3. PR is perpendicular, so its gradient is 2. Through P(0, 0): PR: y = 2x.
  4. At intersection M: 2x = -x/2 + 3.
  5. Multiply by 2: 4x = -x + 6, so x = 6/5 = 1.2 and y = 2.4.
  6. QS bisects PR, so M is midpoint of P and R.
  7. R = 2M = (2.4, 4.8).

Exam-style · 2 · 7 marks

Trapezium with an unknown parameter

A(5, 0), B(0, 2), C(h, 4h). BC is parallel to AD, angle ABC is 90°, and CD is horizontal. Find h and D.

Solution

  1. m_AB = (2 - 0)/(0 - 5) = -2/5.
  2. BC is perpendicular to AB, so m_BC = 5/2.
  3. BC has a finite gradient, so h ≠ 0.
  4. Using B and C: m_BC = (4h - 2)/h.
  5. (4h - 2)/h = 5/2. Hence 2(4h - 2) = 5h, so 3h = 4 and h = 4/3.
  6. Therefore C = (4/3, 16/3).
  7. CD is horizontal, so y_D = 16/3.
  8. AD is parallel to BC, so m_AD = 5/2.
  9. (16/3)/(x_D - 5) = 5/2.
  10. 32/3 = 5x_D - 25, so 5x_D = 107/3 and x_D = 107/15.
  11. D = (107/15, 16/3).
