Circle equations

Reveal the centre
by completing the square.

A circle in general form hides its centre and radius. Regroup the x-terms and y-terms, complete each square, and read the geometry from standard form.

Start the lesson · Go to exercises

Two forms of the same circle

Standard form

(x − a)² + (y − b)² = r²

The centre is (a, b) and the radius is r.

General form

x² + y² + Ax + By + C = 0

Here A, B and C are coefficients. A and B are not the centre coordinates.

  • The same letter can have a different job in a different formula. This lesson uses A, B, C for general-form coefficients and (a, b) for centre coordinates.
  • Complete the square to convert general form into standard form.
  • A real, nondegenerate circle needs r² > 0. If r² = 0, only one point remains. If r² < 0, there are no real points.

Mini example

Read the revealed form

x² + y² − 6x + 4y − 3 = 0 becomes (x − 3)² + (y + 2)² = 16.

Therefore the centre is (3, −2) and the radius is 4.

Alternative coefficient notation

Some questions write x² + y² + 2gx + 2fy + c = 0.

After completing the squares, the centre is (−g, −f) and r² = g² + f² − c.

The letters g and f are coefficients. Their signs flip when you read the centre.

Complete one square at a time

To complete a square, halve the coefficient of x, put the result inside a bracket, then subtract the square you added:

x² + kx = (x + k/2)² − (k/2)²

Worked example

Convert to standard form

Find the centre and radius of x² + y² − 6x + 4y − 3 = 0.

Solution

  1. Move the constant and group like terms: (x² − 6x) + (y² + 4y) = 3.
  2. Half −6 to get −3: x² − 6x = (x − 3)² − 9.
  3. Half 4 to get 2: y² + 4y = (y + 2)² − 4.
  4. Substitute: (x − 3)² − 9 + (y + 2)² − 4 = 3.
  5. Add 13 to both sides: (x − 3)² + (y + 2)² = 16.
  6. Since 16 > 0, this is a circle. Centre (3, −2), radius 4.

Two more worked examples

Worked example · 1

Both signs matter

Find the centre and radius of x² + y² − 8x + 4y − 5 = 0.

Solution

  1. (x² − 8x) + (y² + 4y) = 5.
  2. (x − 4)² − 16 + (y + 2)² − 4 = 5.
  3. (x − 4)² + (y + 2)² = 25.
  4. Centre (4, −2), radius 5.

Worked example · 2

A positive x coefficient

Find the centre and radius of x² + y² + 6x − 2y − 26 = 0.

Solution

  1. (x² + 6x) + (y² − 2y) = 26.
  2. (x + 3)² − 9 + (y − 1)² − 1 = 26.
  3. (x + 3)² + (y − 1)² = 36.
  4. Centre (−3, 1), radius 6.

Extreme points and axis crossings

  • Highest: (a, b + r).
  • Lowest: (a, b − r).
  • Leftmost: (a − r, b).
  • Rightmost: (a + r, b).
  • For x-axis crossings, every point has y = 0. Substitute y = 0 and solve the quadratic in x.
  • For y-axis crossings, every point has x = 0. Substitute x = 0 and solve the quadratic in y.

Worked example · x-axis crossings

The circle is x² + y² − 4x + 6y − 77 = 0. Find the x-coordinates where it meets the x-axis.

Solution

  1. On the x-axis, y = 0: x² − 4x − 77 = 0.
  2. We need two numbers with product −77 and sum −4: −11 and 7.
  3. (x + 7)(x − 11) = 0.
  4. x = −7 or x = 11.

Worked example · lowest point

Find the centre, radius and lowest point of x² + y² + 6x − 2y − 26 = 0.

Solution

  1. Complete both squares: (x + 3)² + (y − 1)² = 36.
  2. The centre is (−3, 1), r² = 36 and r = 6.
  3. Lowest point = (a, b − r) = (−3, 1 − 6).
  4. Centre (−3, 1), radius 6, lowest point (−3, −5).

You do not need the centre to find an axis crossing. Substitute the fixed coordinate straight into the general form.

Build a circle from conditions

When the centre is not given, each independent clue gives an equation. Two unknowns need two equations.

Two points and a line containing the centre

  1. The centre is equally far from both points, so it lies on their perpendicular bisector.
  2. Find the midpoint and perpendicular gradient to form that bisector.
  3. Intersect it with the given line to find centre (a, b).
  4. Find r² as the distance squared from the centre to either point.
  5. Write the standard form.

Two points and a fixed constant

  1. Start with x² + y² + Ax + By + C = 0, where C is given.
  2. Substitute each point to get two equations in A and B.
  3. Solve them simultaneously.
  4. Centre = (−A/2, −B/2).
  5. r² = (A/2)² + (B/2)² − C.

Worked examples from conditions

Worked example · 1

Centre on a given line

A(−7, 3) and B(5, 11) lie on a circle whose centre lies on 12x − 5y = 70. Find the circle.

Solution

  1. Midpoint of AB: M = ((−7 + 5)/2, (3 + 11)/2) = (−1, 7).
  2. m_AB = (11 − 3)/(5 − (−7)) = 8/12 = 2/3.
  3. The perpendicular gradient is −3/2.
  4. Through M: y − 7 = −3/2(x + 1), so the perpendicular bisector is 3x + 2y = 11.
  5. The centre lies on both 3x + 2y = 11 and 12x − 5y = 70.
  6. From the first, y = 11/2 − 3x/2. Substitute: 12x − 5(11/2 − 3x/2) = 70.
  7. Multiply by 2: 24x − 55 + 15x = 140, so 39x = 195 and x = 5.
  8. Then y = 11/2 − 15/2 = −2. Centre = (5, −2).
  9. Using B, r² = (5 − 5)² + (11 − (−2))² = 169.
  10. (x − 5)² + (y + 2)² = 169.

Worked example · 2

Find two coefficients

The circle x² + y² + ax + by − 12 = 0 passes through A(1, 1) and B(2, −6). Here a and b are reused as coefficients, so the centre will be (−a/2, −b/2).

Solution

  1. Substitute A: 1 + 1 + a + b − 12 = 0, so a + b = 10.
  2. Substitute B: 4 + 36 + 2a − 6b − 12 = 0, so 2a − 6b = −28 and a − 3b = −14.
  3. Subtract the second equation from the first: (a + b) − (a − 3b) = 10 − (−14).
  4. 4b = 24, so b = 6. Then a = 10 − 6 = 4.
  5. Centre = (−a/2, −b/2) = (−4/2, −6/2).
  6. a = 4, b = 6, centre (−2, −3).

Quick check · 2

For x² + y² + 2x − 4y − 12 = 0, what equation remains when finding y-axis crossings?

Key ideas

  • Complete the x-square and y-square separately.
  • In standard form, bracket signs reverse when you read the centre.
  • Check r² > 0 for a real, nondegenerate circle.
  • Extreme points move one radius horizontally or vertically from the centre.
  • Set y = 0 on the x-axis and x = 0 on the y-axis.
  • A centre equidistant from two points lies on their perpendicular bisector.
  • When a and b are coefficients, the centre is (−a/2, −b/2).

Your turn

Your turn · 1

For x² + y² − 10x + 4y + 13 = 0, find the centre, radius and lowest point.

Solution

  1. (x² − 10x) + (y² + 4y) = −13.
  2. (x − 5)² − 25 + (y + 2)² − 4 = −13.
  3. (x − 5)² + (y + 2)² = 16.
  4. Centre = (5, −2), r = 4.
  5. Lowest point = (5, −2 − 4). Answer: centre (5, −2), radius 4, lowest point (5, −6).

Your turn · 2

For x² + y² − 4x + 6y + 5 = 0, find the y-coordinates where the circle meets the y-axis.

Solution

  1. On the y-axis, x = 0: y² + 6y + 5 = 0.
  2. (y + 1)(y + 5) = 0.
  3. y = −1 or y = −5.

Your turn · 3

The circle x² + y² + ax + by − 9 = 0 passes through A(3, 0) and B(0, −1). Find a, b and the centre.

Solution

  1. Substitute A: 9 + 3a − 9 = 0, so 3a = 0 and a = 0.
  2. Substitute B: 1 − b − 9 = 0, so −b = 8 and b = −8.
  3. Centre = (−a/2, −b/2) = (0, 4).
  4. a = 0, b = −8, centre (0, 4).

Exam-style practice

Exam-style · 1 · 7 marks

A(0, 0) and B(8, 4) lie on a circle whose centre lies on x + y = 5. Find the circle.

Solution

  1. Midpoint M = ((0 + 8)/2, (0 + 4)/2) = (4, 2).
  2. m_AB = (4 − 0)/(8 − 0) = 1/2, so the perpendicular gradient is −2.
  3. Perpendicular bisector: y − 2 = −2(x − 4), so y = −2x + 10 and 2x + y = 10.
  4. The centre also lies on x + y = 5.
  5. Subtract x + y = 5 from 2x + y = 10: x = 5. Then y = 0.
  6. Centre = (5, 0). Using A, r² = (0 − 5)² + (0 − 0)² = 25.
  7. (x − 5)² + y² = 25.

Exam-style · 2 · 4 marks

The circle x² + y² + ax + by = 0 passes through A(2, 6) and B(8, 0). Find a, b and the centre.

Solution

  1. Substitute A: 4 + 36 + 2a + 6b = 0, so a + 3b = −20.
  2. Substitute B: 64 + 8a = 0, so a = −8.
  3. Then −8 + 3b = −20, so 3b = −12 and b = −4.
  4. Centre = (−a/2, −b/2) = (4, 2).
  5. a = −8, b = −4, centre (4, 2).
