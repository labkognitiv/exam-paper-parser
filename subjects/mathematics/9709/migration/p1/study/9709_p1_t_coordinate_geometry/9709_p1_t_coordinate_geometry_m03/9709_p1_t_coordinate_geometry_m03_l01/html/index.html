Line meets curve

Count intersections with algebra.

Replace y in the curve by the line expression. The real solutions for x tell you where the two graphs meet.

Start the lesson

Turn two equations into one

  • For a straight line, use m for its gradient and c for its y-intercept, where it crosses the y-axis.
  • The line can then be written y = mx+c.
  • A curve has a non-linear equation, such as one containing x², a fraction in x, or √x.
  • At an intersection, the line and curve have the same x-coordinate and the same y-coordinate.
  • Substitute means replace one expression by an equal expression.
  • A root is a solution for x: an x-value that makes an equation equal zero.
  • The domain is the set of x-values allowed by the original equations.

Worked example

Substitute a line into a parabola

The curve is y=x²−4x+3. The line is y=2x−6.

Solution

  1. Both right sides equal y, so set them equal:

    2x−6 = x²−4x+3

  2. Subtract 2x−6 from both sides:

    x²−6x+9 = 0

  3. Factor and solve:

    x²−6x+9=(x−3)²=0 ⇒ x=3

  4. The root x=3 occurs twice. Substitute into the line: y=2(3)−6=0. At (3,0), the line touches the curve locally in the same direction. This is called tangent contact.

  • A real root is a root on the real number line. Two distinct real roots are two different x-values, so they give two intersection points.
  • A repeated root occurs twice. For example, (x−3)²=0 gives x=3 twice.
  • At that repeated root, the line touches the curve locally in the same direction. This is a tangent contact.
  • No real roots mean the graphs do not meet.
  • This root count describes intersections only when the substituted equation remains valid in the original domain.

Use the discriminant for a genuine quadratic

  • A quadratic has the form Ax²+Bx+C=0 with A≠0.
  • Uppercase A, B, C below name quadratic coefficients. They are separate from a line’s lowercase c.
  • The discriminant is Δ=B²−4AC. The Greek letter Δ is read “delta”.
  • Its sign counts real roots without solving the quadratic.
Condition Roots Geometry
Δ>0 Two distinct real roots The line cuts the curve twice.
Δ=0 One repeated real root The line is tangent at one point.
Δ<0 No real roots The line misses the curve.

Tangent method

  1. Substitute the line into the curve and eliminate y.
  2. Rearrange to Ax²+Bx+C=0.
  3. Confirm A≠0 and keep all original domain restrictions.
  4. Set Δ=B²−4AC=0 and solve for the unknown line parameter.
  5. For a contact point, use the repeated root x=−B/(2A), then substitute for y.

Find the line parameter first. Find the contact point second.

Find a line that is tangent

Worked example

Horizontal tangent to a rational curve

The curve is y=(3x+1)/(x²−x). A horizontal line y=c is tangent. Find c.

Solution

  1. The denominator requires x≠0,1.

  2. Substitute and multiply by x²−x:

    c=(3x+1)/(x²−x) ⇒ c(x²−x)=3x+1

  3. Collect terms:

    cx²−(c+3)x−1 = 0

  4. Test c=0 before using a quadratic rule. It gives −3x−1=0, so x=−1/3 and y=0. This is one crossing of the rational curve, not a tangent.

  5. For c≠0 this is a genuine quadratic:

    Δ=(c+3)²+4c = c²+10c+9

  6. Set Δ=0 and factor:

    c²+10c+9 = (c+1)(c+9) = 0

  7. For c=−1, the quadratic is −(x+1)²=0, so x=−1. For c=−9, it is −(3x−1)²=0, so x=1/3. Both roots meet x≠0,1.

    c=−1 at x=−1, or c=−9 at x=1/3

Worked example

Two slanted tangents

The line y=mx−6 is tangent to y=x²−4x+3. Find m and each contact point.

Solution

  1. mx−6=x²−4x+3 ⇒ x²−(4+m)x+9=0
  2. Δ=(4+m)²−36=0
  3. (4+m)²=36 ⇒ 4+m=±6
  4. m=2 or m=−10

  5. For m=2, the repeated root is x=3 and y=2(3)−6=0.

  6. For m=−10, the repeated root is x=−3 and y=−10(−3)−6=24.

    m=2 at (3,0), or m=−10 at (−3,24)

Build a tangent through a known point

Worked example

Through (0,−2)

A line through (0,−2) with gradient m is tangent to y=x²−2x+7.

Solution

  1. The line is y=mx−2.

  2. mx−2=x²−2x+7 ⇒ x²−(2+m)x+9=0
  3. (2+m)²−36=0 ⇒ (m+2)²=36
  4. m+2=±6 ⇒ m=4 or m=−8

  5. For m=4, x=3 and y=4(3)−2=10.

  6. For m=−8, x=−3 and y=−8(−3)−2=22.

    m=4 at (3,10), or m=−8 at (−3,22)

Worked example

A rational curve

The positive constant k makes y=kx−k tangent to y=−1/(2x). Find k and the contact point.

Solution

  1. The curve requires x≠0.

  2. kx−k=−1/(2x) ⇒ 2kx²−2kx+1=0
  3. Δ=(−2k)²−4(2k)(1)=4k(k−2)=0

  4. k=0 would remove the x² term and gives the line y=0, which never touches this curve. Also k is positive. Keep k=2.

  5. 4x²−4x+1=(2x−1)²=0 ⇒ x=1/2
  6. k=2, contact (1/2,−1)

Find a range for a miss or two cuts

  • “Find the set of values” usually asks for a range, so the discriminant condition becomes an inequality.
  • For no intersection use Δ<0.
  • For two distinct intersections use Δ>0.
  • For an upward-opening quadratic expression, its values are negative between its roots and positive outside them.
k²−144<0 −12<k<12
k²−144>0 k<−12 or k>12
(k−1)(k−9)<0 1<k<9
(k+1)(k+9)>0 k<−9 or k>−1

Worked example

A line that misses a rational curve

The curve is y=2x+12/x with x≠0. The line is y+x=k. Find k when they do not meet.

Solution

  1. y=k−x
  2. k−x=2x+12/x ⇒ 3x²−kx+12=0
  3. Δ=k²−144<0
  4. k²<144 ⇒ |k|<12
  5. −12<k<12

Worked example

Two intersections with xy=16

The line is y=−4x+c. Find c so it meets xy=16 twice.

Solution

  1. The curve requires x≠0.

  2. x(−4x+c)=16 ⇒ 4x²−cx+16=0
  3. Δ=c²−256>0
  4. (c−16)(c+16)>0
  5. c<−16 or c>16

A miss condition simplifies to (h−2)(h+6)<0. Which range works?

Find the actual intersection points

Worked example

Two points on a rational curve

y=2x+12/x meets y+x=15. Find both points.

Solution

  1. x≠0 and y=15−x.

  2. 15−x=2x+12/x ⇒ 3x²−15x+12=0
  3. x²−5x+4=(x−1)(x−4)=0

  4. x=1 gives y=14. x=4 gives y=11.

    (1,14) and (4,11)

Worked example

A hidden quadratic from a square root

y=3−2x meets y=4−3√x. Find both x-coordinates.

Solution

  1. The square root requires x≥0.

  2. 4−3√x=3−2x ⇒ 2x−3√x+1=0

  3. Let u=√x. Then u≥0 and x=u².

    2u²−3u+1=(2u−1)(u−1)=0

  4. u=1/2 or u=1; both meet u≥0.

  5. x=1/4 or x=1

Key ideas

  • Substitute the line into the curve to eliminate y.
  • Real x-roots count valid intersection points.
  • Use the discriminant only when the result is genuinely quadratic.
  • Δ=0: tangent. Δ<0: miss. Δ>0: two cuts.
  • Keep rational denominators non-zero.
  • Keep square-root inputs non-negative.
  • An equation gives isolated values; an inequality gives a range.
  • For points, solve x and then substitute back for y.

Your turn

Check an impossible tangent claim

The line y=mx+5 is claimed to be tangent to y=x²+1. Find possible real m.

Solution

  1. mx+5=x²+1 ⇒ x²−mx−4=0
  2. Δ=m²+16

  3. For every real m, m²≥0, so Δ≥16 and can never be zero.

    No real value of m

Your turn

Find a miss range

The line y=x+k does not meet y=x²+2x+4. Find k.

Solution

  1. x+k=x²+2x+4 ⇒ x²+x+(4−k)=0
  2. Δ=1−4(4−k)=4k−15<0
  3. 4k<15
  4. k<15/4

Your turn

Check a false two-intersection premise

The line y=2x−3 is claimed to cut y=x²−x+1 twice. Find the points if they exist.

Solution

  1. 2x−3=x²−x+1 ⇒ x²−3x+4=0
  2. Δ=9−16=−7<0

  3. The algebra contradicts the claim: there are no real intersections.

    No real intersection points

Your turn

Tangent to xy=2

The line y=mx−2 is tangent to xy=2. Find m.

Solution

  1. x≠0.

  2. x(mx−2)=2 ⇒ mx²−2x−2=0

  3. m=0 makes the equation linear and gives one crossing, not tangency. For a genuine quadratic:

    Δ=4+8m=0
  4. 8m=−4
  5. m=−1/2

Exam-style practice

Parameter in both equations

The line is y=6x−c and the curve is y=cx²+2x−3. The line is tangent. Find c and the contact point P. [6]

Solution

  1. Check c=0 separately: the “curve” becomes the line y=2x−3, which crosses y=6x at x=−3/4. It is not tangent.

  2. cx²+2x−3=6x−c ⇒ cx²−4x+(c−3)=0
  3. Δ=16−4c(c−3)=0
  4. 16−4c²+12c=0 ⇒ c²−3c−4=0
  5. c²−3c−4=(c−4)(c+1)=0

  6. For c=4, x=2/c=1/2 and y=6(1/2)−4=−1.

  7. For c=−1, x=2/c=−2 and y=6(−2)+1=−11.

    c=4, P(1/2,−1), or c=−1, P(−2,−11)

Exam-style practice

A rational curve that the line misses

The curve is y=(3x+1)/(x²−x). The line y=c does not intersect it. Find c. [6]

Solution

  1. The curve requires x≠0,1.

  2. c(x²−x)=3x+1 ⇒ cx²−(c+3)x−1=0

  3. c=0 gives the linear equation −3x−1=0, with x=−1/3, so the graphs cross. Exclude c=0 before using the discriminant.

  4. Δ=(c+3)²+4c=c²+10c+9<0
  5. (c+1)(c+9)<0
  6. −9<c<−1
