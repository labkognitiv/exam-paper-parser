Chords

Turn two crossings
into a chord.

Substitute a line into a circle to find its two intersection points. Those points are the chord endpoints, and their distance is the chord length.

Start the lesson · Go to examples

What is a chord?

  • A chord is a straight segment joining two points on a circle.
  • A line that crosses a circle twice is a secant. The part between its crossings is a chord.
  • For a nonvertical line written as y = mx + c, substitute its expression for y into the circle. This removes y.
  • The result is a quadratic in x. A root is a value that makes that quadratic equal zero.
  • The two roots give the x-coordinates of the endpoints A and B.
  • Substitute each x-value back into the line to get its y-coordinate.

Discriminant

For a genuine quadratic ax² + bx + c = 0, the leading coefficient must satisfy a ≠ 0.

The discriminant is Δ = b² − 4ac. It tells you how many real roots exist.

  • Δ > 0: two distinct roots, so the line cuts a chord.
  • Δ = 0: one repeated root, so the line is tangent and only touches once.
  • Δ < 0: no real roots, so the line misses the circle.

Find both endpoints

  1. Substitute the line into the circle.
  2. Expand and collect into ax² + bx + c = 0.
  3. Factor, or use the quadratic formula, to find both x-values.
  4. Put each x-value into the line equation to find y.

Worked example

The line y = 5x − 10 cuts the circle (x − 5)² + (y − 2)² = 13 at A and B. Find A and B.

Solution

  1. Substitute y = 5x − 10: (x − 5)² + (5x − 12)² = 13.
  2. Expand: x² − 10x + 25 + 25x² − 120x + 144 = 13.
  3. So 26x² − 130x + 156 = 0. Divide by 26: x² − 5x + 6 = 0.
  4. Factor: (x − 2)(x − 3) = 0, so x = 2 or x = 3.
  5. If x = 2, y = 0. If x = 3, y = 5.
  6. A = (2, 0), B = (3, 5), in either order.

You may substitute directly into a general-form circle. Conversion to standard form is unnecessary.

More endpoint examples

Worked example · 1

The circle (x + 1)² + (y − 2)² = 85 meets y = 3x − 20 at A and B. Find their coordinates.

Solution

  1. Substitute: (x + 1)² + (3x − 22)² = 85.
  2. Expand: x² + 2x + 1 + 9x² − 132x + 484 = 85.
  3. 10x² − 130x + 400 = 0, so x² − 13x + 40 = 0.
  4. (x − 8)(x − 5) = 0, so x = 8 or x = 5.
  5. Using y = 3x − 20 gives y = 4 or y = −5.
  6. A = (8, 4), B = (5, −5), in either order.

Worked example · 2

The circle (x − 1)² + (y + 4)² = 40 meets y = x − 9 at A and B. Find their coordinates.

Solution

  1. Substitute: (x − 1)² + (x − 5)² = 40.
  2. Expand: x² − 2x + 1 + x² − 10x + 25 = 40.
  3. 2x² − 12x − 14 = 0, so x² − 6x − 7 = 0.
  4. (x + 1)(x − 7) = 0, so x = −1 or x = 7.
  5. Using y = x − 9 gives y = −10 or y = −2.
  6. A = (−1, −10), B = (7, −2), in either order.

Find the chord length

Once A(x₁, y₁) and B(x₂, y₂) are known, their distance is the chord length. Subscripts keep the coordinates of each point together.

AB = √((x₂ − x₁)² + (y₂ − y₁)²)

Exact form means keep square roots rather than using a decimal.

The root-difference shortcut

  • The quadratic formula is x = (−b ± √(b² − 4ac))/(2a).
  • Vertical bars mean absolute value: the nonnegative size of a number. Thus |−3| = 3.
  • Subtract the two roots: |(−b + √Δ)/(2a) − (−b − √Δ)/(2a)| = |2√Δ/(2a)| = √Δ/|a|.
  • So their positive separation is |x₂ − x₁| = √Δ/|a|.
  • The shortcut needs a genuine quadratic, so a ≠ 0, and a non-vertical line with finite gradient m.
  • Define Δx = x₂ − x₁ and Δy = y₂ − y₁. These coordinate changes are different from the discriminant symbol Δ.
  • On y = mx + c, Δy = mΔx.
AB = √(1 + m²) · √Δ/|a|

Derivation: AB = √((Δx)² + (Δy)²) = √((Δx)² + (mΔx)²) = √(1 + m²)|Δx|, then use the root separation above.

Worked example · two routes

For A(2, 0), B(3, 5), line gradient 5 and quadratic x² − 5x + 6 = 0, find AB.

Solution

  1. Distance route: AB² = (3 − 2)² + (5 − 0)² = 26, so AB = √26.
  2. Shortcut route: Δ = (−5)² − 4(1)(6) = 1.
  3. AB = √(1 + 5²) · √1/|1| = √26.
  4. AB = √26.

Worked chord lengths

Worked example · 1

The line y = 5x − 10 meets (x − 5)² + (y − 2)² = 13 at A and B. Find the exact chord length.

Solution

  1. Substitution gives 26x² − 130x + 156 = 0, hence x² − 5x + 6 = 0.
  2. (x − 2)(x − 3) = 0, so x = 2 or 3.
  3. From y = 5x − 10, A = (2, 0), B = (3, 5).
  4. AB² = (3 − 2)² + (5 − 0)² = 1 + 25 = 26.
  5. AB = √26.

Worked example · 2

The line y = 2x + 5 meets x² + y² = 20 at A and B. Find both points and the exact chord length.

Solution

  1. Substitute: x² + (2x + 5)² = 20.
  2. Expand: 5x² + 20x + 5 = 0, so x² + 4x + 1 = 0.
  3. Quadratic formula: x = (−4 ± √(16 − 4))/2 = −2 ± √3.
  4. Using y = 2x + 5 gives y = 1 ± 2√3 with matching signs.
  5. A = (−2 + √3, 1 + 2√3), B = (−2 − √3, 1 − 2√3).
  6. Δx = −2√3 and Δy = −4√3.
  7. AB² = (−2√3)² + (−4√3)² = 12 + 48 = 60.
  8. AB = √60 = 2√15.

Special chord cases

Parallel to an axis

  • Parallel to the x-axis means y is constant along the chord.
  • Set y = k₀ and solve for the two x-coordinates.
  • Parallel to the y-axis means x is constant. Swap the roles of x and y.

A range of values

  1. Substitute the parameter line.
  2. Collect a genuine quadratic.
  3. For two distinct intersections, require Δ > 0.
  4. Solve the resulting inequality.

Worked special cases

Worked example · 1

Chord AB of (x − 2)² + y² = 8 is parallel to the x-axis. A lies on the positive y-axis. Find A and B.

Solution

  1. A is on the y-axis, so x = 0: (0 − 2)² + y² = 8.
  2. y² = 4. Since A is on the positive y-axis, y = 2. Thus A = (0, 2).
  3. AB is horizontal, so B also has y = 2.
  4. Substitute y = 2: (x − 2)² + 4 = 8, so (x − 2)² = 4.
  5. x = 0 or 4. The root x = 0 is A, so B = (4, 2).
  6. A = (0, 2), B = (4, 2).

Worked example · 2

Find k such that y = kx − 5 meets x² + y² + 6x − 2y − 26 = 0 at two distinct points.

Solution

  1. Substitute y = kx − 5.
  2. x² + (kx − 5)² + 6x − 2(kx − 5) − 26 = 0.
  3. Collect: (1 + k²)x² + (6 − 12k)x + 9 = 0. Since 1 + k² > 0, this is always a genuine quadratic.
  4. Require Δ > 0: (6 − 12k)² − 4(1 + k²)(9) > 0.
  5. Expand: 36 − 144k + 144k² − 36 − 36k² > 0.
  6. 108k² − 144k > 0, so 36k(3k − 4) > 0.
  7. The product is positive outside its roots 0 and 4/3.
  8. k < 0 or k > 4/3.

Key ideas

  • Substitute the line into the circle and solve the resulting quadratic.
  • Use each root in the line equation to recover the matching y-coordinate.
  • Δ > 0 gives a chord; Δ = 0 gives a tangent; Δ < 0 gives no real crossing.
  • Chord length is the distance between endpoints.
  • The shortcut needs finite gradient m and nonzero quadratic coefficient a.
  • Horizontal endpoints share y; vertical endpoints share x.

More worked examples

Your turn · 1

The line y = x + 3 cuts (x − 2)² + (y − 1)² = 25 at A and B. Find A and B.

Solution

  1. Substitute: (x − 2)² + (x + 2)² = 25.
  2. Expand: x² − 4x + 4 + x² + 4x + 4 = 25.
  3. 2x² = 17, so x = ±√(17/2).
  4. Using y = x + 3 gives y = 3 ± √(17/2), with matching signs.
  5. A = (√(17/2), 3 + √(17/2)), B = (−√(17/2), 3 − √(17/2)), in either order.

Your turn · 2

The line y = 2x + 1 cuts x² + y² = 10 at A and B. Find the exact length AB.

Solution

  1. Substitute: x² + (2x + 1)² = 10.
  2. 5x² + 4x − 9 = 0 = (5x + 9)(x − 1).
  3. x = −9/5 or 1. From y = 2x + 1, the endpoints are (−9/5, −13/5) and (1, 3).
  4. Δx = 14/5 and Δy = 28/5.
  5. AB² = (14/5)² + (28/5)² = 980/25 = 196/5.
  6. AB = 14/√5. Rationalising the denominator gives AB = 14√5/5.

Exam-style · 1 · 4 marks

Chord AB of (x − 3)² + (y − 5)² = 40 is parallel to the y-axis. A lies on the positive x-axis. Find A and B.

Solution

  1. A is on the x-axis, so y = 0: (x − 3)² + 25 = 40.
  2. (x − 3)² = 15, so x = 3 ± √15. Only 3 + √15 is positive.
  3. A = (3 + √15, 0).
  4. AB is vertical, so B has x = 3 + √15.
  5. Substitute: 15 + (y − 5)² = 40, so y = 0 or 10.
  6. A = (3 + √15, 0), B = (3 + √15, 10).

Exam-style · 2 · 7 marks

The line y = 4x − 3 cuts (x − 1)² + (y + 2)² = 34 at A and B. Find A, B and the exact chord length.

Solution

  1. Substitute: (x − 1)² + (4x − 1)² = 34.
  2. Expand: x² − 2x + 1 + 16x² − 8x + 1 = 34.
  3. 17x² − 10x − 32 = 0 = (17x + 16)(x − 2).
  4. x = −16/17 or 2.
  5. Using y = 4x − 3 gives A = (−16/17, −115/17) and B = (2, 5), in either order.
  6. Δx = 50/17 and Δy = 200/17.
  7. AB² = (50/17)² + (200/17)² = 42500/289.
  8. AB = √42500/17 = 50√17/17.
