The vertex is inside square form

Quick completing-the-square recap

x2+6x+5=(x+3)2−4x^2+6x+5=(x+3)^2-4x2+6x+5=(x+3)2−4

2x2+8x+3=2(x+2)2−52x^2+8x+3=2(x+2)^2-52x2+8x+3=2(x+2)2−5

  • A quadratic graph is a smooth U-shaped or upside-down U-shaped curve called a parabola.
  • The vertex, or turning point, is where it changes direction.
  • In y=a(x+h)2+ky=a(x+h)^2+ky=a(x+h)2+k, the square is zero when x+h=0x+h=0x+h=0, so x=−hx=-hx=−h.
  • The axis of symmetry is the vertical line that divides the graph into mirror halves. Here it is x=−hx=-hx=−h, through the vertex (−h,k)(-h,k)(−h,k).
  • The range is the set of possible yyy-values. If a>0a>0a>0, the curve opens upward, the vertex is a minimum and the range is y≥ky\ge ky≥k.
  • If a<0a<0a<0, it opens downward, the vertex is a maximum and the range is y≤ky\le ky≤k.
  • The vertical axis is the yyy-axis. Its crossing point is the yyy-intercept; set x=0x=0x=0 to find it.

Four facts from the form

  1. Vertex (−h,k)(-h,k)(−h,k).
  2. Axis x=−hx=-hx=−h.
  3. The sign of aaa gives the opening direction.
  4. The minimum or maximum yyy-value is kkk.

The bracket sign flips because the bracket must equal zero.

Find a vertex in four steps

  1. Write a(x+h)2+ka(x+h)^2+ka(x+h)2+k.
  2. Read h,kh,kh,k after simplifying.
  3. Write vertex (−h,k)(-h,k)(−h,k).
  4. Use the sign of aaa for minimum or maximum.

Build a useful sketch

  • A sketch shows correct features without requiring a measured scale.
  • The yyy-intercept is where the curve crosses the vertical axis; set x=0x=0x=0.
  • An xxx-intercept is where it crosses the horizontal axis; set y=0y=0y=0.
  • Find the vertex, axis, intercepts and opening direction.
  • An upward curve whose minimum is above the xxx-axis has no real xxx-intercepts.
  • A downward curve whose maximum is below the xxx-axis has no real xxx-intercepts.
  • Use straight axes, then draw one smooth symmetric curve.

Five-step sketch method

  1. Complete the square for the vertex.
  2. Set x=0x=0x=0 for the yyy-intercept.
  3. Set y=0y=0y=0 for real xxx-intercepts.
  4. Check whether the curve opens up or down.
  5. Plot and label; draw a smooth curve.

Use intersections to find coefficients

  • A coefficient is a number multiplying a variable term. In x2+ax+bx^2+ax+bx2+ax+b, aaa is the coefficient of xxx and bbb is the constant term.
  • A point (2,7)(2,7)(2,7) on y=x2+ax+by=x^2+ax+by=x2+ax+b gives 7=22+2a+b7=2^2+2a+b7=22+2a+b.
  • At an intersection, line and curve have the same xxx and yyy, so set their expressions equal.
  • Two equations in the same unknowns are simultaneous equations: solve them together so one pair satisfies both.

Small simultaneous-equation recap

2a+b=3,5a+b=122a+b=3,\qquad5a+b=122a+b=3,5a+b=12

Subtract whole equations: 3a=9,a=3,b=−3.3a=9,\qquad a=3,\qquad b=-3.3a=9,a=3,b=−3.

Five-step method

  1. Write line = curve.
  2. Substitute each given xxx.
  3. Make one equation from each value.
  4. Solve the pair together.
  5. Substitute back to check.

Worked example · curve meets a line

The curve y=x2+ax+by=x^2+ax+by=x2+ax+b meets y=2x+5y=2x+5y=2x+5 at x=1x=1x=1 and x=3x=3x=3. Find a,ba,ba,b.

Solution

  1. x2+ax+b=2x+5.x^2+ax+b=2x+5.x2+ax+b=2x+5.
  2. At x=1x=1x=1: a+b=6a+b=6a+b=6.
  3. At x=3x=3x=3: 3a+b=23a+b=23a+b=2.
  4. Subtract: 2a=−42a=-42a=−4, so a=−2a=-2a=−2.
  5. Then b=8b=8b=8.
  6. Check at x=3x=3x=3: curve =9−6+8=11=9-6+8=11=9−6+8=11; line =11=11=11.

Answer: a=−2,b=8a=-2, b=8a=−2,b=8.

Key ideas

  • From a(x+h)2+ka(x+h)^2+ka(x+h)2+k, read vertex (−h,k)(-h,k)(−h,k) and axis x=−hx=-hx=−h.
  • Positive aaa gives a minimum; negative aaa gives a maximum.
  • Sketch using the vertex, intercepts, symmetry and opening.
  • A point (r,s)(r,s)(r,s) means substituting x=rx=rx=r gives y=sy=sy=s.
  • At an intersection, line and curve have equal yyy-values.
  • Two unknown coefficients need two independent equations.
  • Check every given point or intersection.

Gradient measures the slope at a point: how much yyy changes as xxx increases there.

Watch out

  • At x=2x=2x=2, use x2=4x^2=4x2=4, not 2.
  • One point gives one equation; two unknowns need another independent condition.
  • When subtracting equations, subtract every term on both sides.
