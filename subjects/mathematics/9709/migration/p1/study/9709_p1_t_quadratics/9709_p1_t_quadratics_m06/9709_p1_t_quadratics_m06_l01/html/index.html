The discriminant

Count the real roots before solving.

One expression inside the quadratic formula tells you whether a quadratic has two real roots, one repeated root or no real roots.

Start with the quadratic formula

  • First write a quadratic equation in standard form: a x 2 + b x + c = 0 ax^2+bx+c=0 a x 2 + b x + c = 0 .
  • The letters a a a , b b b and c c c are coefficients. The coefficient ccc is the constant term, or the coefficient of 1.
  • The condition a ≠ 0 a\ne0 a  = 0 keeps the equation quadratic.
  • A root is an x-value that makes the equation true.
  • A real root is a root on the real number line.

The discriminant

The discriminant is the expression under the square root in the quadratic formula.

D = b 2 − 4 a c D=b^2-4ac D = b 2 − 4 a c
  • The capital letter D D D names the discriminant.
  • In b 2 b^2 b 2 , square the whole signed coefficient b b b .
  • The term 4 a c 4ac 4 a c means 4 × a × c 4\times a\times c 4 × a × c .
  • 9 = 3 \sqrt9=3 9 ​ = 3 and 0 = 0 \sqrt0=0 0 ​ = 0 are real.
  • The square root of a negative number is not real.

The sign decides the root pattern

Discriminant Square-root term Roots
D > 0 D>0 D > 0 Positive and negative choices differ Two distinct real roots
D = 0 D=0 D = 0 Both choices add or subtract zero One repeated real root
D < 0 D<0 D < 0 Square root is not real No real roots

See the three cases

  • The graph of a quadratic is a parabola.
  • A real root is an x-coordinate where the graph meets the x-axis.
  • Distinct means different. A repeated root occurs where the graph just touches the axis.

The method

  1. Write the equation as a x 2 + b x + c = 0 ax^2+bx+c=0 a x 2 + b x + c = 0 .
  2. Identify the signed coefficients a a a , b b b and c c c .
  3. Calculate D = b 2 − 4 a c D=b^2-4ac D = b 2 − 4 a c .
  4. Compare D D D with zero and state the root pattern.

Watch out

Translate the words first

No real roots means D < 0 D<0 D < 0 . Two distinct real roots means D > 0 D>0 D > 0 .

Square the signed coefficient

If b = − 6 b=-6 b = − 6 , then b 2 = ( − 6 ) 2 = 36 b^2=(-6)^2=36 b 2 = ( − 6 ) 2 = 36 , not -36.

Solve a quadratic inequality from its boundaries

For p 2 − 6 p + 1 < 0 p^2-6p+1<0 p 2 − 6 p + 1 < 0 , first solve the matching equation. The roots are 3 ± 2 2 3\pm2\sqrt2 3 ± 2 2 ​ ; the expression is negative between them.

Key ideas

  • Put the equation in the form a x 2 + b x + c = 0 ax^2+bx+c=0 a x 2 + b x + c = 0 , with a ≠ 0 a\ne0 a  = 0 .
  • Use the signed coefficients in D = b 2 − 4 a c D=b^2-4ac D = b 2 − 4 a c .
  • D > 0 D>0 D > 0 : two distinct real roots.
  • D = 0 D=0 D = 0 : one repeated real root.
  • D < 0 D<0 D < 0 : no real roots.
  • D ≥ 0 D\ge0 D ≥ 0 : real roots, including the repeated case.
  • If D D D contains a parameter, solve the resulting equation or inequality carefully.
