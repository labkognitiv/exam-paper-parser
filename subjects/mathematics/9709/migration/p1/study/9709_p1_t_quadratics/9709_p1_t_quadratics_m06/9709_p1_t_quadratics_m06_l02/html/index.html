Tangent lines and the discriminant

One contact point.
One repeated root.

Turn line meets curve into a quadratic. For a tangent, its discriminant must be zero.

Start the lesson

A tangent gives one repeated intersection

  • A tangent is a straight line with the same gradient as the curve at the contact point. For these quadratic graphs, it touches once.
  • The gradient is the slope of a line: the change in yyy for each unit increase in xxx.
  • A parameter is a letter such as kkk whose value changes the line or curve.
  • At an intersection, line and curve have the same xxx and yyy.
  • After rearranging to ax2+bx+c=0ax^2+bx+c=0ax2+bx+c=0, where a≠0a\ne0a=0, the coefficient bbb is the whole multiplier of xxx.
  • The discriminant is D=b2−4acD=b^2-4acD=b2−4ac. One repeated root means D=0D=0D=0.

The six-step method

  1. Set line equal to curve.
  2. Rearrange to ax2+bx+c=0ax^2+bx+c=0ax2+bx+c=0.
  3. Identify a,b,ca,b,ca,b,c from that new equation.
  4. Compute D=b2−4acD=b^2-4acD=b2−4ac.
  5. Choose the required condition: D=0D=0D=0 for one meeting, D>0D>0D>0 for two, or D<0D<0D<0 for none.
  6. For a tangent, use D=0D=0D=0 and solve for the parameter.

Master-method example

Find when y=x2+kx+4y=x^2+kx+4y=x2+kx+4 is tangent to y=2x+1y=2x+1y=2x+1.

Solution

  1. Set equal: x2+kx+4=2x+1x^2+kx+4=2x+1x2+kx+4=2x+1.
  2. Rearrange: x2+(k−2)x+3=0x^2+(k-2)x+3=0x2+(k−2)x+3=0.
  3. Here a=1a=1a=1, b=k−2b=k-2b=k−2, c=3c=3c=3.
  4. For tangency, (k−2)2−4(1)(3)=0.(k-2)^2-4(1)(3)=0.(k−2)2−4(1)(3)=0.
  5. So (k−2)2=12(k-2)^2=12(k−2)2=12, hence k−2=±23k-2=\pm2\sqrt3k−2=±23​.

Answer: k=2±23k=2\pm2\sqrt3k=2±23​.

Read the new coefficients carefully

Worked example 1

The line y=kx+1y=kx+1y=kx+1 is tangent to y=x2+4x+6y=x^2+4x+6y=x2+4x+6. Find kkk.

Solution

  1. x2+4x+6=kx+1x^2+4x+6=kx+1x2+4x+6=kx+1.
  2. x2+(4−k)x+5=0x^2+(4-k)x+5=0x2+(4−k)x+5=0, so a=1a=1a=1, b=4−kb=4-kb=4−k, c=5c=5c=5.
  3. (4−k)2−20=0.(4-k)^2-20=0.(4−k)2−20=0.
  4. 4−k=±254-k=\pm2\sqrt54−k=±25​.

Answer: k=4±25k=4\pm2\sqrt5k=4±25​.

Worked example 2 · parameter in the gradient

Find kkk if y=kx−2y=kx-2y=kx−2 is tangent to y=x2+2x+1y=x^2+2x+1y=x2+2x+1.

Solution

  1. x2+2x+1=kx−2x^2+2x+1=kx-2x2+2x+1=kx−2.
  2. x2+(2−k)x+3=0x^2+(2-k)x+3=0x2+(2−k)x+3=0.
  3. (2−k)2−12=0.(2-k)^2-12=0.(2−k)2−12=0.

Answer: k=2±23k=2\pm2\sqrt3k=2±23​.

Worked example 3 · non-monic curve

Find kkk if y=kx+1y=kx+1y=kx+1 is tangent to y=2x2−x+4y=2x^2-x+4y=2x2−x+4.

Solution

  1. 2x2+(−1−k)x+3=02x^2+(-1-k)x+3=02x2+(−1−k)x+3=0.
  2. (−1−k)2−4(2)(3)=0(-1-k)^2-4(2)(3)=0(−1−k)2−4(2)(3)=0.
  3. (k+1)2=24(k+1)^2=24(k+1)2=24.

Answer: k=−1±26k=-1\pm2\sqrt6k=−1±26​.

The parameter may change another coefficient

Worked example 4 · line intercept

Find kkk if y=2x+ky=2x+ky=2x+k is tangent to y=x2+4y=x^2+4y=x2+4.

Solution

  1. x2−2x+(4−k)=0x^2-2x+(4-k)=0x2−2x+(4−k)=0.
  2. Now c=4−kc=4-kc=4−k.
  3. (−2)2−4(1)(4−k)=0(-2)^2-4(1)(4-k)=0(−2)2−4(1)(4−k)=0, so 4−16+4k=04-16+4k=04−16+4k=0.

Answer: k=3k=3k=3.

Worked example 5 · curve coefficient

Find kkk if y=x2+kx+6y=x^2+kx+6y=x2+kx+6 is tangent to y=2x+2y=2x+2y=2x+2.

Solution

  1. x2+(k−2)x+4=0x^2+(k-2)x+4=0x2+(k−2)x+4=0.
  2. Now b=k−2b=k-2b=k−2.
  3. (k−2)2−16=0(k-2)^2-16=0(k−2)2−16=0, so k−2=±4k-2=\pm4k−2=±4.

Answer: k=6k=6k=6 or k=−2k=-2k=−2.

Three slips to avoid

Stopping at x2+4x+5=kxx^2+4x+5=kxx2+4x+5=kx.

Move every term: x2+(4−k)x+5=0x^2+(4-k)x+5=0x2+(4−k)x+5=0.

Reading b=kb=kb=k.

After rearranging, b=4−kb=4-kb=4−k.

Writing (k−2)2=k2−4(k-2)^2=k^2-4(k−2)2=k2−4.

Expand the whole bracket: (k−2)2=k2−4k+4(k-2)^2=k^2-4k+4(k−2)2=k2−4k+4.

Two tangents can pass through one external point

  • An external point is a point not on the curve. Here (0,−1)(0,-1)(0,−1) lies below the parabola.
  • A line through (0,−1)(0,-1)(0,−1) with gradient mmm has equation y=mx−1y=mx-1y=mx−1.
  • Set it equal to y=x2y=x^2y=x2: x2−mx+1=0x^2-mx+1=0x2−mx+1=0.
  • Tangency gives D=(−m)2−4(1)(1)=0D=(-m)^2-4(1)(1)=0D=(−m)2−4(1)(1)=0.
  • So m2=4m^2=4m2=4, giving two gradients and two tangent lines.

Two-tangent worked example

Find the two tangents to y=x2y=x^2y=x2 through (0,−1)(0,-1)(0,−1), then verify where they meet.

Solution

  1. Use y=mx−1y=mx-1y=mx−1.
  2. x2=mx−1x^2=mx-1x2=mx−1, so x2−mx+1=0x^2-mx+1=0x2−mx+1=0.
  3. D=m2−4=0D=m^2-4=0D=m2−4=0, hence m=2m=2m=2 or m=−2m=-2m=−2.
  4. The tangents are y=2x−1y=2x-1y=2x−1 and y=−2x−1y=-2x-1y=−2x−1.
  5. Set them equal: 2x−1=−2x−12x-1=-2x-12x−1=−2x−1, so x=0x=0x=0 and y=−1y=-1y=−1.

Answer: y=2x−1y=2x-1y=2x−1 and y=−2x−1y=-2x-1y=−2x−1; they meet at (0,−1)(0,-1)(0,−1).

A tangent to y=x2y=x^2y=x2 through (0,−2)(0,-2)(0,−2) is y=mx−2y=mx-2y=mx−2. What equation determines mmm?

Key ideas

  • Set line equal to curve, then move every term to one side.
  • Read a,b,ca,b,ca,b,c only after rearranging.
  • A tangent gives one repeated intersection, so use D=0D=0D=0.
  • A parameter can change the gradient, intercept or a curve coefficient.
  • A line through (0,q)(0,q)(0,q) with gradient mmm is y=mx+qy=mx+qy=mx+q.
  • Two values of mmm give two tangent lines.
  • Substitute back to check the contact or meeting point.

Your turn 4 · no real parameter

Could y=x2+kx+2y=x^2+kx+2y=x2+kx+2 be tangent to y=x+6y=x+6y=x+6 for a real value of kkk?

Solution

  1. x2+kx+2=x+6x^2+kx+2=x+6x2+kx+2=x+6.
  2. Correctly rearranged, x2+(k−1)x−4=0x^2+(k-1)x-4=0x2+(k−1)x−4=0.
  3. D=(k−1)2−4(1)(−4)=(k−1)2+16D=(k-1)^2-4(1)(-4)=(k-1)^2+16D=(k−1)2−4(1)(−4)=(k−1)2+16.
  4. This is positive for every real kkk, so it cannot equal zero.

Answer: No real value of kkk.

Exam-style two tangents [5]

The tangents from (0,−9)(0,-9)(0,−9) to y=x2y=x^2y=x2 are claimed to be y=6x−9y=6x-9y=6x−9 and y=−6x−9y=-6x-9y=−6x−9. Prove the claim and show where they meet.

Solution

  1. Let the line be y=mx−9y=mx-9y=mx−9.
  2. x2=mx−9x^2=mx-9x2=mx−9, so x2−mx+9=0x^2-mx+9=0x2−mx+9=0.
  3. D=m2−36D=m^2-36D=m2−36. Tangency requires m2−36=0m^2-36=0m2−36=0.
  4. Thus m=6m=6m=6 or m=−6m=-6m=−6, giving the claimed lines.
  5. 6x−9=−6x−96x-9=-6x-96x−9=−6x−9 gives x=0x=0x=0 and y=−9y=-9y=−9.

Answer: The two lines are tangents and meet at (0,−9)(0,-9)(0,−9).
