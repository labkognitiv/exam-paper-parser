Always-meets proofs

Turn meeting points
into roots.

One completed square can prove that a line and a curve meet for every allowed value of a parameter.

Start the proof

What must be proved?

  • An intersection is a point shared by two graphs. At that point, both equations have the same xxx and yyy values.
  • A parameter is a fixed but unspecified number, such as mmm. The proof must work for every permitted value.
  • Set the curve equal to the line. Each real solution for xxx gives an intersection.
  • For Ax2+Bx+C=0Ax^2+Bx+C=0Ax2+Bx+C=0 with A≠0A\ne0A=0, AAA is the coefficient of x2x^2x2, BBB is the coefficient of xxx, and CCC is the constant term. The discriminant is D=B2−4ACD=B^2-4ACD=B2−4AC.
  • D>0D>0D>0 gives two distinct intersections; D=0D=0D=0 gives one tangent point, where the line just touches the curve; D<0D<0D<0 gives none.
  • A square is non-negative: for every real uuu, u2≥0u^2\ge0u2≥0. Therefore u2+k≥ku^2+k\ge ku2+k≥k.

To prove at least one meeting, show D≥0D\ge0D≥0. If you show D>0D>0D>0, you have proved two distinct meetings.

The useful pattern is D=(something)2+positive numberD=(\text{something})^2+\text{positive number}D=(something)2+positive number.

The six-step proof

  1. Set the line and curve equations equal.
  2. Rearrange to Ax2+Bx+C=0Ax^2+Bx+C=0Ax2+Bx+C=0.
  3. Identify AAA, BBB and CCC. Check whether AAA can be zero.
  4. When A≠0A\ne0A=0, calculate D=B2−4ACD=B^2-4ACD=B2−4AC.
  5. Write DDD in completed-square form.
  6. Use square non-negativity, check any A=0A=0A=0 case directly, and state the conclusion.

Why the A≠0A\ne0A=0 check matters

The discriminant test is a quadratic test. If a parameter makes A=0A=0A=0, the equation is no longer quadratic.

For example, (v−2)x2+3x−6=0(v-2)x^2+3x-6=0(v−2)x2+3x−6=0 becomes 3x−6=03x-6=03x−6=0 when v=2v=2v=2. Check it directly: x=2x=2x=2, so a real meeting still exists.

Worked proof

Show that y=mx+6y=mx+6y=mx+6 meets y=x2+2x+5y=x^2+2x+5y=x2+2x+5 for every real mmm.

Solution

  1. x2+2x+5=mx+6x^2+2x+5=mx+6x2+2x+5=mx+6.
  2. x2+(2−m)x−1=0x^2+(2-m)x-1=0x2+(2−m)x−1=0.
  3. A=1, B=2−m, C=−1A=1,\ B=2-m,\ C=-1A=1, B=2−m, C=−1, so A≠0A\ne0A=0 for every mmm.
  4. D=(2−m)2−4(1)(−1)D=(2-m)^2-4(1)(-1)D=(2−m)2−4(1)(−1).
  5. D=(m−2)2+4D=(m-2)^2+4D=(m−2)2+4.
  6. Because (m−2)2≥0(m-2)^2\ge0(m−2)2≥0, D≥4>0D\ge4>0D≥4>0.

The line meets the curve at two distinct points for every real mmm.

Key ideas

  • Set the two equations equal and collect every term.
  • Keep the sign of the xxx coefficient when identifying BBB.
  • Use D=B2−4ACD=B^2-4ACD=B2−4AC only when A≠0A\ne0A=0.
  • Complete the square in the parameter.
  • Turn square non-negativity into an exact lower bound for DDD.
  • Finish with what the sign of DDD proves about intersections.

Watch the signs

Lost minus

From x2−(k+3)x−2=0x^2-(k+3)x-2=0x2−(k+3)x−2=0, writing B=k+3B=k+3B=k+3 drops the sign.

Correct coefficient

Vague lower bound
