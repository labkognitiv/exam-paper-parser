Lines and quadratic curves

Turn intersections into roots.

Set the two y-values equal. One discriminant then tells you whether the line crosses, touches or misses the curve.

Start the lesson · Go to practice

Make one quadratic

  • A line and a curve meet where they have the same y-value.
  • For y=x2+3x+1y=x^2+3x+1y=x2+3x+1 and y=2x+5y=2x+5y=2x+5, set x2+3x+1=2x+5x^2+3x+1=2x+5x2+3x+1=2x+5.
  • Bring every term to one side: x2+x−4=0x^2+x-4=0x2+x−4=0.
  • Each real root is the x-coordinate of one intersection.

No intersection

Key ideas

  • Set the line and curve y-values equal.
  • Rearrange to ax2+bx+c=0ax^2+bx+c=0ax2+bx+c=0, with a≠0a\ne0a=0.
  • D>0D>0D>0 means two distinct intersections.
  • D=0D=0D=0 means one tangent intersection.
  • D<0D<0D<0 means no intersection.
  • Use strict inequality signs when the wording says distinct or no intersection.
  • Use boundary values to choose the correct interval.
