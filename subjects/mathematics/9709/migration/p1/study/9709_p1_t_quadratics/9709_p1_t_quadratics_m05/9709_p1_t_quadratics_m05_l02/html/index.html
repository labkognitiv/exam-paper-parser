Curve transformations

Read the change.
Move the graph.

A small change in an equation moves, flips or reshapes its graph in a predictable way.

Start the lesson

Four moves to recognise

  • A transformation changes a graph's position, direction or shape.
  • A translation slides every point by the same amount.
  • A reflection flips the graph in a named axis.
  • On a graph, xxx is the horizontal input and yyy is the vertical output.
  • A vertical stretch multiplies every yyy-coordinate by a positive scale factor. The scale factor tells how many times as large each output becomes.
  • The vertex is the turning point. For y=x2y=x^2y=x2, it is (0,0)(0,0)(0,0).

The four-step method

  1. Compare the two equations. Identify each change.
  2. Match each change to a rule.
  3. Name the translation, reflection or stretch.
  4. Apply the move to the original vertex.

Worked example: identify a translation

The graph of y=x2y=x^2y=x2 becomes y=(x−3)2+2y=(x-3)^2+2y=(x−3)2+2. Describe the transformation and state the new vertex.

Solution

  1. Inside, xxx becomes x−3x-3x−3: move right 3.
  2. Outside, +2+2+2 appears: move up 2.
  3. Combine the moves into one translation vector.

In a column vector, the top number is the horizontal move, positive to the right. The bottom number is the vertical move, positive upward.

(32)\begin{pmatrix}3\\2\end{pmatrix}(32​)

The original vertex (0,0)(0,0)(0,0) maps to (0+3,0+2)=(3,2)(0+3,0+2)=(3,2)(0+3,0+2)=(3,2).

Translation by (32)\begin{pmatrix}3\\2\end{pmatrix}(32​); new vertex (3,2)(3,2)(3,2).

Worked example: a sequence of moves

The graph of y=x2y=x^2y=x2 becomes y=−x2+4y=-x^2+4y=−x2+4. Describe the sequence and state the new vertex.

Solution

  1. The minus sign outside reflects the graph in the xxx-axis.
  2. The +4+4+4 then translates the reflected graph up 4.
  3. The origin stays fixed under the reflection, then moves to (0,4)(0,4)(0,4).

Reflect in the xxx-axis, then translate up 4. New vertex (0,4)(0,4)(0,4).

Worked example: apply a stated translation

The curve y=x2y=x^2y=x2 is translated by (−2−5)\begin{pmatrix}-2\\-5\end{pmatrix}(−2−5​). Find the new equation and vertex.

Solution

  1. Move left 2: replace xxx with x+2x+2x+2.
  2. Move down 5: subtract 5 outside.

y=(x+2)2−5y=(x+2)^2-5y=(x+2)2−5; vertex (−2,−5)(-2,-5)(−2,−5).

Three common slips

Horizontal sign

y=(x−3)2y=(x-3)^2y=(x−3)2 does not move left.

Correct

It moves right 3, placing the vertex at (3,0)(3,0)(3,0).

Stretch or slide?

y=2x2y=2x^2y=2x2 is not a vertical translation.

Correct

It is a vertical stretch by factor 2. The vertex stays at (0,0)(0,0)(0,0).

Wrong order

For y=−(x−2)2+5y=-(x-2)^2+5y=−(x−2)2+5, translating first and reflecting everything would send the vertex to (2,−5)(2,-5)(2,−5).

Correct order

Reflect y=x2y=x^2y=x2 first, then translate right 2 and up 5. The vertex is (2,5)(2,5)(2,5) and the curve opens down.

Key ideas

  • Outside addition moves a graph up or down.
  • Inside subtraction moves right; inside addition moves left.
  • A minus outside reflects in the xxx-axis.
  • A minus inside reflects in the yyy-axis.
  • Multiplication outside stretches or compresses vertically.
  • When several changes appear, state and apply them in order.
