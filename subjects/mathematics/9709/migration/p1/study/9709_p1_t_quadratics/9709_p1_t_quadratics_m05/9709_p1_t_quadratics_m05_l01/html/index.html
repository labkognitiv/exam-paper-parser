Always positive

Prove the curve stays above zero.

Completing the square reveals the lowest value of a quadratic. If that value is positive, every other value must be positive too.

Start the lesson · Go to practice

Turn “always positive” into a picture

  • An inequality compares values rather than saying they are equal.
  • f(x)>0f(x)>0f(x)>0 means the output is strictly positive: it is greater than zero and never equals zero.
  • f(x)≥0f(x)\ge0f(x)≥0 means nonnegative: zero is allowed.
  • “For all real values of xxx” means for every position on the number line.
  • The graph of a quadratic is a parabola. Its turning point is its lowest point when the graph opens upwards.
  • The x-axis is the horizontal line where y=0y=0y=0.

The condition

a(x+h)2+ka(x+h)^2+ka(x+h)2+k
  • a>0a>0a>0 makes the parabola open upwards.
  • Then the squared term is smallest when x+h=0x+h=0x+h=0.
  • The minimum value is kkk.
  • The expression is always positive exactly when a>0a>0a>0 and k>0k>0k>0.
  • It is always nonnegative when a>0a>0a>0 and k≥0k\ge0k≥0.
  1. Complete the square: write the expression as a(x+h)2+ka(x+h)^2+ka(x+h)2+k.
  2. Identify the fully simplified constant kkk.
  3. For strict positivity, write k>0k>0k>0. For nonnegativity, write k≥0k\ge0k≥0.
  4. Solve that inequality for the unknown constant.
  • If a<0a<0a<0, the parabola opens downwards and its values eventually become negative, so it cannot be always positive.
  • To prove an expression is always greater than a number such as 5, subtract 5 first and prove the new expression is always positive.

Check the shape first. Then check the height.

Worked examples

Worked example 1

Find the values of ccc for which x2+4x+c>0x^2+4x+c>0x2+4x+c>0 for every real xxx.

Solution

  1. Half of 4 is 2; its square is 4.
  2. x2+4x+c=(x+2)2−4+cx^2+4x+c=(x+2)^2-4+cx2+4x+c=(x+2)2−4+c
  3. The simplified constant is k=c−4k=c-4k=c−4.
  4. The squared coefficient is positive, so require k>0k>0k>0.
  5. c−4>0c-4>0c−4>0, hence c>4c>4c>4.

c>4c>4c>4.

Why is (x+4)2+2(x+4)^2+2(x+4)2+2 positive for every real xxx?

Watch out

Check the coefficient of the square

Wrong: −2(x−3)2+5-2(x-3)^2+5−2(x−3)2+5 is always positive because 5 is positive.

Correct: the coefficient -2 makes the parabola open downwards. For large positive or negative xxx, the expression is negative.

Strict and non-strict inequalities differ

Wrong: for x2+4x+c>0x^2+4x+c>0x2+4x+c>0, write c≥4c\ge4c≥4.

Correct: c>4c>4c>4. At c=4c=4c=4, the curve touches the x-axis, so the expression equals zero there.

Use the constant after completing the square

Wrong: in x2−6x+kx^2-6x+kx2−6x+k, the minimum is simply kkk.

Correct: x2−6x+k=(x−3)2+k−9x^2-6x+k=(x-3)^2+k-9x2−6x+k=(x−3)2+k−9. The minimum is k−9k-9k−9, so strict positivity requires k>9k>9k>9.

Key ideas

  • Write the quadratic as a(x+h)2+ka(x+h)^2+ka(x+h)2+k.
  • Require a>0a>0a>0 so the graph opens upwards.
  • The fully simplified constant kkk is the minimum value.
  • Always positive means k>0k>0k>0.
  • Always nonnegative means k≥0k\ge0k≥0.
  • For “always greater than NNN”, subtract NNN first.
