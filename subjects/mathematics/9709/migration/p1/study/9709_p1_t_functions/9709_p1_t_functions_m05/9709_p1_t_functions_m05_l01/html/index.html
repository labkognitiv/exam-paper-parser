Reading graphs · single transformations

Read the curve, then move it.

Identify intercepts, turning points and end behaviour. Then match the equation to a translation, stretch or reflection and state the full effect.

Start

Read a graph before transforming it

  • Coordinates are written (x, y): x first, then y.
  • An x-intercept is where y = 0. A y-intercept is where x = 0.
  • A translation moves every point by the same vector (horizontal change, vertical change).
  • A stretch scale factor (SF) multiplies distances parallel to one axis. SF 3 parallel to the y-axis triples every y-coordinate.
  • An asymptote is a line the curve approaches without reaching. For 1/x, the axes are asymptotes.
  • Angles such as π/2 are measured in radians: π radians is half a turn.
  • arcsin reverses sin on its principal range, so arcsin(1/4) is the angle whose sine is 1/4.
  • A stationary point is a point where the curve is momentarily flat; it may be a maximum or minimum. For a quadratic it is the vertex.
  • End behaviour describes what y does at the left and right ends of the domain, including whether it approaches an asymptote.

Reciprocal shape

Four standard forms

y = f(x) + aVertical translation by (0, a).
y = f(x + a)Horizontal translation by (−a, 0).
y = a f(x)Vertical stretch, scale factor a.
y = f(ax)Horizontal stretch, scale factor 1/a.
  • For y = −f(x), every y becomes −y: reflection in the x-axis.
  • For y = f(−x), every x becomes −x: reflection in the y-axis.
  • For an inverse, (x, y) becomes (y, x): reflection in y = x.

Sketch a given function

  1. Substitute the left and right domain endpoints.
  2. Find maxima and minima inside the domain.
  3. Find axis intercepts.
  4. Join the marked points smoothly using the standard shape.

f(x) = 4 sin x − 1, −π/2 ≤ x ≤ π/2

  1. Endpoints: f(−π/2) = −5 and f(π/2) = 3.
  2. x-intercept: 4 sin x − 1 = 0, so x = arcsin(1/4) ≈ 0.253.
  3. y-intercept: f(0) = −1.
  4. Draw a rising sine-shaped curve through (−π/2, −5), (0, −1), (0.253, 0), (π/2, 3).

f(x) = 5 − 2 sin 2x, 0 ≤ x ≤ π

  1. Endpoints: f(0) = f(π) = 5.
  2. Minimum: sin 2x = 1 at x = π/4, giving (π/4, 3).
  3. Maximum: sin 2x = −1 at x = 3π/4, giving (3π/4, 7).
  4. Sketch one wave through (0,5), (π/4,3), (π/2,5), (3π/4,7), (π,5).

Describe one transformation

  • Always state type, direction and magnitude.
  • Outside the function changes y. Inside the function changes x, with the horizontal sign reversed.
  • For stretches, the scale factor is positive. A negative factor adds a reflection.

Describe y = f(x − 4) + 3

  1. Write x − 4 as x + (−4). Both an inside and outside change are present, so this is a translation.
  2. Horizontal shift: −(−4) = 4 right. Vertical shift: +3 up.
  3. Translation by vector (4, 3).

Apply two transformations

y = sin 2x − 5x is reflected in the y-axis, then stretched by SF 1/3 parallel to the x-axis.

  1. Reflect in y-axis: replace x with −x: y = sin(−2x) − 5(−x) = −sin 2x + 5x.
  2. For horizontal SF 1/3, replace x with 3x: y = −sin 6x + 15x.

Translate a quadratic

f(x) = −3x² + 12x + 2 translated by (−3, 1).

  1. Vector (−3,1): replace x with x + 3 and add 1: g(x) = f(x + 3) + 1.
  2. f(x) = −3(x − 2)² + 14, so f(x + 3) = −3(x + 1)² + 14.
  3. g(x) = −3(x + 1)² + 15 = −3x² − 6x + 12.

Apply and reverse transformations

Find a corresponding original point

P(5,6) lies on y = f(2x) − 3. Find the point on y = f(x).

  1. f(2x) is horizontal SF 1/2, so undo it by doubling x.
  2. −3 is a downward translation, so undo it by adding 3: original y = 6 + 3 = 9.
  3. Original x = 5 × 2 = 10. Point: (10, 9).

Read an equation from a diagram

A curve is stretched by SF 3 parallel to y-axis, then translated by (4,0).

  1. Vertical stretch gives y = 3f(x).
  2. Translation 4 right replaces x with x − 4.
  3. y = 3f(x − 4).

Reflections and inverses

  • y = −f(x): reflect every point (x,y) to (x,−y) in the x-axis.
  • y = f(−x): reflect every point (x,y) to (−x,y) in the y-axis.
  • y = f⁻¹(x): reflect every point (x,y) to (y,x) in y = x. f must be one-to-one.

Reflect a curve

f passes through (0,−2), (1,0), (3,2).

  1. Draw y = x dashed.
  2. Swap points: (0,−2)→(−2,0), (1,0)→(0,1), (3,2)→(2,3).
  3. Plot and join smoothly. This is y = f⁻¹(x).

Trigonometric inverse sketch

f(x) = 3 + 2 sin(x/4), 0 ≤ x ≤ 2π.

  1. On this interval x/4 runs from 0 to π/2, so f is increasing and one-to-one.
  2. Endpoints: (0,3) and (2π,5).
  3. Swap them for f⁻¹: (3,0) and (5,2π).
  4. Draw y = x dashed and join the reflected endpoints smoothly.

Two quick checks

What is the full transformation from y = f(x) to y = f(x + 3)?

Which change describes y = 3f(x)?

Key ideas

  • Read intercepts, stationary points and end behaviour before sketching.
  • Outside changes act on y; inside changes act on x and reverse horizontal direction.
  • Translations need a vector. Stretches need an axis and scale factor.
  • Minus outside reflects in x-axis; minus inside reflects in y-axis.
  • Inverse graphs reflect in y = x and swap coordinates.

Try it yourself

Transformation wording

Describe y = f(x − 6) + 2.

Inside x − 6 shifts 6 right; outside +2 shifts 2 up. Translation by (6,2).

Reflection equation

Reflect y = cos x − 4x in the y-axis.

Replace x by −x: y = cos(−x) − 4(−x) = cos x + 4x.

Reverse a point

Q(4,−1) lies on y = f(x/2) + 5.

  1. Undo +5: original y = −1 − 5 = −6.
  2. Undo horizontal SF 2 by halving x: original x = 4/2 = 2.
  3. Corresponding point (2,−6).

Translate and expand

y = 2x² − 4x + 3 translated by (1,−2).

  1. g(x) = f(x − 1) − 2.
  2. 2(x − 1)² − 4(x − 1) + 3 − 2.
  3. g(x) = 2x² − 8x + 7.

Exam practice

A graph is shifted 3 left and 2 down. State its equation in terms of f.

y = f(x + 3) − 2.

Two transformations

Reflect y = cos 2x + 3x in y-axis, then horizontal SF 1/2.

  1. Reflect: cos(−2x) + 3(−x) = cos 2x − 3x.
  2. Replace x by 2x: y = cos 4x − 6x.

Reverse a stretched point

R(6,−4) lies on y = 2f(x − 1) + 3.

  1. Undo outside first: original function value = (−4 − 3)/2 = −7/2.
  2. Undo x − 1 by adding 1: original x = 6 − 1 = 5.
  3. Corresponding point (5,−7/2).
