Composite range · equations · inverse composites

Form the composite,
then respect its domain.

A composite can have a smaller range than either function suggests. Form it, read its legal inputs, solve carefully, and reject roots that do not belong.

Two reliable methods

When asking whether fg exists

  1. Find the range of the inner function g on its domain.
  2. Read the domain of the outer function f.
  3. Compare them. If g overshoots, restrict its domain and find the boundary parameter.
  4. State the boundary or explain why the composite cannot exist.

When finding a composite range

  1. Form fg(x)=f(g(x)).
  2. Put it into readable form: completed square, simplified rational, or isolated trig part.
  3. Use the inner input domain to find the range of the inner expression.
  4. Apply the outer rule and state the output range.

Rational composite becomes linear

f(x)=4/x−2, x>0; g(x)=4/(5x+2), x≥0.

  1. fg(x)=4/[4/(5x+2)]−2=(5x+2)−2=5x.
  2. Since x≥0, 5x≥0.
  3. fg(x)=5x and its range is fg(x)≥0.

Read graphs and solve fg(x)=k

  • An x-intercept has y=0. A y-intercept has x=0.
  • A stationary point is a point where the tangent is horizontal, so the derivative is zero. It may be a local high point, local low point or a flat inflection. Read both coordinates.
  • End behaviour describes what y does near the ends of the domain or near an asymptote.

Three-step equation method

  1. Form the composite.
  2. Set it equal to k.
  3. Solve in x, then reject roots outside the composite input domain: x∈dom(g) and g(x)∈dom(f).

Worked equations and sketches

Rational becomes quadratic

f(x)=1/(x²−9), g(x)=2x−3, x>3. Solve fg(x)=1/7.

  1. 1/[(2x−3)²−9]=1/7.
  2. (2x−3)²=16, so x=7/2 or x=−1/2.
  3. The domain is x>3, so reject −1/2. x=7/2.

Trig composite in exact form

f(x)=2−3cos x, g(x)=x/2, 0≤x≤2π. Solve fg(x)=1.

  1. 2−3cos(x/2)=1, so cos(x/2)=1/3.
  2. Because x/2∈[0,π], there is one solution: x/2=arccos(1/3).
  3. x=2arccos(1/3)≈2.46.

Sketching a restricted sine

For f(x)=4sin x−1, −π/2≤x≤π/2, endpoints are (−π/2,−5) and (π/2,3); y-intercept is (0,−1); x-intercept is x=arcsin(1/4)≈0.253. Join with a smooth sine shape.

For f(x)=5−2sin2x, 0≤x≤π: endpoints are (0,5),(π,5), minimum (π/4,3), maximum (3π/4,7), and midpoint (π/2,5).

Transformations and common traps

In y=a f(b(x+p))+q, assume a and b are non-zero. The vertical scale is |a|, with reflection in the x-axis when a<0. The horizontal scale is 1/|b|, with reflection in the y-axis when b<0. p translates by (−p,0), and q translates by (0,q).

Three transformations

g(x)=3(x+2)²−5 from f(x)=x²: translate by (−2,0), stretch parallel to y-axis scale factor 3, then translate by (0,−5).

Stationary point transform

If (2,−5) maps under y=4−2f(x+3), solve x+3=2 to get x=−1; y=4−2(−5)=14. New point: (−1,14).

More worked examples

Range and composite equation

For f(x)=½x−2, g(x)=4+x−x²/2, fg(x)=−¼(x−1)²+¼, so fg(x)≤¼.

For f(x)=x²+3, x>0, g(x)=2x+1, x>−1/2: solving fg−3=gf gives roots 1 and −3; reject −3, so x=1.

Further exact examples

For f(x)=2/(x²−4), g(x)=3x−1, x>3, solving fg=2/5 gives candidates 4/3 and −2/3, both outside the domain: no solution.

For f(x)=x²−4x+3, x>5, g(x)=1/(x+1), x>−1, gf(x)=1/(x−2)²; since x>5, 0<gf(x)<1/9.

For f(x)=3x²+12x−2 and g(x)=2x+3, g⁻¹(f(x))=(3x²+12x−5)/2. Setting zero gives x=(−6±√51)/3.

Full worked problems

Composite range

f(x)=½x−2, g(x)=4+x−x²/2. Find fg(x) and its range.

  1. Substitute: fg(x)=½(4+x−x²/2)−2.
  2. Expand each term: fg(x)=2+x/2−x²/4−2=x/2−x²/4.
  3. Complete the square: fg(x)=−¼(x²−2x)=−¼[(x−1)²−1]=−¼(x−1)²+¼.
  4. The square is non-negative and the coefficient is negative, so the maximum is ¼. Range: fg(x)≤¼.

Equality of composites

f(x)=x²+3, x>0; g(x)=2x+1, x>−½. Solve fg(x)−3=gf(x).

  1. fg(x)=(2x+1)²+3=4x²+4x+4.
  2. gf(x)=2(x²+3)+1=2x²+7.
  3. Set equal: 4x²+4x+4−3=2x²+7, so 2x²+4x−6=0.
  4. Divide by 2 and factor: (x+3)(x−1)=0. Candidates are x=−3 and x=1.
  5. The composite input domain is x>−½, so reject −3. x=1.

Rational composite

f(x)=1/(x²−q), g(x)=2x−3, x>3. Solve fg(x)=1/7.

  1. Form: 1/[(2x−3)²−q]=1/7.
  2. Cross-multiply: (2x−3)²−q=7, so (2x−3)²=q+7.
  3. Thus 2x−3=±√(q+7), giving x=(3±√(q+7))/2.
  4. Keep only candidates satisfying x>3 and the denominator restrictions; the domain test decides which branch is admissible.

Composite of an inverse

f(x)=2x²+8x+1, g(x)=2x+1. Find g⁻¹(f(x)) and solve it equal to 0.

  1. From y=2x+1, swap and solve: g⁻¹(x)=(x−1)/2.
  2. Substitute the whole f expression: g⁻¹(f(x))=(2x²+8x+1−1)/2=x²+4x.
  3. Set zero: x²+4x=x(x+4)=0. x=0 or x=−4.

Exam practice: exact forms

  1. For f=2/(x²−4), g=3x−1, x>3, setting fg=2/5 gives (3x−1)²=9, candidates x=4/3 and −2/3. Neither is >3, so no solution.
  2. For f=x²−4x+3, x>5; g=1/(x+1), x>−1, f=(x−2)²−1 and gf=1/(f+1)=1/(x−2)². Since x>5, (x−2)²>9, so 0<gf(x)<1/9.
  3. For f=3x²+12x−2, g=2x+3, g⁻¹(f(x))=(f(x)−3)/2=(3x²+12x−5)/2. Setting zero gives 3x²+12x−5=0, hence x=(−6±√51)/3.

Key ideas

  • Check inner range against outer domain.
  • For a range, form, simplify, use the inner domain, then apply the outer rule.
  • For fg=k, form, set equal, solve, reject illegal roots.
  • Read transformations from a,b,p,q.
