Before you start

Notation, order and substitution

f(x)=2x+3 means feed in x and get out 2x+3; for example f(5)=13. The range is the set of outputs. An inverse swaps input and output, so f(x)=2x+1 gives f⁻¹(x)=(x−1)/2.

Read the order

For f(x)=3x+2, g(x)=2x²+3:

  1. fg(x)=f(g(x))=3(2x²+3)+2=6x²+11.
  2. gf(x)=g(f(x))=2(3x+2)²+3=18x²+24x+11.
  3. At x=2, the values are 35 and 131, so order matters.

Substitute a whole expression

If f(x)=3x+2, then f(2x²+3)=3(2x²+3)+2=6x²+11. Brackets protect every term.

Forming a composite

Four steps

  1. Identify the inner function. In fg, it is g; in gf, it is f.
  2. Substitute the whole inner expression into every outer input.
  3. Simplify only when asked. An unsimplified request stops after substitution.
  4. State the requested form.

Show-that example

f(x)=2x²+3, g(x)=3x+2.

  1. gf(x)=g(2x²+3)=3(2x²+3)+2.
  2. =6x²+9+2=6x²+11.
  3. fg(x)=f(3x+2)=2(3x+2)²+3, left unsimplified.

Two rationals

f(x)=4/x−2, g(x)=4/(5x+2).

  1. fg=4/[4/(5x+2)]−2=5x.
  2. gf=4/[5(4/x−2)+2]=4x/(20−8x)=x/(5−2x).
Check A

For f(x)=3x+2, g(x)=2x²+3, which begins fg(x)?

Correct. g is inside and is applied first.
That begins gf(x). Read the letters right to left.
Existence conditions

When is fg defined?

Every output of the inner function must be a legal input of the outer function. The range of g must be a subset of the domain of f.

  1. Find the inner range on its given domain.
  2. Read the outer domain.
  3. Compare. If the inner range oversteps the outer domain, restrict inputs or explain failure.
  4. State the boundary.

Failed composite

f(x)=1/(x−2) for x>2; g(x)=√x for x≥0. The range of g is [0,∞), not contained in (2,∞); g(0)=0 is illegal. Thus fg is not defined on all of the stated domain.

Largest parameter

f(x)=−x/√(4−x²) for −2<x<2, g(x)=2x for −a<x<a.

  1. Range of g: −2a<g(x)<2a.
  2. Fit inside −2<u<2: a≤1.

Maximum a=1.

Check B

If f accepts only positive inputs and g(x)=5x+1 for all real x, is fg defined for every real input?

Correct. g(−1)=−4, outside the domain of f.
The range of g includes negative values, so not every output is legal for f.
Core recap

Three decisions

  • Read composites right to left.
  • Substitute the whole inner expression and use brackets.
  • Check inner range against outer domain before claiming existence.
More worked examples

Inverse branches, identities and numerical composites

Inverse, left branch

f(x)=(x−3)²−1, x<3. Swap: x=(y−3)²−1; isolate (y−3)²=x+1; choose the minus branch because x<3. Therefore f⁻¹(x)=3−√(x+1), x>−1.

Inverse with an endpoint range

f(x)=2(x−4)²−9, x<3. Swapping and isolating gives y−4=±√((x+9)/2); choose minus. Since f(3)=−7 and the endpoint is excluded, f⁻¹(x)=4−√((x+9)/2) for x>−7.

Identity matching

f(x)=x−4√x+1, h(x)=√x−2, g(u)=mu²+n. Expand g(h(x))=m(x−4√x+4)+n=mx−4m√x+4m+n. Match coefficients: m=1, 4+n=1, so m=1,n=−3.

Numerical shortcut

Work from inside out: if f(x)=5−2sinx, then f(0)=5 and ff(0)=f(5)=5−2sin5 (radians). If g(x)=3x−2, g(2)=4 and gg(2)=10. If g(x)=4/(x+1), g(7)=1/2; with f(x)=4x−2, fg(7)=0.

Further practice

ff(x) for f(x)=(x+2)/(x−3): top 3x−4, bottom 11−2x, so ff(x)=(3x−4)/(11−2x) for 3<x<11/2.

For f=x², g=3(x+2)²−5: translate (−2,0), vertical stretch 3, translate (0,−5).
