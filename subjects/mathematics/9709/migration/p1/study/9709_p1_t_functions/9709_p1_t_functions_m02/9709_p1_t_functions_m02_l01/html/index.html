One-to-one functions · domain restriction · inverse functions

Make one output come from one input.

A function has an inverse only when its domain gives each output exactly one input. Learn to recognise the route, choose the branch, and carry the restriction through the inverse.

Start the lesson · Functions lessons

What one-to-one means

  • An input is a number put into a rule; its output is the resulting number. f(x), read “f of x”, names that output. The domain is the allowed inputs; the range is the reached outputs.
  • The symbol ⇒ means “implies”: the statement on its left forces the statement on its right. The letters a and b below name two inputs.
  • A graph places input x across a horizontal axis and output y up a vertical axis. The coordinate pair (a,b) means input a produces output b. A horizontal line represents one fixed output height.
  • An inverse f⁻¹ reverses input and output. Its domain is the original range; its range is the original domain. It can be a function only if each reached output has a unique original input.
  • A quadratic contains a nonzero x² term and no higher powers. Its graph is a parabola, shaped like a U or an upside-down U. Its turning point is the vertex. Each side is called a branch.
  • A function is one-to-one when two different inputs can never give the same output.
  • In symbols: f(a) = f(b) ⇒ a = b.
  • If two distinct inputs give the same output, the function is many-to-one and has no inverse on that domain.
  • The horizontal line test says the same thing visually: every horizontal line must meet the graph at most once.

Counterexample

For f(x) = x² − 6, choose 2 and −2.

f(2) = 4 − 6 = −2,   f(−2) = 4 − 6 = −2.

Because 2 ≠ −2 but the outputs match, f is not one-to-one on ℝ.

Why a quadratic needs a restriction

  • An upward quadratic turns at its minimum vertex; a downward quadratic turns at its maximum vertex.
  • For y = (x − 3)² − 7 on all real x, a horizontal line above the vertex meets both branches.
  • Keeping only x ≥ 3 keeps the right branch. Keeping only x ≤ 3 keeps the left branch.
  • The boundary is the vertex x-coordinate. The restriction is part of the function definition.

Worked example · restriction chooses the inverse branch

f(x)=(x−2)²+2,   x≥2. Find f⁻¹(x).

  1. Set y=(x−2)²+2, then isolate: (x−2)²=y−2.
  2. Take both square roots: x−2=±√(y−2).
  3. The domain x≥2 makes x−2≥0, so keep the plus sign: x=2+√(y−2).
  4. Swap and rename: f⁻¹(x)=2+√(x−2).
  5. The original range starts at 2, so the inverse domain is x≥2.

Choose the route

  • The derivative f′(x), read “f prime of x”, is the graph’s instantaneous gradient. A positive gradient slopes upwards as x increases; a negative gradient slopes downwards. Differentiation finds this gradient rule.
  • Strictly increasing means every larger input gives a larger output; strictly decreasing means it gives a smaller output. Either prevents repeated outputs.
  • On an interval, a derivative that is always positive or always negative is sufficient. It is not necessary: a strictly increasing function can have zero gradient at isolated points.
  • For the calculations below, differentiating xⁿ gives n x^(n−1), a constant gives zero, and constant multipliers remain. For a power of a bracket, also multiply by the derivative of that bracket; this is the chain rule.

Route 1 · quadratic

Complete the square. Read the vertex. Restrict to one side.

x ≥ vertex x  or  x ≤ vertex x

Route 2 · increasing

Differentiate. If f′(x) > 0 throughout an interval domain, f is strictly increasing and one-to-one.

Route 3 · decreasing

Differentiate. If f′(x) < 0 throughout an interval domain, f is strictly decreasing and one-to-one.

  • Quadratic plus a domain bound means Route 1.
  • Rational, cubic or trigonometric functions with an increasing/decreasing instruction usually mean Routes 2 or 3.
  • Complete the square (CTS) gives the vertex in the form a(x − h)² + k. The vertex is (h, k).

Key ideas

  • One-to-one means different inputs give different outputs.
  • Restrict a quadratic to one side of its vertex to prevent repeated outputs.
  • On an interval, an always-positive or always-negative derivative is sufficient for one-to-one behaviour.
  • When finding an inverse, swap input and output, then retain the original domain as a restriction on the inverse output.
  • Domain of the inverse is range of the original function.

Worked examples

Worked example · smallest c

f(x) = (x − 2)² + 2 for x ≥ c. Find the smallest c making f one-to-one.

  1. The function is already in CTS form, so the vertex x-coordinate is 2.
  2. x ≥ c must keep the right branch only.
  3. The smallest boundary that does this is the vertex itself: c = 2.
  4. Check: x ≥ 2 is exactly the right branch, so f is one-to-one.

Worked example · quadratic inverse, right branch

  • Write y=f(x), then exchange x and y to describe the reversed connection. Isolate y by applying the same operation to both sides.
  • After swapping, the original domain restricts y. The symbol √u means the non-negative square root. An equation z²=u allows z=±√u, meaning both signs; the domain tells us which sign to retain.
  • If the original input was at least the vertex input h, then y−h≥0 after swapping, so take the plus root. To the left, take the minus root.

f(x) = 2x² − 12x + 7 for x ≥ 3. Find f⁻¹(x) and its domain.

  1. CTS: f(x) = 2(x − 3)² − 11.
  2. Set y = 2(x − 3)² − 11 and swap: x = 2(y − 3)² − 11.
  3. Isolate: (y − 3)² = (x + 11)/2.
  4. Square root: y − 3 = ±√((x + 11)/2).
  5. x ≥ 3 is the right branch, so keep +. Therefore f⁻¹(x) = 3 + √((x + 11)/2).
  6. The range of f starts at −11, so the inverse domain is x ≥ −11.

Worked example · increasing/decreasing

f(x) = x² − 4x + 7 for x < k. Find the largest k for which f is decreasing.

  1. Differentiate: f′(x) = 2x − 4.
  2. Decreasing means f′(x) < 0: 2x − 4 < 0 ⇒ x < 2.
  3. The domain x < k must stay within x < 2. Thus largest k = 2.

Worked example · rational

f(x) = 2 − 3/(4x − p) for x > p/4. Decide whether it is increasing or decreasing.

  1. Rewrite: f(x) = 2 − 3(4x − p)⁻¹.
  2. Differentiate: f′(x) = −3 × (−1) × (4x − p)⁻² × 4 = 12/(4x − p)².
  3. The denominator is positive on the stated domain, so f′(x) > 0 throughout.
  4. Therefore f is increasing, hence one-to-one.

Worked example · sine inverse

  • Angles use radians: π is a half-turn. Sine increases from −1 to 1 on [−π/2,π/2].
  • arcsin is the inverse sine function returning the unique angle in [−π/2,π/2] for an input in [−1,1]. This chosen output interval is its principal range.

f(x) = 4 sin x − 1 for −π/2 ≤ x ≤ π/2. Find f⁻¹(x) and its domain.

  1. Set y = 4 sin x − 1 and swap: x = 4 sin y − 1.
  2. Add 1 and divide by 4: sin y = (x + 1)/4.
  3. The given y interval is the principal arcsin range, so y = arcsin((x + 1)/4).
  4. Range: −1 ≤ sin x ≤ 1 gives −5 ≤ f(x) ≤ 3.
  5. f⁻¹(x) = arcsin((x + 1)/4), for −5 ≤ x ≤ 3.

Worked example · scaled sine

g(x) = 5 − 2 sin 2x for 0 ≤ x ≤ π/4.

  1. Swap: x = 5 − 2 sin 2y.
  2. Rearrange: sin 2y = (5 − x)/2.
  3. Apply arcsin, then divide by 2: g⁻¹(x) = ½ arcsin((5 − x)/2).
  4. As 2x runs from 0 to π/2, g runs from 5 down to 3. Domain of g⁻¹: 3 ≤ x ≤ 5.

Worked example · leading coefficient and left branch

f(x) = 2x² − 12x + 11 for x ≤ 3.

  1. CTS: f(x) = 2(x − 3)² − 7.
  2. Swap and isolate: (y − 3)² = (x + 7)/2.
  3. Since x ≤ 3, keep the negative root: f⁻¹(x) = 3 − √((x + 7)/2).
  4. Range of f is f(x) ≥ −7, so inverse domain is x ≥ −7.

Worked example · negative a

f(x) = −3x² + 12x + 2 for x ≤ 2.

  1. CTS: f(x) = −3(x − 2)² + 14.
  2. After swapping, (y − 2)² = (14 − x)/3.
  3. The domain is left of the vertex, so keep −: f⁻¹(x) = 2 − √((14 − x)/3).
  4. The maximum is 14, so the inverse domain is x ≤ 14.

Worked example · different letter

g(x) = 6x − x² − 5 for x ≥ 3.

  1. CTS: g(x) = −(x − 3)² + 4.
  2. Swap and rearrange: (y − 3)² = 4 − x.
  3. x ≥ 3 is the right branch, so keep +: g⁻¹(x) = 3 + √(4 − x).
  4. Range is g(x) ≤ 4, so inverse domain is x ≤ 4.

Worked example · strict endpoint

h(x) = 4x² − 12x + 13 for x < 0.

  1. CTS: h(x) = 4(x − 3/2)² + 4.
  2. x < 0 is left of the vertex, so choose − after taking the square root.
  3. h⁻¹(x) = 3/2 − √(x − 4)/2.
  4. The excluded endpoint maps to h(0) = 13, so the inverse domain is strictly x > 13.

Two quick checks

Check A

For y = (x − 5)² + 4 with x ≥ c, which least c gives a one-to-one function?

Check B
