Functions · Lesson 2

Follow the angle.
Find every output.

Track the angle inside a sine or cosine, then follow the operations outside it.

Functions lessonsStartKey ideasMore worked examples

Start with the angle and its interval

  • The domain lists allowed inputs; the range lists all reached outputs. f(x), read “f of x”, means the output of rule f at input x.
  • All angles here are in radians: π radians is a half-turn and 2π is one complete turn. Set a calculator to radian mode if using one.
  • Sine and cosine are the familiar trigonometric functions, written sin and cos. On the unit circle, sine is the vertical coordinate and cosine is the horizontal coordinate. Each lies between −1 and 1.
  • A cycle is one complete repetition. Sine and cosine repeat after the angle increases by 2π. A full cycle reaches both −1 and 1.
  • For sine: sin(0)=0, sin(π/2)=1, sin(π)=0, sin(3π/2)=−1, sin(2π)=0. For cosine at the same angles: 1, 0, −1, 0, 1.
  • The interval [a,b] includes its endpoints. A strict inequality excludes its boundary. On a restricted interval, check endpoints and any turning angles inside; include periodic repeats of those turning angles when relevant.
  • In a+b sin(…), a is the amount added to each output and b is its multiplier. First find the range of the inside angle, then the sine or cosine values.
  • Multiply those values by b. If b is negative, the larger input value gives the smaller product: for instance −3×1=−3 and −3×(−1)=3.
  • Add a to both bounds. Include a boundary only if it is actually reached. Do not assume a restricted angle interval reaches the full sine/cosine range.

Transform the range

Worked example · A full cycle with a negative multiplier

f(x)=5−2sin(2x), for 0≤x≤π. Find the range.

Solution

  1. Multiply the input bounds by 2: 0≤2x≤2π. The angle 2x covers one full cycle.
  2. Therefore −1≤sin(2x)≤1. The endpoints −1 and 1 occur inside this angle interval.
  3. Multiply the inequality by −2, reversing both signs: 2≥−2sin(2x)≥−2. Write it in increasing order: −2≤−2sin(2x)≤2.
  4. Add 5 to all three parts: 3≤f(x)≤7. The minimum occurs when sin(2x)=1; the maximum occurs when it is −1.

Worked example · A restricted angle interval

f(x)=4sin(x)−1, for −π/2≤x≤π/2. Find the range.

Solution

  1. The inside angle is x itself. Sine increases from sin(−π/2)=−1 to sin(π/2)=1 on this interval.
  2. Multiply −1≤sin(x)≤1 by positive 4: −4≤4sin(x)≤4.
  3. Subtract 1 throughout: −5≤f(x)≤3. Both endpoints are allowed and reached.

Worked example · Find constants from a range

g(x)=c+d sin(x), for all real x, has range −4≤g(x)≤10. Find c and d.

Solution

  1. The absolute value |d| is the non-negative magnitude of d. Whether d is positive or negative, d sin(x) ranges from −|d| to |d|.
  2. The maximum gives c+|d|=10. The minimum gives c−|d|=−4.
  3. Add the equations: 2c=6, so c=3. Subtract the second from the first: 2|d|=14, so |d|=7.
  4. c=3 and d=7 or d=−7. The range alone cannot determine the sign of d.
  5. Equivalently, half the sum of the bounds gives c, and half their difference gives |d|.

Apply the inside function first

  • fg(x) means f(g(x)): apply g first, then send its output into f. This is a composite. It does not mean multiplication.
  • The inner function is nearest x; the outer function receives its output. Swap the order and the resulting rule can change.
  • Substitute the whole inner expression into every x in the outer rule, keeping brackets. Expanding a square means multiplying the entire bracket by itself, including both middle products.

Worked example · Linear and quadratic rules

f(x)=2x+3 and g(x)=ax²+b, with real inputs and constants a,b. Find fg and gf.

Solution

  1. fg(x)=f(ax²+b)=2(ax²+b)+3=2ax²+2b+3.
  2. gf(x)=g(2x+3)=a(2x+3)²+b.
  3. Expand (2x+3)²=4x²+6x+6x+9=4x²+12x+9.
  4. Multiply by a and add b: gf(x)=4ax²+12ax+9a+b.

Worked example · Two rational rules

f(x)=4/x−2 for x>0; g(x)=4/(5x+2) for x≥0. Form compatible composites.

Solution

  1. Every g output is positive, so it is allowed in f. Thus fg exists on the full stated domain x≥0.
  2. fg(x)=4/[4/(5x+2)]−2. Dividing by a nonzero fraction means multiplying by its reciprocal. The 4 factors cancel, giving (5x+2)−2=5x, for x≥0.
  3. For gf, the outer rule g needs f(x)≥0. Solve 4/x−2≥0 with x>0: multiply by positive x to get 4−2x≥0, hence x≤2.
  4. Therefore gf cannot be formed on all of f’s original domain. Restrict f to 0 before forming it.
  5. On that restriction, gf(x)=4/[5(4/x−2)+2]=4/(20/x−8).
  6. Multiply numerator and denominator by nonzero x: 4x/(20−8x). Divide both by 4: gf(x)=x/(5−2x), for 0.

Your turn

F(x)=4−3cos(x) for all real x. Which range is correct?

f(x)=4x−3 and g(x)=3x²+2. Which is fg(x)?

Key ideas

  • Track the inside angle, then its trigonometric outputs.
  • Negative multiplication reverses order; add the constant afterwards.
  • Use included bounds only when attained.
  • A full sine/cosine range determines the multiplier’s magnitude, not its sign.
  • For a composite, apply the inner function first and check its outputs fit the outer domain.

Worked example · Check a negative multiplier

Find the full-cycle range of f(x)=3−4sin(x).

Solution

  1. Sine ranges from −1 to 1. Multiplying by −4 gives bounds −4 and 4, in increasing order.
  2. Add 3: −1≤f(x)≤7. Subtracting 4 at both endpoints would be wrong: the sine value changes between endpoints.
  • When solving a trigonometric equation, find every angle in the stated interval. A calculator’s principal value is just its chosen single answer, not automatically the complete solution set.

Worked example · Find all angles

Solve sin(2x)=−1/2 for 0≤x≤π.

Solution

  1. First transform the domain: 0≤2x≤2π.
  2. The acute reference angle with sine 1/2 is π/6. Sine is negative below the horizontal axis, in the third and fourth quarters of the unit circle.
  3. The corresponding angles in the full turn are π+π/6=7π/6 and 2π−π/6=11π/6.
  4. Divide each by 2: x=7π/12 or x=11π/12. Both lie in [0,π].
  5. The principal angle −π/6 for 2x would give x=−π/12, outside this domain. No other angles in the stated full turn have sine −1/2.

Worked example · A cosine range

f(x)=2−3cos(x), for 0≤x≤2π. Find the range.

Solution

  1. Cosine covers one full cycle and reaches −1 and 1.
  2. Multiply by −3 and reorder: −3≤−3cos(x)≤3. Add 2.
  3. −1≤f(x)≤5.

Worked example · Another range gives two signs

g(x)=c+d sin(x), for all real x, has range 1≤g(x)≤9. Find c,d.

Solution

  1. The endpoints give c+|d|=9 and c−|d|=1.
  2. Add: 2c=10, so c=5. Subtract: 2|d|=8, so |d|=4.
  3. c=5, d=4 or d=−4.

Worked example · A cosine equation

f(x)=3+2cos(x), for 0≤x≤2π. Solve f(x)=4, exactly.

Solution

  1. Set 3+2cos(x)=4. Subtract 3, then divide by 2: cos(x)=1/2.
  2. The reference angle is π/3. Cosine is positive to the right of the unit circle, in its first and fourth quarters.
  3. The angles are π/3 and 2π−π/3=5π/3.
  4. x=π/3 or x=5π/3. These are the only two in [0,2π]; the endpoints have cosine 1, not 1/2.

Worked example · Show a result and leave another unsimplified

f(x)=2x²+3 and g(x)=3x+2, both for x≥0. Show gf(x)=6x²+11 and give fg(x) unsimplified.

Solution

  1. Both inner outputs stay non-negative, so both composites exist on x≥0.
  2. gf(x)=g(2x²+3)=3(2x²+3)+2=6x²+9+2=6x²+11.
  3. fg(x)=f(3x+2)=2(3x+2)²+3. Leave these brackets because an unsimplified expression was requested.
  • An identity holds for every allowed input. Matching coefficients means comparing the multipliers of corresponding powers or expressions in two identities.

Worked example · Find constants in an identity

f(x)=x−4√x+1 for x≥0, g(x)=mx²+n, and h(x)=√x−2. Given f(x)=g(h(x)) for every allowed x, find m,n.

Solution

  1. Substitute h into g: g(h(x))=m(√x−2)²+n.
  2. Expand the square: (√x−2)²=x−2√x−2√x+4=x−4√x+4.
  3. Thus g(h(x))=mx−4m√x+4m+n.
  4. Compare with x−4√x+1. The coefficient of x gives m=1; the coefficient of √x gives −4m=−4, agreeing.
  5. The constant terms give 4m+n=1. Substitute m=1: 4+n=1, so n=−3.
  6. m=1 and n=−3. Substituting them back reproduces the whole expression.

Undo a function carefully

  • An inverse reverses the input/output connection. f⁻¹(b) asks which input produced b. The raised −1 here means inverse function, not 1/f.
  • This reverse rule is a function only when every reached output came from exactly one input. Such a function is one-to-one.
  • A whole quadratic usually repeats outputs on opposite sides of its vertex. A branch is one side of the curve. Restricting the domain to one branch removes that repetition.
  • When reversing a rule, original outputs become allowed inverse inputs: domain of f⁻¹ = range of f. Original inputs become inverse outputs: range of f⁻¹ = domain of f.
  • To find an inverse formula, write y=f(x), then exchange x and y. This describes the reversed connection. Make y the subject, meaning leave y alone on one side.
  • Keep an equation balanced by applying the same operation to both sides. Subtracting, dividing, multiplying and adding undo their opposite operations.

Worked example · Swap and rearrange

Reverse y=2x+3.

Solution

  1. Exchange input and output letters: x=2y+3.
  2. Subtract 3 from both sides: x−3=2y.
  3. Divide both sides by 2: y=(x−3)/2. The inverse subtracts 3, then divides by 2.

More inverse rearrangements

  • These rules use the same inverse idea. Keep restrictions while undoing operations.
  • A surd is an exact root that is not rational; expressions containing roots are often called surd expressions. We keep roots exact instead of rounding.
  • The number e is a positive constant, approximately 2.718. e raised to a real power is always positive.
  • The natural logarithm ln(u), defined for u>0, is the power of e that gives u. Thus ln(eᵛ)=v, and e raised to ln(u) equals u. These operations undo each other.

Worked example · Undo a reciprocal

Rearrange x=1/(y−2) to make y the subject.

Solution

  1. The original denominator requires y≠2; also the fraction cannot be zero, so x≠0.
  2. Multiply by y−2: x(y−2)=1. Divide by nonzero x: y−2=1/x.
  3. Add 2: y=2+1/x, for x≠0.

Worked example · Undo a square root

Rearrange x=√(y+3).

Solution

  1. The root output x is non-negative, and its inside requires y+3≥0.
  2. Square both sides: x²=y+3. Subtract 3: y=x²−3, with x≥0.
  3. Keep x≥0: otherwise squaring would include values that could not equal the original non-negative root.

Worked example · Undo an exponential

Rearrange x=e^(2y).

Solution

  1. The exponential output is positive, so x>0.
  2. Apply ln to both sides. Since ln undoes e to a power, ln(x)=2y.
  3. Divide by 2: y=½ln(x), with x>0.

Worked example · Undo a logarithm

Rearrange x=ln(y−1).

Solution

  1. The logarithm input must be positive: y−1>0.
  2. Raise e to both sides: e^x=y−1.
  3. Add 1: y=e^x+1. This always gives y>1, as required. Every real x is allowed.
