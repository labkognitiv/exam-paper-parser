Function notation · domain · range

Read the rule.
Control the inputs.

Which numbers may go in, and which numbers can come out? Use that question to understand ranges, inverses and composites.

Start the lesson

A rule connects an input to an output

  • Imagine a rule that doubles a number, then adds 3. The number you start with is the input; the result is the output.
  • A function gives exactly one output for each allowed input. We name a function with a letter, such as f.
  • Write f(x) for the output when the input is x. Read this as “f of x”. The brackets do not mean multiplication.
  • For the doubling rule, f(x) = 2x + 3. Here 2x means 2 × x. Substituting means replacing every x with the chosen input, keeping brackets around it.
  • The domain is the set of allowed inputs. The range is the set of outputs actually reached. A set is simply a collection of values.
  • The symbol ℝ means all real numbers: numbers on the number line. x ∈ ℝ means x belongs to that set.
  • An inequality compares values. x ≥ 2 means x is at least 2, including 2; x > 2 excludes 2. Similarly, ≤ means at most, and < means less than.
  • An interval contains all numbers between its bounds. [a,b] includes both ends. An open end is excluded.
  • In a fraction, the top is the numerator and the bottom is the denominator. A denominator cannot be zero.
  • The notation x² means x × x. A square is never negative. √u is the non-negative number whose square is u, so a real square root requires u ≥ 0.

Read a quadratic through its square

  • A quadratic is an expression whose highest power of x is x². Its graph is a parabola, a smooth U shape or upside-down U shape.
  • A graph plots input x across the horizontal axis and output y up the vertical axis. A point (a,b) means input a gives output b.
  • The vertex is the turning point. A minimum is the least output; a maximum is the greatest.
  • Completing the square rewrites a quadratic without changing it. For example, (x−3)² = x²−6x+9: multiply (x−3)(x−3), including both middle products.
  • Thus x²−6x = (x−3)²−9. We subtract 9 because expanding the square added 9.
  • In a(x−p)²+q, the square is zero at x=p. When a>0, q is the minimum; when a<0, q is the maximum. It is reached only if p is allowed by the domain.

Worked example · A quadratic on all real inputs

f(x) = 2x²−12x+7, for x ∈ ℝ. Find its range.

Solution

  1. Factor 2 from the terms containing x: f(x)=2(x²−6x)+7.
  2. Replace x²−6x with (x−3)²−9: f(x)=2[(x−3)²−9]+7.
  3. Multiply through and collect constants: f(x)=2(x−3)²−18+7=2(x−3)²−11.
  4. The square is at least zero. Multiplying by positive 2 keeps it at least zero, so the output is at least −11.
  5. x=3 is allowed and gives f(3)=−11. Moving farther from 3 makes the square grow without bound.
  6. Range: f(x) ≥ −11. This is a restriction on outputs, not x.

Undo a function carefully

  • An inverse reverses the input/output connection. f⁻¹(b) asks which input produced b. The raised −1 here means inverse function, not 1/f.
  • This reverse rule is a function only when every reached output came from exactly one input. Such a function is one-to-one.
  • A whole quadratic usually repeats outputs on opposite sides of its vertex. A branch is one side of the curve. Restricting the domain to one branch removes that repetition.
  • When reversing a rule, original outputs become allowed inverse inputs: domain of f⁻¹ = range of f. Original inputs become inverse outputs: range of f⁻¹ = domain of f.
  • To find an inverse formula, write y=f(x), then exchange x and y. This describes the reversed connection. Make y the subject, meaning leave y alone on one side.
  • Keep an equation balanced by applying the same operation to both sides. Subtracting, dividing, multiplying and adding undo their opposite operations.

Worked example · Swap and rearrange

Reverse y=2x+3.

Solution

  1. Exchange input and output letters: x=2y+3.
  2. Subtract 3 from both sides: x−3=2y.
  3. Divide both sides by 2: y=(x−3)/2. The inverse subtracts 3, then divides by 2.
  • If z²=u with u>0, both z=√u and z=−√u work. We write z=±√u to show these two choices. If u=0, they are the same value.
  • After swapping letters, the original domain restricts the new y. Use that restriction to choose the correct root.

Worked example · Keep the right branch

f(x)=(x−2)²+2, for x≥2. Find f⁻¹ and its domain.

Solution

  1. Write y=(x−2)²+2. Swap: x=(y−2)²+2, with y≥2.
  2. Subtract 2: x−2=(y−2)².
  3. Taking roots gives y−2=±√(x−2). Since y≥2, y−2≥0, so keep the non-negative root.
  4. Add 2: f⁻¹(x)=2+√(x−2).
  5. The original minimum is 2, reached at x=2; larger outputs are all reached. Thus inverse domain: x≥2.

Worked example · A scaled bracket

f(x)=9x²−6x+6=(3x−1)²+5, for x≥1/3. Find f⁻¹ and its domain.

Solution

  1. The squared bracket becomes zero when 3x−1=0, so the vertex input is 1/3.
  2. Swap: x=(3y−1)²+5, with y≥1/3.
  3. Subtract 5: x−5=(3y−1)².
  4. Since 3y−1≥0, take 3y−1=√(x−5), not the negative root.
  5. Add 1, then divide every term by 3: f⁻¹(x)=[1+√(x−5)]/3.
  6. The original range starts at 5, reached at x=1/3. Therefore inverse domain: x≥5.

A boundary may be approached without being reached

  • A rational function is a ratio of polynomials. Its denominator restrictions matter even after simplification.
  • “Approaches from above” means values stay greater than the boundary while getting closer to it. Infinity is not a real endpoint; “grows without bound” means there is no largest value.

Worked example · Range on a restricted domain

f(x)=2x/(3x−1), for x>1/3. Find the range.

Solution

  1. Write the numerator as 2x=(2/3)(3x−1)+2/3. Dividing each term by 3x−1 gives f(x)=2/3+(2/3)/(3x−1).
  2. For x>1/3, the denominator 3x−1 is positive. The added fraction is positive, so f(x)>2/3.
  3. As x moves towards 1/3 from above, the positive denominator becomes arbitrarily small and the fraction grows without bound.
  4. As x increases without bound, the fraction decreases towards zero but never equals zero.
  5. Every positive fraction value is reached as the denominator runs through all positive values. Range: f(x)>2/3.

Worked example · Which outputs cannot occur?

f(x)=9x²−6x+6=(3x−1)²+5, for x≥1/3. Find all q for which f(x)=q has no solution.

Solution

  1. The square is at least zero. It equals zero at x=1/3, which is allowed.
  2. The minimum output is 5. On this right branch the square increases without bound, so every output from 5 upwards occurs.
  3. The equation f(x)=q asks whether output q can be reached.
  4. No solution exactly when q<5. At q=5, x=1/3 is a solution, so 5 is excluded from the no-solution set.

Find one inverse value without the whole formula

  • Let a=f⁻¹(k). By the inverse meaning, f(a)=k. Solve that equation and check a is allowed in the original domain.
  • If k is outside the original range, it is not an allowed inverse input.

Worked example · A linear rule

f(x)=4−5x, for x∈ℝ. Find f⁻¹(14).

Solution

  1. Let a=f⁻¹(14), so f(a)=14. This gives 4−5a=14.
  2. Subtract 4: −5a=10. Divide both sides by −5: a=−2.
  3. Check f(−2)=4−5(−2)=14. f⁻¹(14)=−2.

Worked example · A reciprocal rule

f(x)=1/(x+2), for x>−2. Find f⁻¹(1/3).

Solution

  1. Solve f(a)=1/3: 1/(a+2)=1/3.
  2. Multiply both sides by 3(a+2), which is nonzero on the allowed domain: 3=a+2.
  3. Subtract 2: a=1. It satisfies a>−2.
  4. Check 1/(1+2)=1/3. f⁻¹(1/3)=1.

Send one output into another function

  • A composite function applies two functions in sequence. fg(x) means f(g(x)); it does not mean f(x)×g(x).
  • The function next to x is the inner function, applied first. The other is the outer function. In fg, do g first, then f.
  • Identify the inner function; substitute its whole expression into every x in the outer rule; keep brackets; then simplify only as requested.
  • “Evaluate” asks for a numerical value. For ff(0), find f(0), then put that result into f again.
  • “Unsimplified” means keep the substituted form. “Show that” requires enough algebra to reach the stated expression. A requested fraction form may require a common denominator: rewrite fractions with the same bottom before combining their tops.

Worked example · The same pair in two orders

f(x)=3x+2 and g(x)=2x²+3, for real x. Find fg and gf.

Solution

  1. For fg, start with g(x)=2x²+3. Put this entire expression into f: fg(x)=3(2x²+3)+2.
  2. Multiply 3 into each term: fg(x)=6x²+9+2=6x²+11.
  3. For gf, start with f(x)=3x+2. Put this into g: gf(x)=2(3x+2)²+3.
  4. Expand (3x+2)(3x+2)=9x²+6x+6x+4=9x²+12x+4.
  5. Multiply by 2 and add 3: gf(x)=18x²+24x+8+3=18x²+24x+11.
  6. Test x=2: fg(2)=6×4+11=35; gf(2)=18×4+24×2+11=131. The two orders are different here.
  • To form fg on every input in g’s stated domain, all outputs of g must be allowed inputs of f. In set language, the range of g must be a subset of the domain of f; subset means every member is contained in the other set.
  • First find the inner range, using its actual domain. Then compare it with the outer domain. If it does not fit, give an inner output that fails.
  • A question may permit restricting the inner domain. A boundary parameter is a number controlling that restriction. Solve the condition and check whether equality is allowed before choosing its largest or smallest value.
  • For instance, if the outer rule contains √(x−5), every inner output must be at least 5. This illustrates the condition; it does not change a given function’s domain automatically.
  • If the question explicitly gives that the composite exists, proceed to substitution. Preserve all stated restrictions.

Key ideas

  • Domain describes inputs; range describes reached outputs.
  • Complete the square and check whether the vertex is allowed. Reached bounds use ≤ or ≥; unreached bounds use < or >.
  • An inverse reverses the input/output connection, so its domain and range swap with the original function.
  • Choose a quadratic inverse’s root using the original domain.
  • Read composites from inside out. The inner range must fit the outer domain.

Worked example · A square gives a minimum

f(x)=x²+6x+13, for x∈ℝ. Find its range.

Solution

  1. (x+3)²=x²+6x+9, so f(x)=(x+3)²+4.
  2. The square is zero at x=−3. This input is allowed, giving the minimum output 4.
  3. The square can grow without bound. Range: f(x)≥4.

Worked example · A positive reciprocal

g(x)=4/(3x−2), for x>2/3. Find the range.

Solution

  1. The restriction makes 3x−2 positive. Dividing positive 4 by it gives g(x)>0.
  2. As x approaches 2/3 from above, the denominator approaches zero and g grows without bound.
  3. As x increases, g approaches zero from above but never reaches it. Every positive output occurs.
  4. Range: g(x)>0.

Worked example · Subtract a positive fraction

f(x)=2−5/(x+2), for x>−2. Find the range.

Solution

  1. x+2 is positive, so 5/(x+2)>0. Therefore f(x)<2.
  2. Near −2 from above, the subtracted fraction grows without bound, so f decreases without bound.
  3. As x grows, the fraction approaches zero. The output rises towards 2 without reaching 2.
  4. Range: f(x)<2.

Worked example · Use the square in an inequality

Given f(x)=x²−6x+13, find all real x for which f(x)<16, exactly.

Solution

  1. Complete the square: f(x)=(x−3)²+4.
  2. Subtract 4 from both sides of (x−3)²+4<16: (x−3)²<12.
  3. A square below 12 means its base lies between −√12 and √12. Thus −√12
  4. √12=√(4×3)=2√3. Add 3 to every part of the inequality.
  5. 3−2√3 The endpoints give f(x)=16, so they are excluded.

Worked example · State a quadratic range

f(x)=3x²−18x+10, for x∈ℝ. State the range.

Solution

  1. Factor 3 from the x terms: 3(x²−6x)+10.
  2. Use x²−6x=(x−3)²−9: f(x)=3(x−3)²−27+10=3(x−3)²−17.
  3. The vertex input 3 is allowed. The positive square coefficient gives minimum −17.
  4. Range: f(x)≥−17.

Worked example · Read an unreached bound

f(x)=4−6/(x+1), for x>−1. State the range.

Solution

  1. x+1>0, so the subtracted fraction is positive. Hence f(x)<4.
  2. Near −1 from above, 6/(x+1) grows without bound, so f decreases without bound.
  3. For large positive x, the fraction approaches zero and f approaches 4 from below. Every value below 4 is reached.
  4. Range: f(x)<4.

Worked example · Complete the square, then solve

f(x)=x²−8x+20, for x∈ℝ. (a) Complete the square. (b) Hence solve f(x)<29.

Solution

  1. (a) (x−4)²=x²−8x+16, so f(x)=(x−4)²+4.
  2. (b) Reuse part (a): (x−4)²+4<29. Subtract 4: (x−4)²<25.
  3. The base must lie between −5 and 5: −5
  4. Add 4 to all three parts: −1. Both boundary inputs give 29, so neither is included.

More inverse rearrangements

  • These rules use the same inverse idea. Keep restrictions while undoing operations.
  • A surd is an exact root that is not rational; expressions containing roots are often called surd expressions. We keep roots exact instead of rounding.
  • The number e is a positive constant, approximately 2.718. e raised to a real power is always positive.
  • The natural logarithm ln(u), defined for u>0, is the power of e that gives u. Thus ln(eᵛ)=v, and e raised to ln(u) equals u. These operations undo each other.

Worked example · Undo a reciprocal

Rearrange x=1/(y−2) to make y the subject.

Solution

  1. The original denominator requires y≠2; also the fraction cannot be zero, so x≠0.
  2. Multiply by y−2: x(y−2)=1. Divide by nonzero x: y−2=1/x.
  3. Add 2: y=2+1/x, for x≠0.

Worked example · Undo a square root

Rearrange x=√(y+3).

Solution

  1. The root output x is non-negative, and its inside requires y+3≥0.
  2. Square both sides: x²=y+3. Subtract 3: y=x²−3, with x≥0.
  3. Keep x≥0: otherwise squaring would include values that could not equal the original non-negative root.

Worked example · Undo an exponential

Rearrange x=e^(2y).

Solution

  1. The exponential output is positive, so x>0.
  2. Apply ln to both sides. Since ln undoes e to a power, ln(x)=2y.
  3. Divide by 2: y=½ln(x), with x>0.

Worked example · Undo a logarithm

Rearrange x=ln(y−1).

Solution

  1. The logarithm input must be positive: y−1>0.
  2. Raise e to both sides: e^x=y−1.
  3. Add 1: y=e^x+1. This always gives y>1, as required. Every real x is allowed.
