Inverse quadratics · reflected graphs

Undo a quadratic, then sketch its mirror.

Complete the square, swap x and y, choose the sign from the restricted branch, and read the inverse domain from the original range.

Start ·

The six-step inverse method

  • Inverse function: a function that undoes f. If f sends x to y, f⁻¹ sends y back to x.
  • To find it, set y = f(x), swap x and y, then solve for y.
  • Complete the square (CTS) gives a quadratic as a(x − h)² + k. Its vertex is (h, k), where the bracket is zero.
  • The principal square root √v is non-negative. When solving u²=v, the equation has two possible values: u = ±√v. The original domain chooses one sign.
  • Right of the vertex means x − h ≥ 0, so keep +. Left means x − h ≤ 0, so keep −.
  • Domain of f⁻¹ = range of f. If a > 0, the range starts at k; if a < 0, it ends at k. A strict original endpoint can make a strict inverse bound.
  1. Write f in CTS form.
  2. Set y = f(x), then swap x and y.
  3. Isolate the squared bracket.
  4. Take the square root with ±.
  5. Compare the original domain with the vertex and choose the sign.
  6. Rename y as f⁻¹(x), then state its domain.
Right branch

x ≥ h ⇒ +√{…}

Left branch

x ≤ h ⇒ −√{…}

Reflection

Every (a, b) on f becomes (b, a) on f⁻¹.

Worked examples

Right branch, non-monic

f(x) = 2x² − 12x + 7 for x ≥ 3.

  1. CTS: f(x) = 2(x − 3)² − 11.
  2. Swap: x = 2(y − 3)² − 11.
  3. Isolate: (y − 3)² = (x + 11)/2.
  4. Root: y − 3 = ±√((x + 11)/2).
  5. x ≥ 3 is right of the vertex, so choose +.
  6. f⁻¹(x) = 3 + √((x + 11)/2). Minimum f-value is −11, so domain x ≥ −11.

Right branch, monic

f(x) = (x − 2)² + 2 for x ≥ 2.

  1. Swap: x = (y − 2)² + 2.
  2. (y − 2)² = x − 2.
  3. y − 2 = ±√(x − 2). The domain is right of x = 2, so keep +.
  4. f⁻¹(x) = 2 + √(x − 2), for x ≥ 2.

Bracket with a coefficient

f(x) = 9x² − 6x + 6 = (3x − 1)² + 5 for x ≥ 1/3.

  1. The bracket is zero at 3x − 1 = 0, so the vertex x-coordinate is 1/3.
  2. Swap: x = (3y − 1)² + 5; isolate: (3y − 1)² = x − 5.
  3. 3y − 1 = ±√(x − 5). Right branch chooses +.
  4. f⁻¹(x) = (1 + √(x − 5))/3, for x ≥ 5.

Left branch, strict endpoint

f(x) = (x − 3)² − 1 for x < 3.

  1. Swap and isolate: (y − 3)² = x + 1.
  2. y − 3 = ±√(x + 1). The domain is left of the vertex, so choose −.
  3. f⁻¹(x) = 3 − √(x + 1).
  4. The vertex value −1 is excluded because x < 3, so range f is f(x) > −1. Inverse domain: x > −1.

Non-monic left branch

f(x) = 2x² − 12x + 11 for x ≤ 2.

  1. CTS: f(x)=2(x−3)²−7. The vertex is at x=3.
  2. Swap and isolate: (y−3)²=(x+7)/2.
  3. The domain x≤2 is left of the vertex, so choose the minus sign.
  4. Therefore f⁻¹(x)=3−√((x+7)/2). Since f(2)=−5 is included, the inverse domain is x≥−5.

Left of a later vertex

f(x) = 2x² − 16x + 23 for x < 3.

  1. CTS: f(x) = 2(x − 4)² − 9. Vertex is x = 4, outside the strict domain.
  2. Swap and isolate: (y − 4)² = (x + 9)/2.
  3. Choose − because x < 3 is left of x = 4: f⁻¹(x) = 4 − √((x + 9)/2).
  4. The endpoint value is f(3) = −7 and is excluded, so inverse domain x > −7.

Negative leading coefficient

f(x) = −3x² + 12x + 2 for x ≤ 2.

  1. CTS: f(x) = −3(x − 2)² + 14. The vertex is a maximum.
  2. Swap, then multiply by −1: (y − 2)² = (14 − x)/3.
  3. x ≤ 2 is left of the vertex, so choose −.
  4. f⁻¹(x) = 2 − √((14 − x)/3), for x ≤ 14.

Different function letter

g(x) = 6x − x² − 5 for x ≥ 3.

  1. CTS: g(x) = −(x − 3)² + 4.
  2. Swap and rearrange: (y − 3)² = 4 − x.
  3. Right branch gives +: g⁻¹(x) = 3 + √(4 − x).
  4. Range g is g(x) ≤ 4, so inverse domain x ≤ 4.

Strict domain below zero

h(x) = 4x² − 12x + 13 for x < 0.

  1. CTS: h(x) = 4(x − 3/2)² + 4.
  2. Swap and isolate: (y − 3/2)² = (x − 4)/4.
  3. Choose −: h⁻¹(x) = 3/2 − √(x − 4)/2.
  4. At excluded x = 0, h(0) = 13. Therefore inverse domain x > 13.

Sketch f and f⁻¹

  • The graphs reflect in the line y = x.
  • Sketch f on its given domain, mark the vertex and an endpoint or sample point, then draw y = x dashed.
  • Swap each marked point (a, b) to (b, a), then join the reflected points smoothly.
  • Domain and range swap. Open endpoints remain open.

Quadratic reflection

For f(x) = (x − 2)² + 2, x ≥ 2, the vertex (2, 2) stays fixed. The point (4, 6) becomes (6, 4). The inverse starts at (2, 2) and rises more gently: y = 2 + √(x − 2).

Left-branch sketch

For f(x) = (x − 3)² − 1, x < 3, the open point (3, −1) reflects to (−1, 3). Choose any point on the curve and swap its coordinates; every plotted pair must swap exactly.

Trigonometric reflection

For f(x) = 3 tan(x/2) − 2, −π/2 ≤ x ≤ π/2: f(−π/2) = −5, f(0) = −2, f(π/2) = 1. Thus f passes through (−π/2, −5), (0, −2), (π/2, 1); f⁻¹ passes through (−5, −π/2), (−2, 0), (1, π/2).

Two quick checks

After √ equation gives y − 3 = ±√(x + 1) for f(x) = (x − 3)² − 1, x < 3, which sign is correct?

For f(x) = 2(x − 3)² − 11 on x ≥ 3, where does f⁻¹ start?

Key ideas

  • CTS identifies the vertex and range.
  • Swap x and y, isolate the square, then use ± before choosing the branch sign.
  • Compare the original domain with the vertex, including strict inequalities.
  • Inverse domain is original range; inverse range is original domain.
  • Sketch the inverse by reflection in y = x and swapping marked coordinates.

Try it yourself

Try these additional examples with complete visible solutions.

Try 1

f(x) = x² − 6x + 7 for x > 4.

  1. CTS: f(x) = (x − 3)² − 2.
  2. Swap and isolate: (y − 3)² = x + 2.
  3. x > 4 is right of the vertex, so y = 3 + √(x + 2).
  4. f(4) = −1 is excluded; f⁻¹(x) = 3 + √(x + 2), x > −1.

Try 2

g(x) = 2x² + 12x + 11 for x ≤ −4.

  1. CTS: g(x) = 2(x + 3)² − 7.
  2. Swap: (y + 3)² = (x + 7)/2.
  3. x ≤ −4 is left of vertex −3, so choose −.
  4. g⁻¹(x) = −3 − √((x + 7)/2). g(−4) = −5 is included, so domain x ≥ −5.

Try 3

f(x) = −x² + 8x − 10 for x ≥ 4.

  1. CTS: f(x) = −(x − 4)² + 6.
  2. Swap and isolate: (y − 4)² = 6 − x.
  3. Right branch keeps +: f⁻¹(x) = 4 + √(6 − x).
  4. Range f is x ≤ 6, so inverse domain x ≤ 6.

Try 4

f(x) = (2x − 3)² + 1 on x ≥ c, with c smallest.

  1. 2x − 3 = 0 gives vertex x = 3/2, so c = 3/2.
  2. Swap: x = (2y − 3)² + 1; isolate (2y − 3)² = x − 1.
  3. Right branch gives 2y − 3 = √(x − 1).
  4. f⁻¹(x) = (3 + √(x − 1))/2, x ≥ 1.

Exam practice 5

f(x) = x² − 6x + 7 for x > 4.

CTS gives (x − 3)² − 2; the right branch gives f⁻¹(x) = 3 + √(x + 2), with domain x > −1.

Exam practice 6

g(x) = 3x² − 18x + 13 for x ≤ 3.

  1. CTS: g(x) = 3(x − 3)² − 14.
  2. (y − 3)² = (x + 14)/3.
  3. Left branch: g⁻¹(x) = 3 − √((x + 14)/3), x ≥ −14.

Exam practice 7

Sketch the inverse of y = (x − 2)² − 3 for x ≥ 2.

  1. Vertex on f: (2, −3), so inverse starts at (−3, 2).
  2. Sample point on f: (4, 1), so inverse point is (1, 4).
  3. Draw y = x dashed and join the inverse points with the reflected curve.

Common slips

  • In f(x+a), the graph shifts left by a, because the input must be reduced by a to return the old value.
  • Multiplying f(x) outside is a stretch, not a translation.
  • A minus outside reflects in the x-axis; a minus inside reflects in the y-axis.
