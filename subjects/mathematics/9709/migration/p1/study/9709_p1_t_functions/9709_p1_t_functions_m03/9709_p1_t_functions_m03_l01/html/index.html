Inverse functions · one-step rearrangement

Undo a function
one legal step at a time.

An inverse reverses a function. Swap x and y, undo each operation, choose the correct branch, then state the inverse domain.

Before you rearrange

  • A function is one-to-one when each output comes from one input. Only then can its inverse be a function. A full parabola fails this test; restricting to one branch fixes it.
  • Start with y=f(x). Swap x and y, then make y the subject. Example: y=2x+3 becomes x=2y+3, then y=(x−3)/2.
  • Undo a fraction by multiplying, a square root by squaring, e^x with ln x, and ln x with e^x.
  • The inverse domain is the original range. The inverse range is the original domain.

Range of a+bsinθ or a+bcosθ

  1. Find the angle interval and the trig range. A full cycle reaches −1≤sinθ≤1.
  2. Multiply by b. If b<0, reverse the endpoint order.
  3. Add a to every part.
  4. Use inclusive signs when the endpoints are reached. Angles here are in radians: one full turn is 2π.

Worked example: negative multiplier

f(x)=5−2sin(2x), 0≤x≤π.

  1. 0≤x≤π gives 0≤2x≤2π, one full cycle, so −1≤sin(2x)≤1.
  2. Multiply by −2, reversing endpoints: −2≤−2sin(2x)≤2.
  3. Add 5: 3≤5−2sin(2x)≤7.
  4. Therefore the range is 3≤f(x)≤7.

Worked examples

Linear inverse

f(x)=4−5x, x∈ℝ.

  1. Write y=4−5x, then swap: x=4−5y.
  2. Subtract 4: x−4=−5y.
  3. Divide by −5: y=(4−x)/5.
  4. So f⁻¹(x)=(4−x)/5, with domain ℝ.

Right-branch quadratic inverse

Completing the square writes a quadratic as a multiple of a square plus a constant. This reveals its vertex, the point where the curve turns. For example, x²−6x=(x−3)²−9 because expanding (x−3)² gives x²−6x+9.

f(x)=2x²−12x+7, x≥3.

  1. Complete the square: f(x)=2(x−3)²−11.
  2. Write and swap: y=2(x−3)²−11, then x=2(y−3)²−11.
  3. Add 11 and divide by 2: (y−3)²=(x+11)/2.
  4. Square-root: y−3=±√((x+11)/2).
  5. The original domain is the right branch x≥3, so choose the plus sign: f⁻¹(x)=3+√((x+11)/2).
  6. The original minimum is −11, so inverse domain is x≥−11.

Quadratic range

f(x)=x²−4x+8, x∈ℝ.

  1. Complete the square: x²−4x+8=(x−2)²+4.
  2. Since a square is at least zero, (x−2)²≥0.
  3. Hence f(x)≥4; equality occurs at x=2.

Rational range

f(x)=3/(2x+1), x>0.

  1. For x>0, the denominator 2x+1>1, so f(x)>0.
  2. As x→0⁺, f(x)→3, but x=0 is excluded, so 3 is not reached.
  3. As x→∞, f(x)→0⁺, also not reached.
  4. Therefore 0<f(x)<3.

Restricted sine inverse

f(x)=4sin x−1, −π/2≤x≤π/2. The inverse sine, arcsin, returns the principal angle in this same interval.

  1. Write y=4sin x−1 and swap: x=4sin y−1.
  2. Add 1 and divide by 4: sin y=(x+1)/4.
  3. Apply principal arcsin: f⁻¹(x)=arcsin((x+1)/4).
  4. The original range is −5≤y≤3, so inverse domain is −5≤x≤3; inverse range is [−π/2,π/2].

Restricted sine with an inner factor

g(x)=5−2sin(2x), 0≤x≤π/4.

  1. Swap: x=5−2sin(2y).
  2. Rearrange: sin(2y)=(5−x)/2.
  3. Apply principal arcsin: 2y=arcsin((5−x)/2).
  4. Divide by 2: g⁻¹(x)=½arcsin((5−x)/2).
  5. Its range is [3,5], so inverse domain is 3≤x≤5.

Read inverse domain and range without rearranging

Use: domain of f⁻¹ = range of f; range of f⁻¹ = domain of f.

  1. Mini-example 1: f(x)=2x+1, x≥0. At x=0, f=1; larger x gives larger outputs. Thus range f≥1, so domain f⁻¹: x≥1. Its range is y≥0.
  2. Mini-example 2: f(x)=2/(3−2x), x≠3/2. The denominator never equals zero and the fraction never equals zero, so range f≠0. Thus domain f⁻¹: x≠0; its range is y≠3/2.
  3. Mini-example 3: for f(x)=4sin x−1 on [−π/2,π/2], range is [−5,3]. Thus inverse domain is [−5,3], inverse range [−π/2,π/2].

Find one inverse value by a shortcut

By definition, f⁻¹(k)=a exactly when f(a)=k. Solve that equation directly.

  1. Linear: to find f⁻¹(14) for f(x)=4−5x, let a=f⁻¹(14). Then 4−5a=14, so −5a=10, a=−2. Therefore f⁻¹(14)=−2.
  2. Rational: for f(x)=1/(x+2), x>−2, let a=f⁻¹(1/3). Then 1/(a+2)=1/3, so 3=a+2, a=1. Since 1>−2, it is allowed, and f⁻¹(1/3)=1.

Common traps

  1. Do not stop at y=.... Replace it with f⁻¹(x)=....
  2. Always state the inverse domain. For f(x)=e2x+3, rearranging gives f⁻¹(x)=½ln(x−3), with x>3 because the original range is above 3.
  3. When squaring gives ±, the original branch selects one. For f(x)=(x−2)²+2 with x≥2, choose plus: f⁻¹(x)=2+√(x−2).

Before you use composites

A composite applies the inner function first. fg(x)=f(g(x)) and gf(x)=g(f(x)); read from right to left to identify the inner function. To find a composite range, form it first, then use range methods. To form g⁻¹(f(x)), find g⁻¹ first, then substitute.

  1. Find the range of fg or gf.
  2. Solve fg(x)=k or gf(x)=k.
  3. Form g⁻¹(f(x)), or solve g⁻¹(f(x))=0.

These are the three next skills: composition, range/equation work on a formed composite, and inverse substitution.

Key ideas

  • Swap, isolate, choose a branch, state the inverse domain.
  • Inverse domain and range swap.
  • For trig ranges, inspect the angle interval before multiplying; a negative multiplier reverses endpoints.
  • For one inverse value, solve f(a)=k and check a is in the original domain.
  • Form a composite before finding its range or solving an equation about it.

Exam-style practice

Question 1

f(x)=3−4/(x+1), x>−1. Obtain f⁻¹(x) and its domain.

  1. Set y=3−4/(x+1); swap: x=3−4/(y+1).
  2. Subtract 3: x−3=−4/(y+1).
  3. Multiply: (x−3)(y+1)=−4.
  4. Divide: y+1=−4/(x−3)=4/(3−x), so y=−1+4/(3−x).
  5. As original x→−1⁺, f→−∞; as x→∞, f→3⁻. Thus range f<3, and inverse domain x<3. Therefore f⁻¹(x)=−1+4/(3−x).

Question 2

f(x)=2+5/(x−3), x>3.

  1. Set y=2+5/(x−3); swap: x=2+5/(y−3).
  2. Subtract 2 and multiply: (x−2)(y−3)=5.
  3. Divide: y−3=5/(x−2), so f⁻¹(x)=3+5/(x−2).
  4. Original range is f>2, so inverse domain is x>2.

Question 3

f(x)=1−2/(3x−p), x>p/3. Write the inverse as p/a−b/(cx−d).

  1. Swap: x=1−2/(3y−p).
  2. Subtract 1 and multiply: (x−1)(3y−p)=−2.
  3. Rearrange: 3y−p=−2/(x−1)=2/(1−x).
  4. Add p and divide by 3: y=p/3+2/[3(1−x)]=p/3−2/(3x−3).
  5. So a=3,b=2,c=3,d=3.
