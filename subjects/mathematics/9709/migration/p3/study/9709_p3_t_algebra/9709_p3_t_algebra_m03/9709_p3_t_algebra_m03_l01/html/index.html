Factorise, then solve

A known factor opens a cubic into simpler pieces. The remaining quadratic then tells you which real roots exist and which factor controls an inequality.

Read each piece before using it

  • A polynomial is an expression built from constants and whole-number powers of a variable.
  • A factor is an expression multiplied by another expression to build the polynomial.
  • A root is a value of x that makes the polynomial equal to zero.
  • A real root is a root on the real number line.
Linear factor and rootx − r = 0 gives x = r

If x − r is a factor, then x = r is a root. For 2x + 3, solve 2x + 3 = 0: subtract 3, then divide by 2, giving x = −3/2.

An equation asks when two expressions are equal. An inequality asks where one is greater or less than another. For an inequality, the sign of every factor matters.

The three-step route

Use the known factor
Write the matching linear factor from the given root or earlier result.
Find the quadratic
Divide the cubic or compare coefficients in an identity.
Finish the problem
Solve factors for roots, or justify which factors can change sign.
Check the domain
Keep only real roots when the question asks for real values.

A coefficient is the number multiplying a power of x. Comparing coefficients means matching the numbers beside equal powers on both sides.

Worked example

Build the quadratic factor

Factorise p(x) = 2x³ − x² + 9, given that 2x + 3 is a factor.

  1. The other factor must be quadratic, so write p(x) = (2x + 3)(Ax² + Bx + C). Here A, B, C are unknown constant coefficients.
  2. Compare x³ terms: 2A = 2, so A = 1.
  3. Compare constant terms: 3C = 9, so C = 3.
  4. Compare x² terms: 2B + 3A = −1. Substitute A = 1: 2B + 3 = −1, so B = −2.

p(x) = (2x + 3)(x² − 2x + 3).

Which roots follow?

  • A product is zero only if at least one of its factors is zero.
  • So solve each factor equal to zero, then collect its real roots.

For p(x) = (2x + 3)(x² − 2x + 3):

  1. The linear factor gives x = −3/2.
  2. For a quadratic ax² + bx + c, the discriminant is b² − 4ac. The quadratic formula takes the square root of this number. A negative number has no real square root, so a negative discriminant means no real roots.
  3. Here (−2)² − 4(1)(3) = −8 < 0.

The only real root is x = −3/2.

When one factor is always positive

Solve (2x + 3)(x² − 2x + 3) < 0

Completing the square rewrites a quadratic as a square plus or minus a constant. A real square is never negative.

  1. Expand the square: (x − 1)² = x² − 2x + 1.
  2. Subtract 1, then add 3: x² − 2x + 3 = (x − 1)² − 1 + 3.
  3. x² − 2x + 3 = (x − 1)² + 2.
  4. Because (x − 1)² ≥ 0, adding 2 gives (x − 1)² + 2 > 0 for every real x.
  5. A positive factor cannot change the sign of a product. Therefore the product is negative exactly when 2x + 3 < 0.
  6. Subtract 3: 2x < −3. Divide by positive 2, so the inequality direction stays the same: x < −3/2.

x < −3/2.

A tempting mistake

Do not invent roots 1 and 3 by reading x² − 2x + 3 as (x − 1)(x − 3). Expanding that gives x² − 4x + 3, a different quadratic.

The required justification

Show why the quadratic never changes sign. Completing the square proves it is at least 2. A negative discriminant together with a positive leading coefficient also proves it is always positive.

Check the sign decision

Check 1

The factor x² + 6x + 11 = (x + 3)² + 2. Can it ever make a product change sign?

Keep only real roots

Solve (x² − x + 2)(2x² + x − 3) = 0 for real x

  1. First factor: its discriminant is (−1)² − 4(1)(2) = −7. It gives no real roots.
  2. Second factor: 2x² + x − 3 = (2x + 3)(x − 1). Expanding checks the middle term: −2x + 3x = x.
  3. Set each linear factor to zero: 2x + 3 = 0 gives x = −3/2; x − 1 = 0 gives x = 1.

Real roots: x = −3/2 or x = 1.

Key ideas

  1. Turn each linear factor into a root by setting it equal to zero.
  2. Use division or coefficient comparison to find a missing quadratic factor.
  3. Use the discriminant to decide whether a quadratic has real roots.
  4. For inequalities, prove which factors are always positive before deciding which factor controls the sign.
  5. Dividing an inequality by a positive number keeps its direction.

Given factor, positive quadratic

Given p(x) = (2x − 1)(x² + 4x + 7), solve p(x) > 0.

  1. x² + 4x + 7 = (x + 2)² + 3.
  2. This quadratic is always positive because (x + 2)² ≥ 0.
  3. So p(x) > 0 exactly when 2x − 1 > 0.
  4. Add 1 and divide by positive 2: x > 1/2.

x > 1/2.

Worked example

A polynomial has factorisation p(x) = (x + 2)(2x² − 3x + 5). Solve p(x) < 0, justifying the sign.

  1. For the quadratic, b² − 4ac = (−3)² − 4(2)(5) = −31 < 0.
  2. Its leading coefficient is 2, which is positive. With no real roots, the upward-opening quadratic stays positive for all real x.
  3. Therefore the product is negative exactly when x + 2 < 0.

x < −2.

Worked example

Find the real roots of (x² − x + 3)(3x² − x − 2) = 0.

  1. For x² − x + 3, the discriminant is 1 − 12 = −11, so this factor gives no real roots.
  2. 3x² − x − 2 = (3x + 2)(x − 1). The numbers used to split the middle term have product −6 and sum −1.
  3. 3x + 2 = 0 gives x = −2/3; x − 1 = 0 gives x = 1.

Real roots: x = −2/3 or x = 1.

Check the real-root filter

Check 2

For 4x² + 4x + 5, the discriminant is 4² − 4(4)(5) = −64 and the leading coefficient is positive. What can you conclude?

Before you leave

Ask two questions: Which factors give real zeros? and Which factors can change sign? Those decisions determine the roots or interval.
