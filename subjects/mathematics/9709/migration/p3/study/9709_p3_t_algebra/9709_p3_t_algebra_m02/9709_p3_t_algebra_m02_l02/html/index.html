Turn words into equations

Factor and
remainder conditions

A divisor tells you which number to substitute. A factor makes the polynomial value zero; a stated remainder makes it equal that number. Those conditions reveal unknown coefficients.

Start the lesson · Key ideas

First, translate the condition

  • A polynomial is a sum of terms such as 4x³, ax and 2.
  • A term is one part separated by a plus or minus sign.
  • The small raised number is a power; x³ means x × x × x.
  • A coefficient multiplies a power of x. In 4x³, the coefficient is 4.
  • We write the whole polynomial as p(x), read “p of x”.

Division words

  • The dividend is the polynomial being divided.
  • The divisor is the expression we divide by.
  • The quotient is the result of the division.
  • The remainder is what is left.
dividend = divisor × quotient + remainder
  • A root of the divisor is the value of x that makes the divisor zero.
  • Set the whole divisor equal to zero before substituting.

Remainder theorem

If p(x) is divided by x - c, the remainder is p(c).

Factor theorem

x - c is a factor of p(x) exactly when p(c) = 0.

One condition finds one unknown

Worked example

The polynomial p(x) = 4x³ + ax + 2 has factor 2x + 1. Find a.

  1. Set the divisor to zero: 2x + 1 = 0, so x = -1/2.
  2. Because it is a factor, p(-1/2) = 0.
  3. Substitute the whole value in brackets:
4(-1/2)³ + a(-1/2) + 2 = 0
  1. Evaluate the cube first: 4(-1/8) - a/2 + 2 = 0.
  2. So -1/2 - a/2 + 2 = 0, then 3/2 - a/2 = 0.
  3. Multiply by 2: 3 - a = 0.

a = 3

Two conditions form simultaneous equations

  • Simultaneous equations are equations that must be true at the same time.
  • Two independent conditions usually determine two unknown coefficients.

Worked example

p(x) = 6x³ + ax² + bx - 2 has factor 2x + 1 and remainder -24 on division by x + 2. Find a and b.

  1. Factor condition: 2x + 1 = 0 gives x = -1/2, so p(-1/2) = 0.
6(-1/2)³ + a(-1/2)² + b(-1/2) - 2 = 0
  1. Evaluate: -3/4 + a/4 - b/2 - 2 = 0.
  2. Multiply every term by 4: -3 + a - 2b - 8 = 0, so a - 2b = 11. Call this equation (1).
  3. Remainder condition: x + 2 = 0 gives x = -2, so p(-2) = -24.
6(-2)³ + a(-2)² + b(-2) - 2 = -24
  1. Evaluate: -48 + 4a - 2b - 2 = -24.
  2. Add 50: 4a - 2b = 26. Divide by 2: 2a - b = 13. Call this equation (2).
  3. From (1), a = 11 + 2b.
  4. Substitute into (2): 2(11 + 2b) - b = 13.
  5. So 22 + 3b = 13, giving b = -3.
  6. Back in (1): a - 2(-3) = 11, so a = 5.

a = 5, b = -3

Fractions need careful signs

Worked example

p(x) = ax³ + x² + bx + 3 is divisible by 2x - 1 and leaves remainder 5 when divided by x + 2. Find a and b.

  1. From 2x - 1 = 0, use x = 1/2 and p(1/2) = 0.
  2. Substitute: a/8 + 1/4 + b/2 + 3 = 0.
  3. Multiply every term by 8: a + 2 + 4b + 24 = 0.
  4. So a + 4b = -26. Call this (1).
  5. From x + 2 = 0, use x = -2 and p(-2) = 5.
  6. Substitute: -8a + 4 - 2b + 3 = 5.
  7. So -8a - 2b = -2, then 4a + b = 1. Call this (2).
  8. From (2), b = 1 - 4a.
  9. Substitute in (1): a + 4(1 - 4a) = -26.
  10. So -15a = -30, giving a = 2 and b = 1 - 8 = -7.

a = 2, b = -7

  • 2x - 1 gives root 1/2.
  • x + 2 with remainder -24 gives p(-2) = -24.
  • Set divisor = 0 first; then substitute.

Two remainder conditions

Worked example

p(x) = 2x³ + ax² + bx + 6 leaves remainder -38 on division by x + 2, and remainder 19/2 on division by 2x - 1. Find a and b.

  1. From x + 2, use x = -2: p(-2) = -38.
  2. -16 + 4a - 2b + 6 = -38, so 4a - 2b = -28.
  3. Divide by 2: 2a - b = -14. Call this (1).
  4. From 2x - 1, use x = 1/2: p(1/2) = 19/2.
  5. 1/4 + a/4 + b/2 + 6 = 19/2.
  6. Multiply by 4: 1 + a + 2b + 24 = 38, so a + 2b = 13. Call this (2).
  7. From (1), b = 2a + 14.
  8. Substitute in (2): a + 2(2a + 14) = 13.
  9. So 5a = -15, giving a = -3.
  10. Then b = 2(-3) + 14 = 8.

a = -3, b = 8

Quadratic divisors

  • The degree is the highest power. A quadratic has degree 2.
  • A remainder must have lower degree than the divisor.
  • So division by a quadratic can leave a linear remainder rx + s.
  • For exact divisibility, the whole remainder must be zero: both r = 0 and s = 0.

Worked example · long division

p(x) = 4x⁴ + ax² + 11x + b is divisible by x² - x + 2. Find a and b.

  1. Write the missing cubic term as 0x³ so powers stay aligned.
  2. The first quotient term is 4x². Subtract 4x²(x² - x + 2) = 4x⁴ - 4x³ + 8x².
  3. The next quotient term is 4x. Subtract 4x(x² - x + 2) = 4x³ - 4x² + 8x.
  4. The next quotient term is a - 4. Subtract (a - 4)(x² - x + 2).
  5. The quotient is 4x² + 4x + (a - 4).
  6. The remainder is (a - 1)x + (b - 2a + 8).
  7. Divisibility makes both coefficients zero: a - 1 = 0 and b - 2a + 8 = 0.

a = 1, b = -6

Worked example · unknown quotient

x⁴ + 2x³ + ax + b is divisible by x² - x + 1. Find a and b.

  1. A degree-4 polynomial divided by degree 2 has a degree-2 quotient. Its leading term must be x².
  2. Write the unknown quotient as x² + Bx + C.
x⁴ + 2x³ + ax + b = (x² - x + 1)(x² + Bx + C)
  1. Compare the x³ coefficients: B - 1 = 2, so B = 3.
  2. Compare the x² coefficients: C - B + 1 = 0, so C = 2.
  3. Expand (x² - x + 1)(x² + 3x + 2).
x²(x²+3x+2) - x(x²+3x+2) + (x²+3x+2)
  1. Collect equal powers: x⁴ + 2x³ + 0x² + x + 2.
  2. Compare with x⁴ + 2x³ + ax + b.

a = 1, b = 2

Key ideas

Linear factor

Set the divisor to zero. If x-c is a factor, use p(c)=0.

Linear remainder

If division by x-c leaves R, use p(c)=R.

Two unknowns

Translate two conditions into two simultaneous equations, then solve them together.

Quadratic divisor

Use long division or an unknown quadratic quotient. Exact divisibility makes every remainder coefficient zero.

  1. Set each divisor equal to zero.
  2. Substitute its root into p(x).
  3. Write the condition exactly: zero for a factor, or the stated remainder.
  4. Clear fractions after substitution.
  5. Solve and substitute back to check.

More worked examples

Worked example

p(x) = ax³ + 5x² - 4x + b has factor x + 2 and remainder 2 on division by x + 1. Find a and b.

  1. p(-2)=0: -8a + 20 + 8 + b = 0, so -8a + b = -28.
  2. p(-1)=2: -a + 5 + 4 + b = 2, so -a + b = -7.
  3. Subtract the second equation from the first: -7a = -21, so a = 3.
  4. Then -3 + b = -7, so b = -4.

a = 3, b = -4

Worked example A

p(x)=2x³-x²+a has factor 2x+3. Find a.

  1. 2x+3=0 gives x=-3/2, so p(-3/2)=0.
  2. 2(-3/2)³ - (-3/2)² + a = 0.
  3. -27/4 - 9/4 + a = 0.
  4. -36/4 + a = 0, so -9 + a = 0.

a = 9

Worked example B

p(x)=2x³+ax²-11x+b is divisible by 2x-1 and leaves remainder 12 on division by x+1. Find a,b.

  1. p(1/2)=0: 1/4+a/4-11/2+b=0.
  2. Multiply by 4: 1+a-22+4b=0, so a+4b=21.
  3. p(-1)=12: -2+a+11+b=12, so a+b=3.
  4. Subtract: 3b=18, so b=6.
  5. Substitute into a+b=3: a=-3.

a = -3, b = 6

Worked example

x⁴+2x³+ax+b is divisible by x²-x+1. Find a,b.

  1. Let the quotient be x²+Bx+C.
  2. Compare x³: B-1=2, so B=3.
  3. Compare x²: C-B+1=0, so C=2.
  4. Expand: (x²-x+1)(x²+3x+2)=x⁴+2x³+x+2.
  5. Match the coefficient of x and the constant term.

a = 1, b = 2
