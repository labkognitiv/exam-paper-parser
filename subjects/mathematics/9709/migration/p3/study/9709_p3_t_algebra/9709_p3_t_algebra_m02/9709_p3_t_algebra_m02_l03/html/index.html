One root, more than one copy

Find where a polynomial meets the axis and goes flat.

A repeated factor gives two useful facts at the same value of x. The polynomial is zero there, and its gradient is zero there.

What a repeated factor means

  • A polynomial is an expression made from powers of x with non-negative whole-number exponents.
  • A coefficient is the number or constant multiplying a power of x.
  • A factor is an expression that multiplies another expression.
  • A root is a value of x that makes the polynomial equal zero.
  • The factor theorem says: x − c is a factor of p(x) exactly when p(c) = 0.
  • Notice the sign: x − c = 0 gives x = c.
  • A repeated factor occurs at least twice, such as (x − c)2.
  • The number of copies is its multiplicity.

Repeated-factor conditions

p(x) = (x − c)mq(x),   m ≥ 2
  • The integer m is the exact multiplicity when q(c) ≠ 0. If m ≥ 2, the factor is repeated.
  • At x = c, the repeated factor is zero, so p(c) = 0.
  • The gradient describes the graph’s steepness: how its height changes as x increases. At one point, it is the slope of the tangent, the straight line matching the curve’s direction there.
  • A zero gradient means that tangent is horizontal.
  • The derivative p′(x) gives the gradient of the graph at each value of x.
  • The prime mark in p′ is read “p prime”.
  • A repeated polynomial root has gradient zero, so p′(c) = 0.

Differentiation used here

  • For a term Axn, where A is a constant coefficient and n is a positive whole number, multiply by the exponent and reduce the exponent by one.
  • d/dx(Axn) = nAxn−1.
  • A constant has derivative zero because its graph has gradient zero.
  • For example, d/dx(ax3) = 3ax2.

Even multiplicity

The graph touches the x-axis and turns back.

Odd repeated multiplicity

The graph crosses the axis, but it is flat at the root.

  1. Read c from x − c.
  2. Write p(c) = 0.
  3. Differentiate p(x).
  4. Write p′(c) = 0.
  5. Solve both equations.

Worked example

p(x) = ax3 − 10x2 + bx + 8. The expression x − 2 is a factor of both p(x) and p′(x). Find a and b. [5]

  1. x − 2 gives the root x = 2.
  2. Use p(2) = 0:
    8a − 40 + 2b + 8 = 08a + 2b − 32 = 04a + b = 16   (1)
  3. Differentiate term by term:
    p′(x) = 3ax2 − 20x + b
  4. Use p′(2) = 0:
    12a − 40 + b = 012a + b = 40   (2)
  5. Subtract equation (1) from equation (2):
    (12a + b) − (4a + b) = 40 − 168a = 24a = 3
  6. Substitute a = 3 into equation (1):
    4(3) + b = 16b = 4

Answer: a = 3, b = 4.

Final check: both p(2) and p′(2) must equal zero.

Common traps

  • x − 2 gives x = 2, not x = −2.
  • Use two different conditions: p(2) = 0 and p′(2) = 0.
  • The derivative of ax3 is 3ax2.
  • Find both unknown coefficients.

From a repeated root to a factorisation

  • A cubic has highest power 3. Removing two copies of a linear factor leaves one linear factor.
  • Write p(x) = (x − c)²(kx + d), with unknown constants k and d.
  • Expand the product and compare coefficients: equal polynomials have the same coefficient beside each power of x.

Key ideas

  • x − c is a repeated factor when p(c) = 0 and p′(c) = 0.
  • The derivative gives the gradient, so a repeated root is flat at x = c.
  • Even multiplicity touches the axis. Odd repeated multiplicity crosses with gradient zero.
  • The two zero conditions usually form simultaneous equations for unknown coefficients.
  • Once a double root is known, begin a cubic factorisation with (x − c)2.

More worked examples

Worked example

p(x) = ax3 − 8x2 + bx + 4. The expression x − 1 is a factor of both p(x) and p′(x). Find a and b.

  1. x − 1 gives x = 1.
  2. Use p(1) = 0:
    a − 8 + b + 4 = 0a + b = 4   (1)
  3. Differentiate:
    p′(x) = 3ax2 − 16x + b
  4. Use p′(1) = 0:
    3a − 16 + b = 03a + b = 16   (2)
  5. Subtract equation (1) from equation (2):
    2a = 12a = 6
  6. Use equation (1): 6 + b = 4, so b = −2.

Answer: a = 6, b = −2.

Worked example

For a = 3 and b = 4, factorise p(x) = 3x3 − 10x2 + 4x + 8 completely. [3]

  1. Because x − 2 divides both p(x) and p′(x), it is repeated.
  2. A cubic has total degree 3. After the two copies of x − 2, one linear factor remains.
  3. Write p(x) = (x − 2)2(kx + m).
  4. Expand the square first:
    (x − 2)2 = x2 − 4x + 4
  5. Multiply by kx + m:
    (x2 − 4x + 4)(kx + m)= kx3 + (m − 4k)x2 + (4k − 4m)x + 4m
  6. Compare coefficients: equal polynomials have matching coefficients of each power of x.
    k = 3m − 4k = −104k − 4m = 44m = 8
  7. The first and last equations give k = 3 and m = 2. The two middle equations confirm the same values.

Answer: p(x) = (x − 2)2(3x + 2).
