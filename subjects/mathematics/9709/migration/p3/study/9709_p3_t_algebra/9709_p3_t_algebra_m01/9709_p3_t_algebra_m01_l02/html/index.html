One expression, one temporary name

Unmask the repeated unknown.

A difficult-looking equation often repeats the same power in several forms. Give that expression a temporary name, solve the simpler equation, then return to x.

Spot what repeats

  • An unknown is a value we are trying to find.
  • An expression is a mathematical combination such as 5x.
  • A substitution gives an expression a short temporary name.
  • If u = 5x, then 52x = (5x)2 = u2.
  • If u = 4x, then 4−x = 1/4x = 1/u.
  • If u = 33x, first solve the simpler equation for u; then undo that substitution.
  • If the repeated expression is 5x − 1, substitute the whole expression, not only part of it.

Index laws used here

am+n = aman    am−n = am/an    a−m = 1/am

A positive base raised to any real power is positive.

Returning from a power to its exponent

  • A logarithm reverses a power: if ax = u, then x = logau.
  • Calculator change of base gives logau = log u/log a.
  • For real logarithms here, a > 0, a ≠ 1, and u > 0.
  • For example, 33x = u gives 3x = log u/log 3, then divide by 3.

Quadratic formula recall

  • For Au2 + Bu + C = 0, A, B, and C are the coefficients.
  • u = (−B ± √(B2 − 4AC))/(2A).
  • The symbol ± means calculate one value with plus and another with minus.
  1. Name the repeated expression.
  2. Rewrite every term using it.
  3. Solve the simpler equation.
  4. Reject impossible values.
  5. Undo the substitution.

Worked examples

First make every power look like the same unknown.

Worked example · Linear in a power

Solve 3x + 2(3x−2) = 8, to 3 decimal places.

  1. Let u = 3x.
  2. Use 3x−2 = 3x/32 = u/9.
  3. u + 2u/9 = 8.
  4. Multiply every term by 9: 9u + 2u = 72, so u = 72/11.
  5. Undo: 3x = 72/11, so x = log(72/11)/log 3.

Answer: x = 1.710 to 3 decimal places.

Keep 72/11 exact until the final calculation.

Worked example · Quadratic in a power

Solve 52x = 5x + 5, to 3 decimal places.

  1. Let u = 5x, so 52x = u2.
  2. u2 − u − 5 = 0.
  3. Quadratic formula: u = (1 ± √21)/2.
  4. Because u = 5x > 0, reject (1 − √21)/2.
  5. x = log((1 + √21)/2)/log 5.

Answer: x = 0.638.

Solve exactly, reject, convert, then round.

Worked example · Reciprocal power

Solve 4x = 3 + 4−x.

  1. Let u = 4x, so 4−x = 1/u.
  2. u = 3 + 1/u.
  3. Multiply by u: u2 = 3u + 1.
  4. u2 − 3u − 1 = 0, so u = (3 ± √13)/2.
  5. Reject the negative root and undo the substitution.

Answer: x = log((3 + √13)/2)/log 4 = 0.862 to 3 decimal places.

Worked example · Ratio of powers

Solve (32x + 3−x)/(32x − 3−x) = 4.

  1. The denominator cannot be zero. After multiplying by 3x, this requires 33x − 1 ≠ 0, so x ≠ 0.
  2. Multiply numerator and denominator by 3x.
  3. The fraction becomes (33x + 1)/(33x − 1) = 4.
  4. Let u = 33x.
  5. u + 1 = 4(u − 1), so u = 5/3.
  6. 33x = 5/3, hence x = log(5/3)/(3 log 3).

Answer: x = 0.155.

Worked example · “Hence” means reuse

Suppose 2|t − 1| = 3|t| has already given t = −2 or t = 2/5. Hence solve 2|5x − 1| = 3|5x|.

  1. Let t = 5x.
  2. The earlier equation now applies exactly.
  3. Because 5x > 0, reject t = −2.
  4. Use 5x = 2/5.
  5. x = log(2/5)/log 5.

Answer: x = −0.569 to 3 significant figures.

Worked example · Keep linked values paired

Given 3a2 + 4a − 4 = 0 and k = (2a − 1)/3, find the matching value of k for each value of a.

  1. (3a − 2)(a + 2) = 0.
  2. So a = 2/3 or a = −2.
  3. For a = 2/3, k = (4/3 − 1)/3 = 1/9.
  4. For a = −2, k = (−4 − 1)/3 = −5/3.

Answer: (a,k) = (2/3,1/9) or (−2,−5/3).

Key ideas

  • Choose a substitution that makes every repeated expression a power, reciprocal, or simple function of one unknown.
  • Solve the new equation before returning to x.
  • If u = ax with a > 0, then u > 0.
  • Check candidates in the original equation when modulus or multiplication may create invalid roots.
  • Check that every original denominator is non-zero.
  • Keep exact values until the final requested rounding.
  • "Hence" tells you to reuse an earlier result.

Worked example

Solve 22x = 6(2x) − 8.

  1. Let u = 2x.
  2. u2 − 6u + 8 = 0.
  3. (u − 2)(u − 4) = 0.
  4. 2x = 2 or 2x = 4.

Answer: x = 1 or x = 2.

Worked example

Solve 3x = 2 + 3−x, to 3 decimal places.

  1. Let u = 3x, so 3−x = 1/u.
  2. u2 − 2u − 1 = 0, so u = 1 ± √2.
  3. Keep u = 1 + √2 because u > 0.

Answer: x = log(1 + √2)/log 3 = 0.802.

Worked example

Solve 4x = 5 + 4−x, to 3 decimal places.

  1. Let u = 4x.
  2. u = 5 + 1/u, so u2 − 5u − 1 = 0.
  3. u = (5 ± √29)/2; reject the negative root.
  4. x = log((5 + √29)/2)/log 4.

Answer: x = 1.188.

Worked example

Solve (23x + 1)/(23x − 1) = 3.

  1. The denominator requires 23x − 1 ≠ 0, so x ≠ 0.
  2. Let u = 23x.
  3. u + 1 = 3u − 3, so u = 2.
  4. 23x = 21, so 3x = 1.

Answer: x = 1/3.
