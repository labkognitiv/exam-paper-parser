Key ideas

  • Combine each side into one logarithm before removing logs.
  • Only products and quotients split under logarithms. Sums do not.
  • Check every original logarithm input is positive.
  • For repeated exponentials, substitute one positive variable and solve the resulting polynomial.
  • For inequalities, check whether the exponential base makes the function increasing or decreasing.
  • Keep exact values through the working. Round once, at the end.
