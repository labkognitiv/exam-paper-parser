Distance, shape, region

Modulus graphs
and inequalities

A modulus measures distance without direction. That one idea explains the V-shaped graph, the split into cases, and why every inequality needs a region rather than only boundary values.

Start the lesson · Key ideas

Distance cannot be negative

  • On a number line, |x - a| is the distance from x to a.
  • The vertical bars are called modulus signs.
  • A distance is always zero or positive, so |x - a| ≥ 0.
  • Write a distance as d, with the condition d ≥ 0.
  • If x = a - d or x = a + d, the distance from a is d in both cases.

Definition

|u| = u when u ≥ 0;   |u| = -u when u < 0.
  • The letter u stands for the whole expression inside the bars.
  • To remove the bars, split where that expression equals zero.
  • For |x - 2|, the split is x = 2.
  • So |x - 2| = 2 - x when x < 2, and |x - 2| = x - 2 when x ≥ 2.

The bars do not mean “delete a minus sign”. First decide the sign of everything inside.

Sketch the V from its vertex

  • A vertex is the sharp point where the two straight arms meet.
  • For y = |ax + b| with a ≠ 0, set ax + b = 0 to find the vertex.
  • If a = 0, the graph is the horizontal line y = |b|, not a V.
  • The vertical line through the vertex is the line of symmetry: the two arms mirror each other.
  • The y-intercept is where the graph crosses the vertical axis, so substitute x = 0.

Worked example

Sketch y = |2x + 1|.

  1. Find the vertex: 2x + 1 = 0, so x = -1/2.
  2. At that value, y = 0. The vertex is (-1/2, 0).
  3. At x = 0, y = |1| = 1, so the y-intercept is (0, 1).
  4. Useful symmetric points are (-2, 3) and (1, 3).

A one-mark sketch needs the V-shape, the correct vertex and correct intercept behaviour.

Two modulus expressions give boundary values

  • A critical value is an x-value where the two sides are equal.
  • Critical values divide the number line into regions.
  • Squaring is safe when both sides are moduli because both sides are non-negative.

Worked example

Solve |2x - 1| > 3|x + 2|.

  1. Find boundaries from |2x - 1| = 3|x + 2|.
  2. Square: (2x - 1)² = 9(x + 2)².
  3. Expand: 4x² - 4x + 1 = 9x² + 36x + 36.
  4. Rearrange and divide by 5: x² + 8x + 7 = 0.
  5. Factorise: (x + 1)(x + 7) = 0.
  6. The critical values are x = -7 and x = -1.
  7. Test x = -2: 5 > 0, so the middle region works.

-7 < x < -1

When one side is an ordinary line

  • A modulus side is never negative.
  • If the other side is negative, it cannot equal a modulus.
  • That is why squaring an ordinary line can create a false, or extraneous, root.
  • Check candidates in the original expression.

Worked example

Solve |x - 3| < 3x - 4.

  1. The right side must be positive: 3x - 4 > 0, so x > 4/3.
  2. Split where x - 3 = 0, at x = 3.
  3. If x ≥ 3: x - 3 < 3x - 4, giving x > 1/2. Together with x ≥ 3, all x ≥ 3 work.
  4. If x < 3: 3 - x < 3x - 4, giving x > 7/4. Together: 7/4 < x < 3.
  5. Combine the touching regions.

x > 7/4

Worked example

Use the sketch of y = |2x + 1| to solve 3x + 5 < |2x + 1|.

  1. Equality on the left arm gives 3x + 5 = -(2x + 1).
  2. So 5x = -6 and x = -6/5.
  3. The other squared candidate is x = -4, but there the line is -7 while the modulus is 7. Reject it.
  4. The line lies below the V to the left of the real crossing.

x < -6/5

Watch out: squaring

  • Before squaring, check whether the non-modulus side can be negative.
  • Find candidates, then substitute each one into the original equation.
  • A candidate from the squared equation is not automatically a crossing of the original graphs.

Constants and parameters

  • A constant is a fixed value.
  • A parameter is a letter that represents a fixed value within a problem.
  • The condition a > 0 fixes the order of values involving a.

Worked example

Let a > 0. Solve |2x - a| < |x + 3a|.

  1. Find equality: (2x - a)² = (x + 3a)².
  2. Use the difference of two squares: [(2x - a) - (x + 3a)][(2x - a) + (x + 3a)] = 0.
  3. Simplify: (x - 4a)(3x + 2a) = 0.
  4. Critical values: x = 4a and x = -2a/3.
  5. Test x = 0: |-a| < |3a| is true because a > 0.

-2a/3 < x < 4a

Case conditions must overlap the answer

Worked example

Solve 2 - 5x > 2|x - 3|.

  1. Split at x = 3.
  2. If x ≥ 3, then 2 - 5x > 2(x - 3), so x < 8/7.
  3. No value can satisfy both x ≥ 3 and x < 8/7. This case contributes nothing.
  4. If x < 3, then 2 - 5x > 2(3 - x).
  5. So -3x > 4. Dividing by negative 3 reverses the sign: x < -4/3.
  6. This already lies inside x < 3.

x < -4/3

Keep exact fractions when the question asks for exact values.

Strict inequalities

The signs < and > exclude equality, so their endpoints stay open.

  1. Find critical values.
  2. Decide which region works.
  3. Keep strict endpoints open.
  4. Test in the original inequality.

Use the critical values to divide the line, then prove which region works.

More worked examples

Worked example

Solve |2x + 3| > |x - 1|.

  1. Equality gives (2x + 3)² = (x - 1)².
  2. Expand and rearrange: 3x² + 14x + 8 = 0.
  3. Factorise: (3x + 2)(x + 4) = 0.
  4. Critical values are -4 and -2/3.
  5. Test x = 0: 3 > 1, so the right outer region works.
  6. Test x = -5: 7 > 6, so the left outer region works.
  7. Test x = -1: 1 > 2 is false, so the middle region does not work.

x < -4 or x > -2/3

Worked example

Solve |x - 4| < 2x + 1.

  1. The right side must be positive, so x > -1/2.
  2. If x ≥ 4, then x - 4 < 2x + 1, giving x > -5. All x ≥ 4 work.
  3. If x < 4, then 4 - x < 2x + 1, giving x > 1.
  4. Combine 1 < x < 4 with x ≥ 4.

x > 1

Worked example

(a) Sketch y = |2x + 3|. (b) Hence solve 3x + 8 > |2x + 3|.

  1. The vertex comes from 2x + 3 = 0: (-3/2, 0).
  2. The y-intercept is (0, 3).
  3. Compare the V with the line y = 3x + 8.
  4. The relevant intersection is on the left arm: 3x + 8 = -(2x + 3).
  5. So 5x = -11 and x = -11/5.
  6. The line is above the V to the right of that crossing.

x > -11/5

Worked example

Solve |2x - 1| < 3|x + 1|.

  1. Square: (2x - 1)² < 9(x + 1)².
  2. Expand and rearrange: 5x² + 22x + 8 > 0.
  3. Factorise: (5x + 2)(x + 4) > 0.
  4. The critical values are -4 and -2/5.
  5. Test x = 0: 1 < 3, so the right region works.
  6. Test x = -5: 11 < 12, so the left region works.
  7. At x = -1, 3 < 0 is false, so the middle region does not work.

x < -4 or x > -2/5
