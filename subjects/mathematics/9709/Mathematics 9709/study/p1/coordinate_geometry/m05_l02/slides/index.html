Part 2

A tangent with a given gradient

A new circle, x² + y² = 8. Its centre is O(0, 0) and its radius is √8.

What the discriminant says · Slide a line across · Find k · Where it touches · Two ways

Recap from lesson 5

Put the line into the circle. Then read the discriminant.

You get a quadratic ax² + bx + c = 0. Its discriminant is Δ = b² − 4ac. Say what each row means before you show it.

DiscriminantThe quadratic has…So the line…
Δ > 0two different rootscuts the circle at two points
Δ = 0one repeated roottouches: it is a tangent
Δ < 0no real rootsmisses the circle

A tangent means Δ = 0. That one line does most of this lesson.

Watch it happen

Slide the line y = x + k across the circle

Every line here has gradient 1. Only k changes, so the lines are parallel.

At k = 6 the line misses. At k = 4 it just touches. At k = 0 it cuts twice. At k = −4 it touches again.

So exactly two values of k give a tangent.
Δ = 0 finds them.

Worked example · a given gradient

y = x + k is a tangent to x² + y² = 8

Find the two possible values of k.

  1. Put y = x + k into the circle, and collect:
    x² + (x + k)² = 8 x² + x² + 2kx + k² = 8 2x² + 2kx + k² − 8 = 0
  2. Read off the three numbers: a = 2, b = 2k, c = k² − 8.
  3. The discriminant:
    Δ = (2k)² − 4 × 2 × (k² − 8) = 4k² − 8k² + 64 = 64 − 4k²
  4. A tangent needs Δ = 0:
    4k² = 64 k² = 16 !k = 4 or k = −4

Where does it touch?

The repeated root is the point of contact

For y = x + 4 the quadratic is 2x² + 8x + 8 = 0. Δ = 0, so both roots are the same x.

x² + 4x + 4 = 0 (x + 2)² = 0 x = −2, so y = −2 + 4 = 2

It touches at (−2, 2). Shortcut: when Δ = 0, x = −b ÷ 2a = −8 ÷ 4 = −2.

Your turn: where does y = x − 4 touch x² + y² = 8?

Another way to the same two lines

Two ways to find parallel tangents

Tangents to x² + y² = 8 with gradient 1.

Way 1: the discriminant

2x² + 2kx + k² − 8 = 0 Δ = 64 − 4k² = 0 !k = 4 or k = −4

Works for any line and any circle. This is the method to learn first.

Way 2: the diameter

Radius gradient = −1 Diameter: y = −x x² + x² = 8, so x = ±2 !Contacts (2, −2) and (−2, 2)

Each tangent is at 90° to its radius, so both contacts are on the diameter with gradient −1. Then lines of gradient 1 through them give y = x − 4 and y = x + 4.

Both ways give y = x + 4 and y = x − 4. Way 2 hands you the contact points too.

The method

Tangents through T in four steps

A line through T

Gradient m, so y − yT = m(x − xT). Here T is (4, 0), so y = m(x − 4).

Put it in the circle

Collect a quadratic in x. The numbers in it contain m.

Set Δ = 0

That gives an equation in m alone. Solve it: usually two answers.

Check straight up

The line x = xT has no gradient, so test it by itself.

Worked example · your go first

Tangents to x² + y² = 8 through T(4, 0)

Find the gradients of the two tangents, and their equations.

Try it on paper first. Then show the steps one at a time.

  1. A line through T(4, 0): y = m(x − 4) = mx − 4m.
  2. Put it in the circle, and collect:
    x² + (mx − 4m)² = 8 x² + m²x² − 8m²x + 16m² = 8 (1 + m²)x² − 8m²x + 16m² − 8 = 0
  3. The discriminant, b² − 4ac:
    Δ = 64m⁴ − 4(1 + m²)(16m² − 8) = 64m⁴ − 64m⁴ − 32m² + 32 = 32 − 32m²
  4. Δ = 0 gives m² = 1, so m = 1 or m = −1. The tangents are y = x − 4 and y = −x + 4.
  5. Straight up through T: x = 4 gives 16 + y² = 8. No points, so it is not a tangent.

Worked example · your go first

An unknown centre: (x − a)² + y² = 5

The line y = 2x − 1 is a tangent to this circle. Find the two possible values of a.

Same idea: substitute, then Δ = 0. This time Δ = 0 gives an equation in a.

  1. Put y = 2x − 1 in, and collect:
    (x − a)² + (2x − 1)² = 5 x² − 2ax + a² + 4x² − 4x + 1 = 5 5x² − (2a + 4)x + a² − 4 = 0
  2. The discriminant:
    Δ = (2a + 4)² − 4 × 5 × (a² − 4) = −16a² + 16a + 96
  3. Δ = 0. Divide by −16, then factorise:
    a² − a − 6 = 0 (a − 3)(a + 2) = 0 !a = 3 or a = −2

A full exam question

Exam-style question · 13 marks

The circle x² + y² = 10 and the point T(5, 5)

O is the origin. Two tangents from T touch the circle at A and B.

(a) Show that T is outside the circle, and find the exact length of TA.[3]

(b) A line through T has gradient m. Show that it is a tangent when 3m² − 10m + 3 = 0. Hence find the two values of m.[5]

(c) Find the coordinates of A and B.[3]

(d) Find the area of the kite OATB.[2]

Get a pen. Do all four parts on paper, then go to the next slide.

Part (a) · 3 marks

Outside, and the tangent length

Compare squares. Then take away r². Try it first.

  1. The centre is O(0, 0) and r² = 10:
    OT² = 5² + 5² = 50
    50 > 10, so T is outside.
  2. The right angle is at A:
    TA² = 50 − 10 = 40 !TA = √40 = 2√10

Part (b) · 5 marks

The two gradients

"Show that" means every line of working. Try it first.

  1. The line through T: y − 5 = m(x − 5), so y = mx + (5 − 5m).
  2. Put it in x² + y² = 10, and collect:
    x² + (mx + 5 − 5m)² = 10 (1 + m²)x² + (10m − 10m²)x + 25m² − 50m + 15 = 0
  3. The discriminant, b² − 4ac:
    (10m − 10m²)² = 100m⁴ − 200m³ + 100m² 4(1 + m²)(25m² − 50m + 15) = 100m⁴ − 200m³ + 160m² − 200m + 60 Δ = −60m² + 200m − 60
  4. Δ = 0. Divide by −20, then factorise:
    3m² − 10m + 3 = 0 (3m − 1)(m − 3) = 0 !m = 1/3 or m = 3

Part (c) · 3 marks

The points of contact

Δ = 0, so each quadratic has a repeated root. Try it first.

  1. m = 3: the line is y = 3x − 10.
    x² + (3x − 10)² = 10 10x² − 60x + 90 = 0 (x − 3)² = 0
    x = 3 and y = 9 − 10 = −1. A is (3, −1).
  2. m = 1/3: the line is y = (x + 10) ÷ 3. Times 9 to clear the fraction:
    9x² + (x + 10)² = 90 10x² + 20x + 10 = 0 (x + 1)² = 0
    x = −1 and y = 9 ÷ 3 = 3. B is (−1, 3).

Part (d) · 2 marks

The area of the kite OATB

Where are the right angles? Try it first.

  1. The radius meets each tangent at 90°. So OATB is two right-angled triangles, OAT and OBT, each with sides √10 and 2√10 round the right angle.
  2. Two triangles, each half of base times height:
    Area = 2 × ½ × √10 × 2√10 = 2 × 10 != 20

√10 × √10 = 10. That's why the square roots vanish.

Common mistakes · Summary

Common mistakes

Six slips that cost marks

Comparing with r, not r²

✗ CT² = 18, more than r = 5, so outside

✓ 18 is less than r² = 25, so inside

Adding in the tangent length

✗ TP² = CT² + r²

✓ CT is the longest side: TP² = CT² − r²

Squaring a bracket badly

✗ (x + k)² = x² + k²

✓ (x + k)² = x² + 2kx + k²

Solving the quadratic instead of Δ = 0

✗ Solve 2x² + 2kx + k² − 8 = 0 for k

✓ Set its discriminant to 0: 64 − 4k² = 0

Keeping only one root

✗ m² = 1, so m = 1

✓ m = 1 or m = −1: two tangents

Forgetting the line straight up

✗ Δ = 0 gave one m, so there's one tangent

✓ Test x = xT by itself. From T(2, 4), x = 2 is the other

Summary

Everything on one page

The facts

Where is T?CT² less than r²: inside, no tangents. Equal: on, one. More: outside, two
Tangent lengthTP² = CT² − r². Both tangents from T are the same length
Tangent testPut the line in the circle. Tangent means Δ = b² − 4ac = 0
Point of contactThe repeated root: x = −b ÷ 2a, then y from the line

The method

  1. Write the line with one unknown: y = x + k for a given gradient, or y − yT = m(x − xT) through T.
  2. Substitute into the circle and collect a quadratic in x.
  3. Set Δ = 0 and solve for the unknown. Keep both roots.
  4. Through T: test the line straight up, x = xT, by itself.
