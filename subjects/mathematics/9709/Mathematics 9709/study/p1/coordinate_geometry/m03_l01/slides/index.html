Part 1

Where they meet

At a meeting point, the line and the curve have the same x and the same y.

Same x, same y · The method · Put it in order · Your turn

Same x, same y

Where does y = x + 3 meet y = x² − 2x − 1?

The straight line crosses the curve at two points. At each one, the two graphs are in the same place: the same x and the same y.

Look at x = 4. The line gives y = 4 + 3 = 7. The curve gives y = 16 − 8 − 1 = 7. Same height, so they meet there.

So at a meeting point, the line's y equals the curve's y:

!x² − 2x − 1 = x + 3

This puts one expression in place of the other. That is called substitution. Now there is only x, and we can solve it.

To find where they meet, set the two y's equal.

Worked example · the method

y = x + 3 and y = x² − 2x − 1

Find the coordinates of the points where the line meets the curve.

  1. Set the two y's equal:
    x² − 2x − 1 = x + 3
  2. Take x + 3 from both sides, so one side is 0:
    x² − 3x − 4 = 0
  3. Factorise and solve:
    (x − 4)(x + 1) = 0 !x = 4 or x = −1
  4. Put each x into the line. It is the simpler equation. x = 4 gives y = 4 + 3 = 7. x = −1 gives y = −1 + 3 = 2.
    !The points are (4, 7) and (−1, 2)

    What b² − 4ac tells you

    The sign of b² − 4ac counts the meeting points

    After substituting you have a quadratic. Its roots are the x-values of the meeting points. Say what goes in each row, then show it.

    b² − 4acThe quadratic hasThe line and the curveIn the lab
    Positive (> 0)Two different rootsCut: they meet twicek = 1: 20 + 4 = 24
    Zero (= 0)One repeated rootTouch: they meet oncek = −5: 20 − 20 = 0
    Negative (< 0)No real rootsMiss: they never meetk = −7: 20 − 28 = −8

    In the lab, b² − 4ac was always 20 + 4k.

    A new word

    Tangent

    IN PLAIN WORDS
    A line that touches a curve at one point and doesn't cross it there. That point is the point of contact.
    EXAMPLE
    y = 2x − 5 touches y = x² − 2x − 1 at (2, −1). Substituting gives x² − 4x + 4 = 0, which is (x − 2)² = 0.
    WATCH OUT
    (x − 2)² = 0 gives x = 2 twice. That is the repeated root: two meeting points squashed into one. It means b² − 4ac = 0.

    Sort · tap a card, then tap its group

    Each quadratic came from a line and a curve. Cut, touch or miss?

    Cut: two points

    Touch: one point

    Miss: no points

    Part 3

    Tangents

    A missing number makes the line a tangent. b² − 4ac = 0 finds it.

    Find k and the contact point · The repeated root · Lines through one point · Two values of m

    Worked example · find the missing number

    y = 2x + k is a tangent to y = x² − 2x − 1

    Find k, and the point of contact.

    1. Set the y's equal and make one side 0:
      x² − 2x − 1 = 2x + k x² − 4x − 1 − k = 0
    2. So a = 1, b = −4 and c = (−1 − k). Keep c in a bracket: it has two parts.
    3. A tangent touches, so b² − 4ac = 0:
      16 − 4(1)(−1 − k) = 0 16 + 4 + 4k = 0 !k = −5
    4. Put k = −5 back: x² − 4x + 4 = 0, so (x − 2)² = 0 and x = 2. From the line, y = 2(2) − 5 = −1.
      !Contact point (2, −1)

    A shortcut for the contact point

    The repeated root

    x = −b ÷ 2a
    −bThe number in front of x, with its sign changed.
    2aTwice the number in front of x².
    Why it worksThe quadratic formula is (−b ± √(b² − 4ac)) ÷ 2a. When b² − 4ac = 0, the ± part is ± 0, so both roots are the same.
    Examplex² − 4x + 4 = 0 gives x = 4 ÷ 2 = 2. The same as factorising.

    Use it only when b² − 4ac = 0. Find the missing number first, then the contact point.

    Lines through one point

    y = mx + 2 and y = x² − x + 3

    Every line y = mx + 2 goes through (0, 2), whatever m is: put in x = 0 and you get y = 2. Changing m turns the line about that point.

    How many of these lines touch the curve?

    Worked example · your go first

    y = mx + 2 is a tangent to y = x² − x + 3

    Find the two values of m, and each point of contact.

    Try it on paper first. Then show the steps.

    1. Set the y's equal and make one side 0. Group the x terms:
      x² − x + 3 = mx + 2 x² − (1 + m)x + 1 = 0
    2. Here b = −(1 + m), so b² = (1 + m)². A tangent needs b² − 4ac = 0:
      (1 + m)² − 4 = 0 (1 + m)² = 4 1 + m = 2 or 1 + m = −2 !m = 1 or m = −3
    3. The contact points. The repeated root is x = −b ÷ 2a = (1 + m) ÷ 2.
      m = 1 (purple): x = 2 ÷ 2 = 1, and y = 1 + 2 = 3.
      m = −3 (orange): x = −2 ÷ 2 = −1, and y = 3 + 2 = 5.
      !Contact (1, 3) and (−1, 5)

    Part 4

    A range of values

    "Find the set of values" means an inequality, not one number.

    Reading an inequality · Lines that miss · Two points · Quick check

    Reading an inequality · from P1 Quadratics

    Sketch it, then read it

    Below the axis means < 0. Above the axis means > 0. The teal part of the axis is the answer.

    Lines that miss

    When does y = 2x + k miss y = x² − 2x − 1?

    Try it first. You have already done most of the work.

    1. From the tangent example: x² − 4x − 1 − k = 0, and b² − 4ac = 16 + 4 + 4k = 20 + 4k.
    2. Miss means no real roots, so b² − 4ac < 0:
      20 + 4k < 0 4k < −20 !k < −5

    It fits the picture. The purple line is the tangent, k = −5. The orange dashed line is k = −8. It is lower, so it misses.

    Worked example · your go first

    y = kx + 2 meets y = x² + 3x + 6 at two different points

    Find the set of values of k.

    Try it on paper first. Then show the steps.

    1. Set the y's equal and group the x terms:
      x² + 3x + 6 = kx + 2 x² + (3 − k)x + 4 = 0
    2. Two points, so b² − 4ac > 0. Multiply out and factorise:
      (3 − k)² − 16 > 0 k² − 6k + 9 − 16 > 0 k² − 6k − 7 > 0 (k − 7)(k + 1) > 0
    3. The roots are −1 and 7. A ∪ shape is above the axis outside them:
      !k < −1 or k > 7

    Quick check

    Read the inequality

    1. (k − 3)(k + 5) < 0 means…
    2. m² > 25 means…
    3. 12 − 4k < 0 means…

    Part 5

    Other curves

    Clear the fraction or the square root first. Then it is a quadratic again.

    x underneath · A range with 2/x · The square-root trap · √x in disguise · A flat tangent

    x underneath

    Where does y = x + 1 meet y = 6/x?

    Try it first. How do you get rid of the fraction?

    1. Set the y's equal. Then multiply every term by x. (x can't be 0 on this curve: 6 ÷ 0 has no answer.)
      x + 1 = 6/x x² + x = 6 x² + x − 6 = 0
    2. Factorise: (x + 3)(x − 2) = 0, so x = 2 or x = −3.
    3. Put each x into the line y = x + 1. x = 2 gives y = 3. x = −3 gives y = −2.
      !The points are (2, 3) and (−3, −2)

    Worked example · your go first

    y = k − x never meets y = x + 2/x

    Find the set of values of k.

    Try it on paper first. Then show the steps.

    1. Set the y's equal, then multiply every term by x:
      k − x = x + 2/x kx − x² = x² + 2 2x² − kx + 2 = 0
    2. Never meets, so b² − 4ac < 0. Here a = 2, b = −k, c = 2:
      k² − 16 < 0 (k − 4)(k + 4) < 0
    3. Below the axis is between the roots:
      !−4 < k < 4
      On the board, the dashed line (k = 1) misses. The orange lines (k = 4 and k = −4) just touch.

    The square-root trap

    Solving k² − 16 < 0

    It is tempting to take the square root of both sides. That loses half of the answer.

    ✗ Square-rooting both sides

    k² < 16 k < 4

    Test k = −10. It fits k < 4, but (−10)² = 100, which is not less than 16. So "k < 4" lets in wrong values.

    ✓ Factorise and sketch

    (k − 4)(k + 4) < 0 !−4 < k < 4

    The roots are −4 and 4. A ∪ shape is below the axis between them. Test k = 0: 0 − 16 < 0 ✓

    Always factorise, find both roots, and read the sketch.

    √x in disguise

    Where does y = x − 1 meet y = 2√x + 2?

    1. Spot the hidden quadratic

    Set equal: x − 1 = 2√x + 2, so x − 2√x − 3 = 0. Let u = √x. Then x = u², and it becomes u² − 2u − 3 = 0.

    2. Solve for u

    (u − 3)(u + 1) = 0, so u = 3 or u = −1. These are values of √x, not of x.

    3. Throw away the impossible one

    √x can't be negative, so u = −1 goes. u = 3 gives x = 9 and y = 9 − 1 = 8. Just one point, (9, 8).

    A flat tangent · your go first

    y = c touches y = (2x + 1) ÷ (x² + 2)

    Try it first. Multiply by the bottom.

    1. x² + 2 is never 0, so multiply both sides by it:
      c(x² + 2) = 2x + 1 cx² − 2x + 2c − 1 = 0
    2. Touch means b² − 4ac = 0. Here the number in front of x² is c, and the number on its own is 2c − 1:
      4 − 4c(2c − 1) = 0 8c² − 4c − 4 = 0 2c² − c − 1 = 0 (2c + 1)(c − 1) = 0
    3. !c = 1 or c = −1/2
      The flat lines touch at the top and the bottom of the curve.

    Part 6

    A full exam question

    Four parts, one part per slide. Try each on paper before you reveal it.

    (a) The quadratic · (b) The meeting points · (c) The tangent · (d) Two points

    Exam-style question · 10 marks

    The curve y = 2x² − 3x + 4

    The line y = x + k, where k is a constant, meets the curve.

    (a) Show that the x-coordinates of the meeting points satisfy 2x² − 4x + 4 − k = 0.[1]

    (b) When k = 10, find the coordinates of the meeting points.[3]

    (c) Find the value of k for which the line is a tangent, and the point of contact.[3]

    (d) Find the set of values of m for which y = mx + 2 meets the curve at two different points.[3]

    Get a pen. Do all four parts on paper, then go to the next slide.

    Part (a) · 1 mark

    Show the quadratic

    Try it first. "Show that" means every line of working.

    1. Set the y's equal:
      2x² − 3x + 4 = x + k
    2. Take x and k from both sides:
      !2x² − 4x + 4 − k = 0

    So a = 2, b = −4 and c = 4 − k. You will need these in (c). The dashed lines are y = x + k for three values of k.

    Part (b) · 3 marks

    k = 10: the meeting points

    Try it first. Use (a) with k = 10.

    1. Put k = 10 into the quadratic from (a), then halve every term:
      2x² − 4x − 6 = 0 x² − 2x − 3 = 0 (x − 3)(x + 1) = 0
    2. So x = 3 or x = −1. Now y from the line y = x + 10: x = 3 gives y = 13, and x = −1 gives y = 9.
      !(3, 13) and (−1, 9)

    Part (c) · 3 marks

    The tangent

    Try it first. Keep c = 4 − k in a bracket.

    1. Tangent, so b² − 4ac = 0, with a = 2, b = −4, c = 4 − k:
      16 − 4(2)(4 − k) = 0 16 − 32 + 8k = 0 8k = 16 !k = 2
    2. The repeated root. Here a = 2, so 2a = 4:
      x = 4 ÷ 4 = 1 y = 1 + 2 = 3 !Contact point (1, 3)

    Part (d) · 3 marks

    y = mx + 2: two different points

    Try it first. This is a new line, so start again from the y's.

    1. Set the y's equal and group the x terms:
      2x² − 3x + 4 = mx + 2 2x² − (3 + m)x + 2 = 0
    2. Two points, so b² − 4ac > 0. Here 4ac = 4 × 2 × 2 = 16:
      (3 + m)² − 16 > 0 m² + 6m − 7 > 0 (m − 1)(m + 7) > 0
    3. Outside the roots −7 and 1:
      !m < −7 or m > 1

    Part 7

    Before you practise

    The slips that cost marks, and everything on one page.

    Common mistakes · Summary

    Common mistakes

    Six slips that cost marks

    Stopping at x

    ✗ They meet at x = 4 and x = −1

    ✓ Find y too: (4, 7) and (−1, 2)

    Losing the bracket round c

    ✗ 16 − 4(1)(−1 − k) = 16 − 4 − 4k

    ✓ = 16 + 4 + 4k. Both parts of c change sign

    The wrong sign for the question

    ✗ "Doesn't meet", so b² − 4ac > 0

    ✓ Miss: < 0. Touch: = 0. Two points: > 0

    Square-rooting an inequality

    ✗ k² < 16, so k < 4

    ✓ (k − 4)(k + 4) < 0, so −4 < k < 4

    Forgetting a in −b ÷ 2a

    ✗ 2x² − 4x + 2 = 0: x = 4 ÷ 2 = 2

    ✓ 2a = 4, so x = 4 ÷ 4 = 1

    Keeping an impossible root

    ✗ √x = −1, so x = 1

    ✓ √x can't be negative. Throw u = −1 away

    Summary

    Everything on one page

    The method

    Where they meetSet the y's equal, make one side 0, solve, then y from the line
    Cut, touch, missb² − 4ac > 0, = 0 or < 0
    Tangentb² − 4ac = 0 finds the missing number. Then contact at x = −b ÷ 2a
    FractionsMultiply every term by the bottom (x, or x² + 2) first

    Letters and ranges

    1. "Set of values": write b² − 4ac with the letter in it, then an inequality. Factorise and sketch: < 0 is between the roots, > 0 is outside.
    2. A tangent with m: often two values of m. Each one has its own contact point.
    3. √x: let u = √x to get a quadratic in u. Throw away any negative u.
