# Source-package QC contract

`source_review.json` must contain:

```json
{
  "reviewer": "independent reviewer name",
  "paper_code": "9702_m16_12",
  "qp_identity": "passed",
  "ms_identity": "passed",
  "qp_complete": "passed",
  "answer_key_complete": "passed",
  "source_authority": "original_official_pdfs",
  "verdict": "passed",
  "notes": ""
}
```

Pass only after visually confirming the QP and MS identities and completeness. The answer key must cover all 40 MCQs. Do not treat filenames alone as sufficient evidence.
