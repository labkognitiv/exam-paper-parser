# Unified lesson library

Local searchable viewer for individual HTML lessons across Biology 9700,
Chemistry 9701 and Physics 9702. Biology and Chemistry are read from their
active study workspaces. Physics is read from the preserved 2026-09-08
root-slimming archive. Lesson content is served in place and never modified.

Run:

```bash
python3 server.py --port 8790
```

Open `http://localhost:8790`.
