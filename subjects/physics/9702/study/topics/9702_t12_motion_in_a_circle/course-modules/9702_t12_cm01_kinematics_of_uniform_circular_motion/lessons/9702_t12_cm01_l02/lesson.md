# Angular speed: describing how fast an object turns

Picture a playground roundabout. A child runs around its edge. The child moves from place to place, so they have a **linear speed**. At the same time, the line from the centre of the roundabout to the child turns. We need a way to describe how fast that line turns.

That turning rate is called **angular speed**. It is useful for a wheel, a rotating fan or any object moving in a circle at a constant speed.

This lesson uses the previous lesson's idea that one complete turn is an angular displacement of **\(2\pi\) radians**. It does not yet explain the force or acceleration that keeps an object moving in a circle. That is the next lesson.

## What does angular speed mean?

**Angular speed** tells us how much angle an object sweeps out in each second. Its symbol is **\(\omega\)**, read as "omega".

For uniform circular motion, the object makes equal turns in equal times. Its angular speed is therefore constant. A larger value of \(\omega\) means that the object completes each turn more quickly.

The SI unit of angular speed is **radians per second**, written **\(\mathrm{rad\ s^{-1}}\)**. This unit says two things:

- **radian** tells us that we are measuring an angle.
- **per second** tells us that the angle is changing with time.

Ask yourself: if one object completes a turn in half the time of another, which object has the larger angular speed? It is the first object, because it sweeps out the same angle in less time.

> **Term meaning: period, \(T\).** The time taken for one complete revolution.

The period is measured in seconds, \(\mathrm{s}\). A **revolution** means one complete trip around the circle.

> **Term meaning: frequency, \(f\).** The number of complete revolutions each second.

Frequency is measured in hertz, \(\mathrm{Hz}\). One hertz means one revolution per second, so \(1\,\mathrm{Hz}=1\,\mathrm{s^{-1}}\).

## Angular speed and the period

One complete revolution sweeps an angle of \(2\pi\) radians. If that revolution takes a period \(T\), dividing the angle by the time gives the angular speed.

### <a id="formula-angular-speed-period"></a>Angular speed, period and frequency

> **Formula to learn: Angular speed and period relationship.**
>
> \[
> \omega = \frac{2\pi}{T} = 2\pi f
> \]

In this formula:

- **\(\omega\)** is angular speed, in \(\mathrm{rad\ s^{-1}}\).
- **\(T\)** is the period for one revolution, in \(\mathrm{s}\).
- **\(f\)** is frequency, in \(\mathrm{Hz}\) or \(\mathrm{s^{-1}}\).
- **\(\pi\)** is the number \(3.14159\ldots\). It appears because one full turn is \(2\pi\) radians.

Use this formula for an object making repeated complete revolutions at a constant angular speed. The two forms say the same thing. Use \(\omega=2\pi/T\) when you know the period. Use \(\omega=2\pi f\) when you know the frequency.

In plain language, a short period means fast turning. A high frequency also means fast turning. Both give a large angular speed.

### Worked example 1: use a period

A small turntable completes one revolution every \(0.80\,\mathrm{s}\). Find its angular speed.

**What is known?** The period is

\[
T=0.80\,\mathrm{s}
\]

**What is needed?** The angular speed \(\omega\), in \(\mathrm{rad\ s^{-1}}\).

**Decision.** We know the time for one revolution, so use \(\omega=2\pi/T\).

\[
\omega=\frac{2\pi}{T}
\]

Substitute the period with its unit:

\[
\omega=\frac{2\pi}{0.80\,\mathrm{s}}
\]

\[
\omega=7.85\,\mathrm{rad\ s^{-1}}
\]

To two significant figures:

\[
\boxed{\omega=7.9\,\mathrm{rad\ s^{-1}}}
\]

**Check.** The answer has radians per second, which is the correct unit. The period is less than one second, so completing \(2\pi\) radians each second should give an angular speed greater than \(2\pi\,\mathrm{rad\ s^{-1}}\). The value \(7.9\,\mathrm{rad\ s^{-1}}\) fits this expectation.

If a wheel has a period of \(2.0\,\mathrm{s}\), which answer is its angular speed?

- **A:** \(\pi\,\mathrm{rad\ s^{-1}}\)
- **B:** \(4\pi\,\mathrm{rad\ s^{-1}}\)

**Feedback for A:** Correct. One revolution is \(2\pi\) radians, so \(\omega=2\pi/2.0=\pi\,\mathrm{rad\ s^{-1}}\).

**Feedback for B:** Not correct. This value multiplies by the period instead of dividing by it. A longer period must mean a smaller angular speed.

## Angular speed and linear speed

An object on a circle has two useful speeds. **Angular speed** says how fast the radius line turns. **Linear speed** says how much distance the object moves along its circular path each second. Linear speed is also called tangential speed because, at any instant, it is along a tangent to the circle.

Imagine two marks on the same rotating disc. They both turn through the same angle in the same time, so they have the same angular speed. The mark farther from the centre travels around a larger circle. It covers more distance each second, so it has a larger linear speed.

> **Term meaning: radius, \(r\).** The straight-line distance from the centre of a circle to the object's path.

Radius is measured in metres, \(\mathrm{m}\). Convert centimetres to metres before using it in a speed calculation. For example, \(35\,\mathrm{cm}=0.35\,\mathrm{m}\).

### <a id="formula-circular-linear-speed"></a>Linear speed in circular motion

> **Formula to learn: Linear speed in circular motion.**
>
> \[
> v = r\omega
> \]

In this formula:

- **\(v\)** is linear speed, in metres per second, \(\mathrm{m\ s^{-1}}\).
- **\(r\)** is the radius of the circular path, in metres, \(\mathrm{m}\).
- **\(\omega\)** is angular speed, in radians per second, \(\mathrm{rad\ s^{-1}}\).

The units show why the formula makes sense:

\[
\mathrm{m}\times\mathrm{rad\ s^{-1}}
\]

A radian is a measure of angle, so the result is written as linear speed:

\[
\mathrm{m\ s^{-1}}
\]

Use \(v=r\omega\) only when \(r\) is the radius of the path followed by the object. Do not use the diameter by mistake. The diameter is twice the radius.

### Worked example 2: connect the two speeds

A point on the edge of a rotating disc is \(0.35\,\mathrm{m}\) from the centre. The disc completes one revolution in \(1.4\,\mathrm{s}\). Find:

1. the angular speed of the disc;
2. the linear speed of the point.

**Stage 1: find angular speed.** We know a period, so first use \(\omega=2\pi/T\).

\[
T=1.4\,\mathrm{s}
\]

\[
\omega=\frac{2\pi}{1.4\,\mathrm{s}}
\]

\[
\omega=4.49\,\mathrm{rad\ s^{-1}}
\]

**Stage 2: find linear speed.** The point is \(0.35\,\mathrm{m}\) from the centre, so \(r=0.35\,\mathrm{m}\). Now use \(v=r\omega\).

\[
v=(0.35\,\mathrm{m})(4.49\,\mathrm{rad\ s^{-1}})
\]

\[
v=1.57\,\mathrm{m\ s^{-1}}
\]

To two significant figures:

\[
\boxed{\omega=4.5\,\mathrm{rad\ s^{-1}}}
\]

\[
\boxed{v=1.6\,\mathrm{m\ s^{-1}}}
\]

**Check.** Multiplying a radius in metres by an angular speed in radians per second gives metres per second. The point is not far from the centre, so a linear speed of \(1.6\,\mathrm{m\ s^{-1}}\) is sensible for this turning rate.

Two points are fixed to the same rotating disc. Point P is \(0.20\,\mathrm{m}\) from the centre and point Q is \(0.50\,\mathrm{m}\) from the centre. Which statement is correct?

- **A:** P and Q have the same angular speed, but Q has the larger linear speed.
- **B:** P and Q have the same linear speed, but Q has the larger angular speed.

**Feedback for A:** Correct. One rigid disc completes each turn together, so both points have the same \(\omega\). Since \(v=r\omega\), the larger radius gives Q the larger linear speed.

**Feedback for B:** Not correct. The disc does not let one point turn through more angle than the other in the same time. Both have the same angular speed. Their different radii make their linear speeds different.

## A common formula choice mistake

It is tempting to put the linear speed directly into \(\omega=2\pi/T\). That formula does not use linear speed. It connects angular speed with the time for one revolution.

When a question gives a radius and an angular speed, use \(v=r\omega\). When it gives a period, use \(\omega=2\pi/T\) first. Some questions need both steps, as in Worked example 2.

Another common mistake is to use a radius in centimetres. The standard unit of linear speed is \(\mathrm{m\ s^{-1}}\), so change the radius to metres before substitution.

## Core recap

- **Angular speed, \(\omega\),** is the angle swept out each second. Its unit is **\(\mathrm{rad\ s^{-1}}\)**.
- For one complete revolution, the angular displacement is **\(2\pi\) radians**.
- Use **\(\omega=2\pi/T=2\pi f\)** to connect angular speed with period or frequency.
- Use **\(v=r\omega\)** to find the linear speed of an object on a circular path.
- Points on the same rigid rotating object have the same **angular speed**. The point with the larger radius has the larger **linear speed**.
