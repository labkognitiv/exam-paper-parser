# Physics lesson brand reference

Read before every visual build. Apply this shared presentation baseline together
with the subject-specific visual-design reference. Existing verified Physics
lessons may be inspected for reusable components, but they are not content sources.

## Colours and type

| Role | Colour |
|---|---|
| Reading surface | `#ffffff` |
| Headings, hero, buttons | `#29213f` |
| Body | `#24222c` |
| Secondary text | `#625d6d` |
| Links, emphasis, focus | `#08756f` |
| Handwritten thinking questions | `#b52a31` |
| Subtle borders | `#d9d6e3` |
| Mint definitions / activities | `#edf8f4` |
| Peach activities | `#fff3e8` |
| Blue worked examples / activities | `#edf3ff` |
| Lilac activities | `#f5effc` |
| Yellow activities | `#fff8dc` |
| Correct / incorrect feedback | `#08613b` / `#902e25` |

Use Source Sans 3 regular/semibold when available and Kalam bold for short red
thinking questions. Body is 20px desktop, 18px mobile, line-height 1.55; content
max-width 1080px. Use fluid headings and modest rounded cards. Preserve focus.

## Composition and imagery

White reading surface; plum title area; short explanations beside their diagrams.
Definitions and worked examples have distinct backgrounds. Activities use the
pastel palette, aligned controls and conditional feedback. Reserve handwritten
red text for meaningful student questions. Adapt grouping and hierarchy to the
lesson; never copy content, IDs, answers or diagrams from another lesson.

Prefer clean diagrams, dark clear outlines, restrained pastel fills and readable
labels. Preserve physical accuracy, scale, vectors, axes and geometry over stylistic
imitation. No grey panels, heavy borders or giant empty margins around figures.

Work only in the target lesson directory. Reuse verified components after adapting
content and testing behavior. Visual approval does not certify lesson science or
a pending topic audit.
