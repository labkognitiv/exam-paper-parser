## Parallel Execution & Agent Claiming Protocol

To avoid duplicate work when running multiple agents in parallel:

1. **Check Status**: Read this file (`references/paper-log.md`). Only select papers marked `NOT_STARTED`.
2. **Claim Paper**: Before starting authoring, update the paper status in this table to `IN_PROGRESS` (or ensure no conflicting agent is working on the same paper code).
3. **Preflight SHA-256**: Hash all 40 question JSON files before generating enrichments.
4. **Author & Validate**: Author all 40 enrichment records and run `scripts/validate_p1_enrichment.py` for every question.
5. **Postflight SHA-256**: Verify byte-for-byte invariance of source question JSONs.
6. **Finalize Claim**: Update status in this table to `COMPLETE`, set Enriched to `40`, and record validation notes (or run `.venv/bin/python scripts/update_p1_paper_log.py` to auto-sync).
